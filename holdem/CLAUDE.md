# 로열 홀덤 — 게임 프롬프트

하루퍼즐과 **별개로 돌아가는 독립 게임**이에요. 이 폴더(`holdem/`)만 고치고, 하루퍼즐의 `core/`·`portal/`·빌드와 섞지 않는다.
배포: Railway 프로젝트 `royal-holdem`(루트 폴더 `holdem`, `npm start`).

## 사용자 지시
- 2026-10-12: 사이트는 하루퍼즐과 별도 독립 게임으로 만든다.
- 2026-10-12: 모드는 AI 상대 솔로, 실시간 친구 대전, 일일 토너먼트 세 가지.
- 2026-10-12: 룰은 표준 텍사스 홀덤 노리밋(블라인드, 프리플롭~리버, 올인·사이드팟).

## 구조
| 파일 | 무엇 |
|---|---|
| `public/engine.js` | 공용 엔진(브라우저·서버 같이 씀): 족보 판정, 베팅 라운드, 사이드팟, 쇼다운, 봇 AI(성격 5종) |
| `public/app.js` | 화면·연출(카드 딜링·칩 이동·쇼다운 하이라이트·배너·폭죽), 솔로 진행, 온라인 연결 |
| `public/style.css`, `public/index.html` | 화면. 크기는 테이블 기준 `cqw` 단위 |
| `public/img/` | 테이블·카드 뒷면·로고·아바타 6종(Figma AI로 만든 그림) |
| `server.js` | 정적 파일 + 웹소켓(`/ws`) 대전 방 + 오늘의 토너먼트 + `/api/daily` 랭킹(`DATA_DIR/daily.json`) |
| `test/engine.test.js` | 족보·순서·사이드팟·칩 보존·봇 1,700핸드 시뮬레이션 (`npm test`) |

## 규칙 메모
- 시작 칩 10,000, 블라인드 50/100에서 10핸드마다 오름.
- 친구 대전: 방 코드 4자리·링크 초대, 최대 6명, 빈자리 AI(방장 선택), 차례 25초(넘기면 체크/폴드, 자리비움은 4초), 끝나면 방장이 재대결.
- 오늘의 토너먼트: 씨앗 `daily:날짜(KST)` → 모두 같은 카드·같은 봇 판단, 30핸드 후 남은 칩이 점수, 하루 1회(토큰 기준), 중간에 나가면 그때 칩으로 기록.
- 서버가 판을 진행(서버 권위)하고, 남의 카드는 쇼다운·올인 전까지 보내지 않는다.
