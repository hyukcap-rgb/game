# 로열 홀덤 — 게임 프롬프트

하루퍼즐과 **별개로 돌아가는 독립 게임**이에요. 이 폴더(`holdem/`)만 고치고, 하루퍼즐의 `core/`·`portal/`·빌드와 섞지 않는다.
배포: Railway 프로젝트 `royal-holdem`(루트 폴더 `holdem`, `npm start`).

## 회원·승인·보유 칩
- 가입: 닉네임+PIN(숫자 4~6) → 관리자 가입 승인(설정의 '가입 지급 칩' 지급). 로그인 세션은 기기에 저장(`rh_sess`).
- 입장: 접속할 때마다 자동으로 입장 승인 요청 → 관리자가 승인해야 게임 메뉴가 열림. 잠깐 끊김(90초)·게임 중 재접속은 승인 유지, 홀덤을 나가면(하루퍼즐로 돌아가기) 승인 해제.
- 보유 칩: AI 대결·친구 대전에 들어갈 때 가져갈 칩을 직접 고름(방 최소 머니 이상, 보유 칩 이하) → 그만큼 보유 칩에서 빠지고, 나오거나 게임이 끝나면 남은 칩이 돌아옴. 방장은 방을 만들 때 블라인드(50/100~1만/2만, 고정)와 최소 머니(1천~100만, BB 10배 이상)를 정함. AI 대결도 블라인드를 고름(최소 머니 = BB 20배 근처). 게임이 끝나면 방은 대기실로 돌아가고 각자 다시 칩을 가져와 앉음. 오늘의 토너먼트는 무료(별도 칩). 모든 변동은 칩 로그. 서버가 다시 켜지면 테이블에 있던 칩(핸드 시작 기준)을 돌려줌.
- 리바인: 칩이 40BB보다 적고 지금 핸드에 걸려 있지 않을 때(칩을 다 잃었거나 폴드했거나 핸드가 끝난 뒤) [💰 리바인] → 40BB~200BB를 보유 칩에서 가져옴. 테이블 모두에게 가운데 알림·좌석 금빛 '리바인 +금액'·칩 날아오기·토스트로 보이고, 좌석 이름 아래 '리바인 N' 배지가 남음. 사람이 모두 칩을 잃으면 30초 동안 리바인을 기다린 뒤 끝냄. 칩 로그 종류 '리바인'.
- 관리자: `/admin`(비밀번호 = Railway 변수 `ADMIN_PASSWORD`). 승인 대기(가입·입장), 전체 회원(상태·보유·테이블 칩, 칩 ±, 로그, 강퇴, 차단, PIN 초기화, 메모, 삭제), 칩 로그, 게임 방, 설정(가입 지급·바이인·최소 보유·자동 승인).
- 저장: `DATA_DIR/db.json`(Railway 볼륨 `/data`).

## 규칙 메모
- 9인 테이블(AI 8명). 일반 방은 블라인드 고정, 오늘의 토너먼트만 50/100에서 10핸드마다 오름. AI의 칩은 max(최소 머니, 100BB).
- 친구 대전: 방 코드 4자리·링크 초대, 최대 9명, 빈자리 AI(방장 선택), 차례 25초(넘기면 체크/폴드, 자리비움은 4초), 끝나면 방장이 재대결.
- 오늘의 토너먼트: 씨앗 `daily:날짜(KST)` → 모두 같은 카드·같은 봇 판단, 30핸드 후 남은 칩이 점수, 하루 1회(토큰 기준), 중간에 나가면 그때 칩으로 기록.
- 서버가 판을 진행(서버 권위)하고, 남의 카드는 쇼다운·올인 전까지 보내지 않는다.
