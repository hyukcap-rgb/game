# 로열 홀덤 — 게임 프롬프트

하루퍼즐과 **별개로 돌아가는 독립 게임**이에요. 이 저장소(`royal-holdem`)가 원본이고, 하루퍼즐 저장소(`game/holdem`)에서 2026-10-13에 떼어 왔어요.
배포: Railway(저장소 루트, `npm start`, 헬스체크 `/healthz`, 볼륨 `/data` + 변수 `DATA_DIR=/data`, `ADMIN_PASSWORD`). 이전 방법은 `README.md`.
하루퍼즐 사이트는 `?embed=1`로 이 서비스를 열어요 — 주소가 바뀌면 하루퍼즐 쪽 `games/holdem` 주소도 바꿔야 해요.

## 회원·승인·보유 칩
- 가입: 닉네임+PIN(숫자 4~6) → 관리자 가입 승인(설정의 '가입 지급 칩' 지급). 로그인 세션은 기기에 저장(`rh_sess`).
- 입장: 접속할 때마다 자동으로 입장 승인 요청 → 관리자가 승인해야 게임 메뉴가 열림. 잠깐 끊김(90초)·게임 중 재접속은 승인 유지, 홀덤을 나가면(하루퍼즐로 돌아가기) 승인 해제.
- 보유 칩: AI 대결·친구 대전에 들어갈 때 가져갈 칩을 직접 고름(방 최소 머니 이상, 보유 칩 이하) → 그만큼 보유 칩에서 빠지고, 나오거나 게임이 끝나면 남은 칩이 돌아옴. 방장은 방을 만들 때 블라인드(50/100~1만/2만, 고정)와 최소 머니(1천~100만, BB 10배 이상)를 정함. AI 대결도 블라인드를 고름(최소 머니 = BB 20배 근처). 게임이 끝나면 방은 대기실로 돌아가고 각자 다시 칩을 가져와 앉음. 오늘의 토너먼트는 무료(별도 칩). 모든 변동은 칩 로그. 서버가 다시 켜지면 테이블에 있던 칩(핸드 시작 기준)을 돌려줌.
- 리바인: 칩이 40BB보다 적고 지금 핸드에 걸려 있지 않을 때(칩을 다 잃었거나 폴드했거나 핸드가 끝난 뒤) [💰 리바인] → 40BB~200BB를 보유 칩에서 가져옴. 테이블 모두에게 가운데 알림·좌석 금빛 '리바인 +금액'·칩 날아오기·토스트로 보이고, 좌석 이름 아래 '리바인 N' 배지가 남음. 사람이 모두 칩을 잃으면 30초 동안 리바인을 기다린 뒤 끝냄. 칩 로그 종류 '리바인'.
- 관리자: `/admin`(비밀번호 = Railway 변수 `ADMIN_PASSWORD`). 승인 대기(가입·입장), 전체 회원(상태·보유·테이블 칩, 칩 ±, 칩 로그, 게임 로그, 강퇴, 차단, PIN 초기화, 메모, 삭제), 칩 로그, 게임 로그, 게임 방, 설정(가입 지급·바이인·최소 보유·자동 승인·차례 시간).
- 게임 로그(`/admin/api/hands?acct=|no=|days=`): 서버가 핸드마다 게임번호(`db.handSeq`)·시작 시각·방·블라인드·참가자(자리·D/SB/BB·카드·시작/끝 칩·손익·족보)·행동 순서(SB/BB/폴드/체크/콜/베팅/레이즈/올인, 금액은 그 스트리트 누적 '~까지', 핸드 시작 뒤 경과 초, 시간초과·폴드예약·타임뱅크 표시)·보드·팟 결과·수수료를 기록. 관리자 화면은 회원별/게임번호로 찾기, 줄 누르면 상세, TXT 저장.
- 저장: `DATA_DIR/db.json`(Railway 볼륨 `/data`).

## 분양(사업장)·수수료
- 사업장 = `db.tenants[id]` { name, slug, domains[], active, adminSalt/adminHash, settings(가입 지급·바이인·최소·자동 승인·테스트 PIN·rake), stats(rake, rakeDays) }. 본사 = `main`(기본 주소 `/`).
- 주소: 사업장 도메인(Host) → `/s/주소이름/…`(서버가 앞부분을 떼고 처리) → 본사. 화면은 `BASE`로 같은 사업장 API·웹소켓에 붙고, 로그인 정보도 `rh_sess:주소이름`으로 따로 저장.
- 분리: 회원(`a.tid`, 같은 닉네임 가능)·세션·칩 로그(`tid`)·방(`room.tid`, 다른 사업장은 방 코드로도 못 찾음)·토너먼트 순위(`daily['tid|날짜']`)·설정·수수료. 사업장 관리자 토큰은 자기 사업장만, 슈퍼 비밀번호(`ADMIN_PASSWORD`)는 모든 사업장 관리자 페이지에 들어갈 수 있음.
- 슈퍼 관리자(`/super`): 사업장 추가(이름·주소 이름·도메인·관리자 비밀번호·메모), 수정, 운영 중지/재개(중지하면 그 사업장 접속자 내보내고 칩 정산, 주소는 403), 사업장별 회원·접속·보유 칩·수수료(오늘/누적).
- 수수료: 사업장 설정 `rake` { on, nfnd(플랍 전 무료), solo, friends, levels[BB] = { pct, capBB } }, 기본 5% / 30BB. 엔진 `setRake({pct, cap, nfnd})` → 쇼다운·단독 승리 때 팟에서 떼고(메인팟부터, 무승부는 뗀 뒤 나눔, 따라오지 않은 베팅은 제외) `result.rake`. 서버는 사람이 이긴 몫에서 뗀 것만 사업장 수수료·회원 '낸 수수료'(`rakePaid`)로 집계(AI 칩은 진짜 칩이 아님). 오늘의 토너먼트는 무료. 관리자가 바꾸면 다음 핸드부터.
- 칩은 게임 안에서만 쓰는 칩(현금 충전·환전 기능 없음).

## 규칙 메모
- 9인 테이블(AI 8명). 일반 방은 블라인드 고정, 오늘의 토너먼트만 50/100에서 10핸드마다 오름. AI의 칩은 max(최소 머니, 100BB).
- 친구 대전: 방 코드 4자리·링크 초대, 최대 9명, 빈자리 AI(방장 선택), 끝나면 방장이 재대결.
- 차례 시간: 기본 15초(관리자 설정 `turnSec` 5~60초). 넘기면 체크/폴드, 그다음부터 자리비움(4초). 타임뱅크 +15초(차례마다 1번, 처음 3개, 20핸드마다 1개 다시 채움, 최대 3). AI 생각 0.6~1.4초, 핸드 끝 다음 핸드까지 쇼다운 4.2초·폴드 2초, 올인 카드 공개 1.2초 간격.
- 폴드 예약: 내 차례 전에 켜 두면 차례가 오는 즉시 폴드(체크할 수 있으면 체크하고 예약 유지). 직접 행동하거나 새 핸드면 꺼짐. 서버가 처리(`pre` 메시지, `p.preFold`).
- 내 차례 알림: 3음 차임·진동, 내 자리 금빛 파동, 테이블에 '내 차례!' 배지, 버튼 줄 반짝, 버튼 위 남은 시간 막대·초, 남은 5초부터 째깍 소리·빨간 막대·빨간 테두리, 다른 탭이면 제목 '🔔 내 차례!' 깜빡임.
- 오늘의 토너먼트: 씨앗 `daily:날짜(KST)` → 모두 같은 카드·같은 봇 판단, 30핸드 후 남은 칩이 점수, 하루 1회(토큰 기준), 중간에 나가면 그때 칩으로 기록.
- 서버가 판을 진행(서버 권위)하고, 남의 카드는 쇼다운·올인 전까지 보내지 않는다.
