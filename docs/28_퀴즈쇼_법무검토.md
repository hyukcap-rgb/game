# 28. 캠페인 "머리가 깨어나는 시간" · 이슈 퀴즈 법무 검토 (2026-10-18)

대표 지시: 마케팅 헤드라인 "여기서 게임하면 머리가 좋아진다" — 아이·어른 모두 여기 있는 시간은 두뇌를 맑게 한다.
이슈를 만들 퀴즈(쇼츠 10초 연예인 맞히기, 노래 맞히기, 춤으로 노래 맞히기, CM송, 상표 가린 과자·아이스크림)를 **법적으로 가능한 범위에서** 만든다.
10대는 연예인·인플루언서, 30대 이상은 추억(CM송·과자·아이스크림).

> 아래는 기획팀 검토이며 법률 자문이 아니다. 정식 출시·제휴 계약 전 변호사 검토를 받는다.

## 1. 헤드라인
| 문구 | 위험 | 판단 |
|---|---|---|
| 여기서 게임하면 머리가 좋아진다 | 효과 단정. 표시광고법상 사실 주장은 광고하는 쪽이 실증해야 함(제5조). 미국 FTC는 두뇌 훈련 앱의 "인지 능력 향상" 광고에 200만 달러 제재(2016, 루모시티). 아이 대상이면 더 엄격하게 봄 | 광고·스토어 문구로는 쓰지 않음 |
| **여기서 노는 시간, 머리가 깨어나는 시간** (채택) | "깨어난다"는 비유. 효과 수치·의학 표현 없음 | 메인 캠페인 |
| 아이도 어른도, 하루 10분 머리 쓰는 놀이 | 사실(머리를 쓰는 게임) | 보조 문구 |

- 금지: "IQ가 오른다", "치매 예방", "두뇌 발달", "성적 향상", 전문가·연구 인용(자료 없이).
- 연구로 실증 자료를 만들면(외부 기관 사용자 연구) 그때 효과 문구를 다시 검토.
- 26번 문서의 고정 헤드라인("하루 10분, 우리 동네 두뇌 1위에 도전")과 함께 쓴다: 캠페인 층 = 이 문구, 고정 층 = 26번.

## 2. 퀴즈별 판단
| 요청 | 걸리는 법 | 결론 |
|---|---|---|
| 노래 듣고 맞히기(가요) | 음원·멜로디 모두 저작권(작곡·작사 + 음반 제작자 권리). 우리가 다시 연주해도 멜로디 사용이라 한음저협 이용 허락 필요 | 가요는 넣지 않음. **저작권 끝난 곡**(사후 70년 지난 작곡가·외국 민요·Happy Birthday)만, 게임이 음표로 직접 연주 → 두뇌 퀴즈쇼 '멜로디' |
| 한국 동요 | 학교종·산토끼·곰 세 마리·반달·섬집 아기 등 작곡가 저작권 살아 있음. 아기상어는 분쟁 이력 | 넣지 않음 |
| CM송 맞히기 | CM송은 광고주·작곡가의 저작물. 가사 한 줄 인용도 위험, 광고 문구는 상표로 등록된 경우도 있음 | 무단으로는 불가. **브랜드 제휴 광고 상품**으로 판매(3절) |
| 상표 가린 과자·아이스크림 | 포장 디자인·로고 = 저작권·상표. 제품 이름을 정답으로 말하는 것은 상품을 가리키는 말일 뿐(상표적 사용 아님) | 포장·로고·사진 없이 **우리가 쓴 사실 힌트(나온 시기·모양·맛) + 우리가 그린 단순 모양**만. 회사 이름도 안 씀. "상표는 각 회사의 것 · 제휴 아님" 표기 → 두뇌 퀴즈쇼 '추억 간식' |
| 연예인·인플루언서 맞히기 | 초상·이름의 상업적 사용 = 퍼블리시티권(부정경쟁방지법 2조 1호 타목, 2022). 광고로 돈 버는 앱에서 사진·영상을 쓰면 위험. 사실 힌트도 정보가 자주 바뀌고 틀리면 명예훼손 소지 | 우리가 사진·영상을 올리지 않음. **10초 퀴즈**(사용자가 유튜브 공식 플레이어로 연결만) + 향후 소속사·채널 공식 제휴 |
| 쇼츠 10초 보고 맞히기 | 영상 내려받기·잘라 올리기 = 복제. 유튜브 공식 퍼가기 플레이어는 영상 주인이 퍼가기를 허락한 경우 허용. 플레이어를 가리거나 소리만 따로 트는 것은 유튜브 API 정책 위반 | 공식 플레이어(youtube-nocookie) 그대로, start·end 값으로 10초만. 덮개 없음, 퍼가기 막힌 영상(오류 101·150)은 안 틈 |
| 춤 보고 노래 맞히기 | 안무도 저작물(판례 있음). 우리 캐릭터로 따라 추게 만들면 복제 위험 | 직접 만들지 않음. 10초 퀴즈에서 공식 영상·챌린지 영상 연결만 |
| 그림(이모지) 속담 | 속담은 누구의 저작물도 아님 | 바로 사용 |
| 옛 인물 힌트 | 돌아가신 지 오래된 역사 인물. 퍼블리시티권 대상 아님 | 바로 사용(사진 없이 글 힌트) |

## 3. 만든 것 (2026-10-18)
### 3-1. 두뇌 퀴즈쇼 (`games/quiz`, 솔로·연습·대전 최대 4명)
- 4종 섞기: 🎵 멜로디(저작권 끝난 14곡, 직접 연주) · 🍦 상표 가린 추억 간식(18종, 30대 이상) · 🧩 그림 속담(14개) · 📜 옛 인물(14명).
- 문제마다 시간 막대, 간식·인물은 힌트가 1/3마다 하나씩 열림(힌트 적게 보고 맞힐수록 점수 큼).
- 오늘의 시험지(리그·상금 대상)에는 **넣지 않음**: 26번 결정(리그 = 4영역 8게임) 유지. 솔로·대전·캠페인 띠에서만.
- 문제 은행은 `games/quiz/quiz-bank.js` 한 파일. 새 문제는 1절·2절 기준을 지켜서 더함.

### 3-2. 10초 퀴즈 (`shorts/index.html`, 사이트 `…/game/shorts/`)
- 만들기: 유튜브 쇼츠·영상 주소 + 시작 초 + 질문 + 보기 4개(정답 표시), 최대 5문제 → 링크 하나.
- 퀴즈 종류 칩: 🌟 누구일까?(연예인·인플루언서) · 🎵 무슨 노래? · 🕺 무슨 춤? · ❓ 자유.
- 풀기: [▶ 10초 보기] → 공식 플레이어가 그 구간만 재생 → 끝나면 보기 열림 → 결과 자랑·나도 퀴즈 내기·하루퍼즐로.
- **퀴즈는 링크 주소 안에만** 담김(서버 저장 없음) → 게시물 보관·개인정보 수집 없음, 14세 미만도 가입 없이 사용.
- 신고 버튼(지금은 저장소 이슈 창, 출시 전 전용 메일로 교체), 신고된 영상 ID는 `BLOCK` 목록에 더해 막음.
- 만드는 사람 규칙 표시: 비하·성적 내용·사생활·아이가 나오는 영상 금지.
- 한계: 유튜브 플레이어 위쪽에 영상 제목·채널 이름이 보일 수 있음(가리면 정책 위반). 그래서 만드는 사람이 정답이 안 보이는 시작 초를 고르게 안내.

### 3-3. 사이트
- 오늘 화면 맨 아래 캠페인 띠: "여기서 노는 시간, 머리가 깨어나는 시간" + [두뇌 퀴즈쇼] [10초 퀴즈].
- 링크 미리보기(og:title)·검색 설명에 캠페인 문구.

## 4. 다음 단계(제안)
1. **브랜드 퀴즈 라운드 = 광고 상품.** 과자·아이스크림·음료 회사에 "추억의 CM송 맞히기", "상표 가리고 맞히기" 공식 라운드를 판매. 회사가 CM송·포장 사용을 허락하고 광고비를 냄 → 상금 풀에 들어감. 30대 이상 추억 + 광고 매출이 한 번에.
2. **공식 채널 제휴 10초 퀴즈.** 소속사·크리에이터에게 "우리 채널 쇼츠로 퀴즈" 제안(홍보가 되므로 수락 가능성 높음). 허락받은 영상만 운영팀 추천 목록에.
3. 연령별 묶음: 10대 = 10초 퀴즈(연예인·춤·챌린지) / 30대 이상 = 추억 간식·멜로디 → 세대 대결 이벤트("엄마 vs 딸 퀴즈").
4. 출시 전: 변호사에게 1절 문구·2절 표 확인, 신고 창구 메일 개설, 간식 힌트 사실 확인(나온 시기는 10년 단위로만 적어 둠).
