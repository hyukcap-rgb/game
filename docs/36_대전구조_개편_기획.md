# 36. 트럼프 고스톱 — 대전 구조 개편 (랭크 대전 · 친구 방 벌칙전)

> 2026-10-25 대표와 정한 방향을 기획팀이 정리한 문서예요. 코드는 아직 바꾸지 않았고, 구현은 개발팀이 이 문서를 보고 합니다(7절).
> 결정로그 `docs/16_결정로그_3부.md` 267~273, 게임 프롬프트 `games/tgostop/CLAUDE.md` 사용자 지시(2026-10-25)와 같은 내용이에요.

## 1. 왜 바꾸나

지금 실시간 대전은 **솔로에서 모은 골드를 걸고, 이긴 사람이 진 사람 골드를 가져가는**(상대 보유까지, 상한 없음) 구조예요. 방 코드로 친구와 바로 마주 앉을 수도 있어요(`tgostop.js` 방 이름 `o`).

- 이러면 **일부러 져서 골드를 넘겨주는 길**(칩 덤핑)이 열려 있어요. 골드가 다른 사람에게 넘어갈 수 있으면 바깥에서 현금으로 사고파는 시장(RMT)이 생기고, 그 순간 골드가 '현금으로 바꿀 수 있는 판돈'이 돼요. 미국 소셜 카지노 소송(Big Fish Casino 판결: 현금화가 안 되는 칩도 '가치 있는 것'), 한국 웹보드 게임 규제(게임머니 양도·환전 금지)가 모두 이 지점을 봐요.
- 지금은 골드가 각자 기기(localStorage)에만 저장되고 서버가 검증하지 않아서 실제 위험은 낮아요. 하지만 계획된 **서버 검증 골드·보유 골드 순위표(P2)** 로 가는 순간 골드가 진짜 자산이 돼요. 그 전에 구조를 바꿔 둬요.
- 몰입감은 돈에서 나오지 않아요. 스타크래프트처럼 **상대가 사람이고, 내 실력이 숫자(티어)로 남으면** 충분히 열광해요.

## 2. 지키는 원칙 (어떤 이유로도 바꾸지 않음)

1. **골드는 어떤 이유로도 돈으로 살 수 없다.** 골드를 직접 팔지 않는 것은 물론, 아래처럼 돈으로 골드를 더 얻거나 덜 잃게 하는 상품도 모두 금지:
   - 점수·정산 상한(E-3) 유료 해제
   - 무료 충전 금액·횟수 유료 상향, 골드를 매일 주는 유료 회원
   - 금고(보관) 유료화 — 금고를 넣는다면 **무료 기본 기능**
   - 충전권 판매, 확률형(가챠) 상품
2. **골드는 플레이로만 얻고, 그 계정 안에서만 존재하며, 밖으로 나갈 길이 없다.** 거래·선물·Steam 인벤토리 아이템화 금지.
3. **사람끼리 하는 대전에서는 어떤 재화도 상대에게 넘어가지 않는다.**
4. 돈은 **게임 판매($4.99) + 꾸미기·확장 DLC**로만 번다(판 결과와 무관한 것만).

## 3. 재화 두 가지로 나누기

| 재화 | 어디서 | 얻는 법 | 잃는 법 | 쓰는 곳 |
|---|---|---|---|---|
| **골드(G)** | 솔로 스테이지 · 컴퓨터 판 **전용** | 컴퓨터를 이겨서, 출석·업적·첫 클리어 | 컴퓨터에게 져서, 나가기 벌점 | 컴퓨터 판 입장(초급·중급·고급), 칭호 |
| **레벨 포인트(LP)** | 랭크 대전 **전용** | 랭크 대전 승리 상금 | 랭크 대전 패배(조금) | 티어 표시 · 시즌 보상(꾸미기)만 |

- 골드와 LP는 **서로 바꿀 수 없어요.** LP로 골드·아이템·해금을 살 수 없어요.
- 지금 있는 솔로·컴퓨터 판 경제(E-3 상한·E-4·E-5·충전권·출석)는 **그대로** 둬요.

## 4. 랭크 대전 (무작위 매칭 · 누적 목표 경주)

### 4-1. 방식
```
매칭 → 상금(LP) 제시(예: 300 LP)
여러 판을 이어서 친다 → 판마다 얻은 점수를 누적
누적 목표(예: 30점)에 먼저 닿은 사람이 상금을 받는다
```
- 한 판 대박보다 **목표까지의 경주**라서 고/스톱 판단에 전략이 생겨요("앞서 있으니 스톱으로 굳힐까, 뒤졌으니 고로 뒤집을까").
- 고박·피박·광박 같은 배수는 그 판 점수에 그대로 반영돼 누적 점수를 크게 흔들어요 → 고스톱 본연의 긴장감 유지.

### 4-2. 일부러 져주기를 막는 세 조건
| 조건 | 내용 | 왜 |
|---|---|---|
| ① 상대를 고를 수 없다 | 상금이 걸린 대전은 **무작위 매칭만**. 방 코드·친구 초대로는 랭크 대전을 못 함 | 넘겨줄 상대를 지정할 수 없음 |
| ② 1:1로 옮겨지지 않는다 | 상금은 **시스템이 줌**(진 사람 몫이 아님). 진 사람은 **조금 잃고 그 몫은 사라짐**(예: +300 / −100) | 져주는 쪽은 손해만, 받는 쪽도 정해진 만큼만 |
| ③ LP는 쓸 데가 없다 | 티어·시즌 보상(꾸미기)에만 씀 | 부풀려도 실익이 적음 |

- 상금은 **실력 차로 조정**(MMR): 강한 상대를 이기면 더, 약한 상대를 이기면 덜. 지는 쪽도 강한 상대에게 지면 덜 잃음. 약자만 골라 사냥하는 걸 막아요.
- 그래도 남는 '대리 랭크'는 롤·발로란트에도 있는 공정성 문제예요 — 같은 상대 반복 매칭 제한, 이상한 승패 패턴 신고·제재로 관리.

### 4-3. 진 쪽 손실과 긴장감
- 패배 −LP는 상금보다 작게(예: 1/3), 티어 경계 아래로 떨어지면 강등.
- 연승 보너스(연승이 끊기는 것도 손실), 시즌 끝 티어별 한정 꾸미기·칭호.
- 판 도중 나가기 = 패배 처리 + 추가 −LP(지금 점당 ×10 골드 벌점 대신).

## 5. 친구 방 (친선전 · 벌칙전)

### 5-1. 기본
- 방 코드·친구 초대로 만든 방은 **골드·LP 변동 없음**.
- 대신 **체면과 벌칙**을 걸어요. 실제 친구끼리 고스톱 칠 때의 딱밤·내기 분위기를 화면 안에서 살려요.
- 방장이 판 시작 전에 벌칙을 고르고 **상대가 수락해야** 시작.

### 5-2. 진 사람 벌칙 (정해진 목록에서만 고름)
| 벌칙 | 내용 | 기기 |
|---|---|---|
| 딱밤 | 이긴 사람이 눌러 세기를 정하고, 진 사람 캐릭터가 이마를 맞는 연출 | 모두 |
| 얼굴 낙서 | 이긴 사람이 진 사람 캐릭터에 스티커·낙서, 다음 판 내내 보임 | 모두 |
| 굴욕 칭호 | 친구 목록에 24시간 "오늘의 호구" · "피박 전문" 같은 칭호 | 모두 |
| 벌칙 미니게임 | 10초 안에 패 10장 뒤집기 같은 짧은 연타(단순 연타 대신 재미있게) | 모두 |
| 10걸음 걷기 | 휴대폰 걸음 센서로 10걸음 | **휴대폰만 · 둘 다 동의할 때만 · 언제든 건너뛰기** |

### 5-3. 이긴 사람 혜택
- **맞대결 전적판**: "철수 vs 영희 12승 8패"처럼 친구별 전적이 계속 쌓임(가장 강한 동기).
- **도발 이모트**: 승리 포즈·한마디("아싸 고도리~").
- **연승 왕관**: 같은 친구에게 연승 중이면 표시.

### 5-4. 지킬 것
1. 벌칙은 **게임 화면 안에서 끝난다.** "진 사람이 커피 사기"처럼 현실 돈·물건이 걸린 내기를 게임이 걸게 하지 않는다.
2. 몸을 움직이는 벌칙은 **기본값이 아니다.** Steam PC·스팀 덱에는 걸음 센서가 없고, 걷기가 어려운 사람에게 장벽이 되고, 화면을 보며 걷다 다칠 수 있다.
3. 낙서·칭호는 **정해진 목록만**(직접 입력 금지 — 욕설·괴롭힘 방지).
4. 스토어 문구 예: *"Play with friends — loser gets flicked!"*

## 8. 아직 정할 것

1. **누적 목표 점수**(예: 30점)와 **상금 규모**(예: +300 / −100 LP) — `tools/tgostop-sim.js`로 평균 대전 시간(목표 10~15분 안팎)을 보고 기획팀이 추천.
2. **왕 판**(점당 5,000 G, 지금 실시간 대전 전용) — 대전에서 골드가 빠지면 없앨지, 컴퓨터 판 최상위로 옮길지.
3. **웹(하루퍼즐) 대전과 짝짓기**(결정로그 258: 매칭은 함께) — 스팀만 랭크 대전으로 바꾸면 웹 골드 대전과 짝이 안 맞음. 매칭을 나눌지, 웹도 같이 바꿀지.
4. 시즌 길이, 티어 이름(영어 포함), 시즌 보상 목록.
5. 벌칙 연출 그림·소리(디자인팀·효과팀), 걸음 센서 옵션을 1차에 넣을지.
