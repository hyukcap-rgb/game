# 30. 트럼프 고스톱 스팀 출시 준비

2026-10-21 · 대상: `games/tgostop` · 앱: `steam/`

## 1. 지금 상태
- **PC 앱 완성(1단계)**: `steam/`에서 `npm start`로 1600×900 창 실행 확인. 솔로 판까지 정상(앱 안 글꼴, 인터넷 없이도 솔로 가능). 대전은 웹과 같은 서버라 웹 사용자와도 매칭.
- **스팀 연결**: steamworks.js로 업적 10개(첫 승리·10승·50승·200승·5연승·스테이지 10/30·첫 대전·대전 10승·100판). 스팀이 꺼져 있어도 게임은 돎.
- **빌드·업로드 설정**: Windows 빌드(`npm run dist:win`), SteamPipe 업로드 설정(`steam/upload`).

## 3. 영어 화면(필수에 가까움)
- 지금 게임 글자는 전부 한국어. 스팀 이용자 대부분은 해외 → 영어가 없으면 '지원 언어: 한국어'만 표시되어 판매가 크게 줄어듦.
- 할 일: `games/tgostop`의 화면 글자·도움말·결과 문구를 `T('키')` 사전으로 빼고 ko/en 두 벌. 앱은 `app.getLocale()`(또는 스팀 언어)로 고름. 용어는 영어 설명서(`guide.html`)와 맞춤(Go / Stop / Ppeok / Ttadak…).
- 성우 대사(한국어)는 그대로 두되 영어 자막.
- 웹 버전에도 그대로 쓰여 이득. (고스톱 `games/gostop`과 같이 바꿔야 하는 규칙 → 두 게임 함께)

## 4. PC용 첫 화면
- 지금: 모바일 첫 화면(세로 카드 3개)이 1600×900 창 가운데 작게 → 빈 공간이 큼.
- 바꿀 것: 왼쪽 큰 로고·카드 그림(J·Q·K 인물), 오른쪽 큰 버튼(솔로·대전·게임 방법·설정·나가기), 아래 버전·크레딧. 창 크기에 맞춰 커짐. 마우스 오버 효과·키보드(Enter/Esc) 지원.
- 방식: 게임 정의에 '데스크톱 첫 화면' 선택 항목(앱이 `?mode=menu&desktop=1`로 열 때만) — core/shell에 게임 이름 분기 없이.

## 7. 가격·판매
- 단품 4.99달러(₩5,500) 권장, 출시 할인 20%. **게임 안에서 돈으로 사는 것 없음**(포인트는 판매하지 않음) → 국내 고스톱·포커류 결제 한도 규제와 무관하게 유지.
- 무료 데모(선택): 솔로 스테이지 1~5만 → 찜 목록·리뷰 늘리기.
- 웹(하루퍼즐) 버전은 그대로 무료 — 스토어 링크를 게임 방법 화면에 넣어 유입.

## 8. 등급·법
- 스팀 콘텐츠 설문: '도박 묘사(실제 돈 없음)' 체크, 19세 확인 화면 유지.
- **한국 판매**: 국내 등급분류(게임물관리위원회) 필요 — 고스톱·포커류는 청소년이용불가 가능성이 큼. 등급을 받기 전에는 **한국 지역을 판매 제외**로 두고 해외 먼저 출시할 수 있음. (전문가 확인 권장)
- 그림: 카드·인물·메달·캐릭터는 모두 직접 만든 원본, 글꼴은 OFL(앱 안 `fonts/*/LICENSE.txt`). 화투 그림(Commons, CC BY-SA)은 이 앱에 들어가지 않음.
