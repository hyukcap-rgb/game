# 20. 순발력 게임 5종 기획서 (기획팀 · 2026-10-05)

사용자 요청: "레벨이 가능한 순발력 게임 5가지. 대전도 흥미롭고 솔로도 계속 접속하게. 기획팀은 레벨별 차별화를 세밀하게, 디자인팀은 글로벌 게임 수준, UI팀은 버튼 배치와 난이도별 재미, 효과팀은 이펙트·사운드를 정확하게."

사용자가 정한 원칙
1. **순발력 = 판단이 빠른 것.** 무조건 빨리 누르는 게임이 아니다. 막 누르면 손해, 침착하게 바로 판단하면 이긴다.
2. **소리가 없어도 똑같이 할 수 있다.** 모든 명령·신호는 글자 + 그림으로 화면에 나온다. 소리(목소리·효과음)는 덤이다. 소리 끈 사람이 불리하면 안 된다.
3. 추억·인기: 30대 이상 한국 이용자가 바로 아는 놀이(청기백기·두더지·가위바위보).

## 0. 다섯 게임

| id | 이름 | 한 줄 | 판단 포인트 |
|---|---|---|---|
| `flag` | 청기 백기 | 진행자 명령대로 파란 깃발·흰 깃발을 올리고 내린다 | "~하지 마"·이미 올라간 깃발 = **가만히** |
| `mole` | 두더지 땅땅 | 구멍에서 튀어나오는 두더지만 친다 | 폭탄 두더지는 **치면 안 됨** |
| `twin` | 쌍둥이 찾기 | 두 카드에 딱 하나 같은 그림을 찾아 누른다 | 닮은꼴 함정 |
| `arrow` | 거꾸로 화살표 | 파란 화살표는 그 방향, 빨간 화살표는 반대로 민다 | 색 규칙 전환 |
| `rps` | 가위바위보 지령 | 상대 손과 지령(이겨라·져라·비겨라)에 맞는 손을 낸다 | 지령이 바뀔 때 거꾸로 생각 |

능력 이름(`abil`)은 다섯 게임 모두 **'순발력'**(새 과목). 사이트 솔로·대전 목록 필터에 '순발' 칩을 더한다. 오늘의 시험지 과목(`SUBJ`)에는 아직 넣지 않는다(사용자에게 확인 후).

## 1. 공통 판 구조 (다섯 게임 같음)

- 한 판 = **문제 N개**(명령·카드·두더지 물결). 시간 대신 개수로 끝나서, 같은 씨앗이면 모두 정확히 같은 문제를 같은 순서로 받는다.
- 문제마다 **판단 시간(창)** 이 있다. 창 안에 맞게 하면 정답, 틀리게 하면 바로 오답, 창이 끝날 때까지 안 하면 → "가만히가 정답"인 문제는 정답, 아니면 시간 초과 오답.
- **기회 3개**(공용 `.hlives` 별, 하트 아님). 오답마다 1개. 0이면 실패(`finish(false)`). N개를 다 하면 성공.
- 막 누르기 방지: 문제가 없는 순간·이미 판정된 뒤 누른 것은 무시하지만, 0.25초 안에 3번 넘게 마구 누르면 "천천히!" 표시와 0.5초 잠금(벌점 없음). 두더지는 빈 구멍 누르기 = 작은 감점 + 0.4초 멍.
- 다음 문제까지 간격 0.35~0.6초(판정 연출 시간). 이 간격은 판단 시간에 안 들어간다.

### 점수 (배율 전 최대 1,000, 엔진이 난이도 배율을 곱함)
- `base` = 500 × 정답 수 / N
- `time` = 350 × (정답 문제들의 평균 "남은 창 비율"). 단 **"가만히가 정답"인 문제는 빠르기 점수를 1.0으로 계산**(참은 것도 실력). 빨리 막 누르는 사람이 이기지 못하게 오답은 0으로 평균에 넣는다.
- `extra` = 50 × 남은 기회 (최대 150)
- 결과 줄: `['정답 a/N', '판단 속도 보너스 (평균 0.xx초)', '남은 기회 n개']`
- 별(솔로): 오답 0 → ★★★, 1 → ★★, 그 외 ★

### 난이도(오늘의 문제·연습·대전) 공통 틀
| | easy | normal | hard |
|---|---|---|---|
| 문제 수 N | 20 | 25 | 30 |
| 판단 창 시작 → 끝(점점 짧아짐) | 2.6 → 2.0초 | 2.2 → 1.5초 | 1.9 → 1.2초 |
| 함정 비율 | 15% | 25% | 35% |
게임별로 숫자는 조정 가능(아래). 같은 판 안에서 뒤로 갈수록 창이 선형으로 짧아지고 함정이 늘어난다(한 판 안의 긴장 곡선).

### 솔로 스테이지 공통 (엔진 `planOf(id, n)` 개념 사이클)
- 챕터 = 10판. 자리 k: 1 새 규칙 소개(쉬움) · 2~3 익히기 · 4 이전 규칙과 섞기 · 5 어려움 · 6 변주 소개(쉬움) · 7~8 규칙+변주 · 9 쉬어가기 · 10 보스.
- 새 규칙 4개(`concepts.order`)는 11·21·31·41판, 변주(`twists`)는 6·16·26·36·46판. 51부터 리믹스.
- 문제 수: 챕터 1은 12개에서 시작해 18개까지, 챕터마다 +2(최대 32). 보스는 +6.
- 판단 창: 챕터마다 약 6%씩 짧아짐(최저: 게임별 바닥값, 사람이 판단 가능한 0.9초 근처). k=5 ×0.9, 보스 ×0.85, 쉬어가기 ×1.15.
- 함정 비율: 챕터 1 10%→ 챕터 5 40% 근처, 보스 +10%p.
- **챕터 진행자**(솔로가 계속 오고 싶게): 챕터마다 진행자 캐릭터가 바뀐다(공용 캐릭터 12종 중, 게임별로 정해 둠). 진행자가 바뀌면 말투·색·배경이 바뀌어 "다음 챕터엔 누가 나올까" 기대를 만든다. 보스 판은 진행자가 'wow' 표정 + 붉은 배경 띠 + "보스!" 연출.
- 판 안 **콤보**: 연속 정답 5·10·20에서 "좋아요!/대단해요!/완벽해요!" (점수엔 영향 없음, 공정성).
- 개인 기록: 판이 끝나면 "평균 판단 속도 0.62초 · 내 최고 0.58초"를 보여 준다(게임별 `store` 저장). 다시 하고 싶게 만드는 장치.

### 대전 (엔진 기본 대전)
- 같은 씨앗·normal 설정으로 두 사람이 같은 문제를 동시에 푼다. 끝났을 때 점수가 높은 쪽 승.
- `duelStat = { unit:'개', lfMax:3, get:() => ({ v:정답 수, t:N, lf:남은 기회 }) }` → 상대 진행 막대·기회 점.
- `duelPace = [평균 초, 성공률]`: flag [55,.75] · mole [50,.8] · twin [60,.78] · arrow [50,.75] · rps [55,.75] (첫 값, N=25 기준).
- 대전이 흥미로운 이유: 문제 수가 같아서 "지금 누가 앞서나"가 막대에 바로 보이고, 함정에서 역전이 난다(상대 실수 알림은 엔진이 띄움).

## 2. 게임별 설계

### 2-1. 청기 백기 (`flag`)
- 화면: 가운데 진행자(챕터 캐릭터)가 깃발 두 개(왼손 파랑, 오른손 흰색)를 들고 서 있다. 진행자 위 말풍선에 명령 글자 + 그림 기호(파란/흰 깃발 아이콘, ↑↓ 화살표, "하지 마"는 빨간 ✕ 도장). 아래쪽에 **내 깃발 상태**를 보여 주는 내 캐릭터(여우)가 두 깃발을 들고, 내 입력대로 깃발이 올라가고 내려간다.
- 조작: 엄지 자리에 큰 버튼 4개(2×2): 왼쪽 열 파랑 ▲ / 파랑 ▼, 오른쪽 열 흰 ▲ / 흰 ▼. 키보드 Q/A(파랑 올려/내려), P/L(흰 올려/내려), 또는 ←↑/←↓ 대체. 화면 왼쪽 절반 위로 밀기 = 파랑 올려 같은 스와이프도 지원.
- 판정: 명령이 원하는 최종 상태(파랑·흰 각각 위/아래)를 정한다. 내 상태가 목표와 같아지면 즉시 정답(빠르기 점수). 목표와 다른 쪽으로 바꾸면 즉시 오답. 이미 목표 상태인 명령("청기 올려"인데 이미 올라가 있음) 또는 "하지 마" = 아무것도 안 누르고 창이 끝나면 정답.
- 문제 만들기(rng): 깃발 상태를 따라가며 명령을 만든다. 함정 = 이미 그 상태인 명령, "하지 마", (챕터 규칙) 섞기.
- 소리: 목소리는 Web Speech(`speechSynthesis`, ko-KR)가 있고 소리가 켜져 있으면 명령을 읽어 준다(없으면 생략). **판단 창은 글자가 화면에 뜬 순간부터** 센다. 효과음: 명령 등장 "띵", 깃발 휙, 정답 맑은 음, 오답 낮은 버저.
- 개념(솔로): `order: ['neg', 'both', 'third', 'flip']`
  - `neg` 하지 마: "청기 올리지 마" 명령 등장(가만히가 정답).
  - `both` 두 개 한꺼번에: "청기 올리고 백기 내려" (두 깃발 모두 맞아야 정답, 순서 상관없음).
  - `third` 노란 깃발: 진행자 머리에 노란 깃발 추가(가운데 열 버튼 2개 추가 → 버튼 3×2).
  - `flip` 반대로!: 진행자가 "반대로!" 카드를 들면 그다음 명령부터 다시 "그대로!"가 나올 때까지 올려↔내려가 반대. 화면 테두리 색이 보라로 바뀌어 지금 반대 상태임을 보여 준다.
  - 변주 `twists: ['flash', 'mimic', 'tight']` — `mimic` 흉내쟁이: 가끔 진행자 대신 너구리 같은 다른 캐릭터가 명령한다. **진행자 명령만** 따른다(흉내쟁이 명령 = 가만히).
- 챕터 이름: 운동회 마당 · 깃발 학교 · 바람 언덕 · 반대 나라 · 깃발 왕국 / 진행자: fox, rabbit, bear, panda, tiger.

### 2-2. 두더지 땅땅 (`mole`)
- 화면: 잔디 판에 구멍 3×3(챕터 3부터 4×3, 보스 4×4). 두더지가 구멍에서 쏙 올라왔다 내려간다. 위에 HUD(잡은 수/목표, 기회 별).
- 문제 = "물결"(동시에 1~3마리 등장). 물결마다 판단 창 = 두더지가 나와 있는 시간. 각 두더지를 따로 판정한다(정답 수는 두더지 단위, N은 두더지 총 수).
  - 일반 두더지: 창 안에 치면 정답, 놓치면 오답이 **아님**(놓침 = 점수만 없음, 기회 안 줄어듦).
  - 폭탄 두더지(머리에 폭탄): 치면 오답(기회 −1, 폭발 연출). 안 치고 들어가면 "참았다" 정답.
  - 빈 구멍 누르기: −5점(점수 표시용), 0.4초 망치 멍(누를 수 없음).
- 점수 공통식에서 정답 수 = (친 일반 두더지 + 참은 폭탄 두더지). 실패 = 기회 0 또는 정답률이 목표(쉬움 60% · 보통 65% · 어려움 70%)에 못 미치고 끝남.
- 개념: `order: ['helmet', 'gold', 'order', 'hide']`
  - `helmet` 헬멧 두더지: 두 번 쳐야 쓰러짐(한 번 치면 헬멧이 날아감).
  - `gold` 황금 두더지: 아주 짧게 나옴, 잡으면 정답 2개로 계산 + 반짝 연출.
  - `order` 번호 두더지: 1·2·3 번호표를 단 두더지가 동시에 나오면 번호 순서대로 쳐야 한다(순서 틀리면 오답).
  - `hide` 숨바꼭질: 두더지가 한 번 쏙 들어갔다 옆 구멍에서 다시 나온다(첫 등장 때 치면 빗나감).
  - 변주 `twists: ['flash', 'dark', 'tight']` — `dark` 밤의 들판: 판이 어두워지고 두더지가 나올 때만 구멍에 불이 켜진다.
- 챕터 이름: 앞마당 · 당근 밭 · 달빛 들판 · 두더지 마을 · 땅속 왕국 / 진행자(판 옆 심판): frog, chick, owl, bear, dog. 두더지 그림은 이 게임 전용으로 공용 캐릭터 질감(3D 비닐 장난감)에 맞춰 직접 그린다.

### 2-3. 쌍둥이 찾기 (`twin`)
- 화면: 위·아래 두 장의 둥근 카드. 카드마다 그림 k개(쉬움 5, 보통 6, 어려움 7, 솔로 4→8)가 흩어져 있다. 두 카드에 **딱 하나** 공통 그림이 있다. 어느 카드에서 눌러도 된다.
- 그림 풀: 공용 캐릭터 12종 + 이 게임용 오리지널 사물 아이콘(최소 24종: 사과·별·달·우산·열쇠·컵…, 공용 3D 질감에 맞춤). 카드 만들기는 rng: 공통 그림 1개 + 나머지는 겹치지 않게 뽑기(한 장 안에서도 중복 없음).
- 판정: 맞으면 두 카드의 그 그림이 함께 반짝 → 다음 카드가 날아 들어옴. 틀리면 오답 + 그 그림에 빨간 ✕ + 0.5초 잠금.
- 판단 창: 쉬움 6→4.5초, 보통 5→3.5초, 어려움 4.2→3초(그림 찾기라 다른 게임보다 길다).
- 개념: `order: ['spin', 'size', 'look', 'three']`
  - `spin` 빙글: 그림들이 제각각 돌아가 있다.
  - `size` 크고 작게: 그림 크기가 0.6~1.4배로 제각각.
  - `look` 닮은꼴: 같은 그림의 색만 다른 가짜(예: 파란 고래 vs 초록 고래)가 섞인다(색까지 같아야 정답).
  - `three` 세 장: 카드 3장, 세 장 모두에 있는 그림 하나를 찾는다.
  - 변주 `twists: ['flash', 'blink', 'tight']` — `blink` 깜빡: 카드가 0.6초 보였다 0.3초 덮였다를 반복.
- 챕터 이름: 장난감 상자 · 소풍 바구니 · 별빛 서랍 · 거울 방 · 쌍둥이 성 / 진행자: owl, cat, rabbit, panda, fox.

### 2-4. 거꾸로 화살표 (`arrow`)
- 화면: 가운데 큰 원판 위에 화살표 하나가 "툭" 나타난다. 화살표 색이 규칙: **파랑 = 그 방향, 빨강 = 반대 방향.** 색맹 배려로 빨강 화살표에는 꼬리에 ↺ 무늬(반대 표시)를 같이 그린다.
- 조작: 화면 어디서든 상하좌우로 밀기(스와이프 24px). 밀기 어려운 사람용 아래쪽 십자 버튼(↑←→↓, 큰 버튼)도 있음. 키보드 화살표·WASD.
- 판정: 맞는 방향 = 정답, 다른 방향 = 오답, 창이 끝나면 시간 초과 오답(가만히가 정답인 문제는 `stop` 규칙에서만).
- 개념: `order: ['side', 'word', 'stop', 'pair']`
  - `side` 엉뚱한 자리: 화살표가 원판 가운데가 아니라 가장자리(위·아래·왼·오)에 나온다. 위치가 아니라 **화살표 방향**을 따른다(위치 함정).
  - `word` 글자 화살표: 화살표 대신 "왼쪽" 같은 글자가 나온다. 노란 글자 = 글자 뜻대로, 글자가 화살표 모양 안에 있으면 모양 말고 **글자**를 따른다.
  - `stop` 정지 표지: 회색 화살표 = 밀지 말고 가만히(정답).
  - `pair` 두 개 중 하나: 화살표 두 개가 동시에 나오고, 테두리가 빛나는 쪽만 따른다.
  - 변주 `twists: ['flash', 'ghost', 'tight']` — `ghost` 순간: 화살표가 0.35초만 보이고 사라진다(판단 창은 그대로).
- 챕터 이름: 표지판 길 · 미로 정원 · 거울 터널 · 바람개비 언덕 · 나침반 탑 / 진행자: whale, frog, tiger, owl, fox.

### 2-5. 가위바위보 지령 (`rps`)
- 화면: 위쪽 상대 캐릭터(챕터 진행자)가 손 그림(가위·바위·보, 큰 3D 손 아이콘)을 내민다. 그 아래 **지령 판**: "이겨라"(초록) · "져라"(빨강) · "비겨라"(노랑) 글자 + 그림 기호(왕관·눈물·악수). 아래 엄지 자리에 내 손 버튼 3개(가위·바위·보, 큰 그림 + 글자).
- 판정: 맞는 손 = 정답, 다른 손 = 오답, 시간 초과 = 오답.
- 개념: `order: ['hide', 'not', 'two', 'last']`
  - `hide` 그림 지령: 지령 글자가 사라지고 그림 기호(왕관/눈물/악수)만 나온다.
  - `not` 하지 마라: "이기지 마라" → 지거나 비기면 정답(두 손 다 정답), "지지 마라" 등.
  - `two` 두 손: 상대가 두 손을 내밀고, 지령 판의 화살표가 가리키는 손을 기준으로 한다.
  - `last` 기억 지령: 지령 대신 "아까처럼!" → 바로 앞 문제의 지령을 기억해서 적용.
  - 변주 `twists: ['flash', 'swap', 'tight']` — `swap` 자리 바꾸기: 내 손 버튼 3개의 순서가 문제마다 섞인다.
- 챕터 이름: 골목 대결 · 운동장 · 놀이공원 · 지령 본부 · 가위바위보 왕좌 / 진행자: dog, cat, bear, rabbit, tiger. 손 그림은 오리지널(공용 3D 질감, 둥근 장갑 손).

## 3. UI팀 규칙 (다섯 게임 공통)
- 공용 규격: `.hud-row` > `.hchip`(① 진행 "a/N" ② 남은 창 막대는 판 위쪽 전용 막대 ③ 콤보 ④ 없음), 기회 `.hlives` 별, 도구 `.tools-row > .tool`. 핑크 사탕 버튼은 화면당 주 행동 1개만(이 게임들은 큰 조작 버튼이 주인공이므로 조작 버튼은 게임 전용 큰 버튼 스타일).
- 조작 버튼은 **엄지 자리(화면 아래 40%)**, 버튼 최소 64px, 버튼 사이 간격 10px 이상. 명령·신호는 **화면 위 1/3 ~ 가운데**, 눈과 엄지가 동시에 쓰이게.
- 판단 창 막대: 명령 바로 아래 가로 막대가 줄어든다(초록 → 노랑 → 빨강). 남은 0.4초부터 막대가 떨린다.
- 판정 피드백 0.1초 안: 정답 = 버튼이 눌린 모양 + 초록 체크 도장 + 위로 "+점수"; 오답 = 빨간 ✕ 도장 + 화면 가장자리 붉게 + 짧은 흔들림(동작 줄이기 켜짐이면 흔들림 없음).
- 글자 크기: 명령 글자 최소 26px(Jua), 버튼 글자 18px 이상. 본문 15px, 보조 13px.
- 첫 판(도움말)은 3단계 그림 카드. 새 규칙이 열리는 판은 엔진의 규칙 카드(`concepts.info`)를 쓴다.
- 390×844, 360×740에서 스크롤 없이 한 화면에 들어가야 한다.

## 4. 디자인팀 규칙
- 공용 캐릭터(`toyImg/toyImage`, 3D 비닐 장난감 질감)와 같은 질감으로 게임 전용 그림(깃발·두더지·손·화살표·사물 아이콘)을 그린다: 외곽선 없음, 색 하나 + 큰 실루엣, 위 하이라이트·아래 그늘·바닥 그림자. 엔진 `TOY` 라이브러리의 필터(`TOY.DEFS`, `TOY.GL`, `TOY.SH`, `TOY.EYE`)를 재사용해도 된다.
- 게임마다 배경 세계 하나: 청기백기 = 운동회 마당(하늘·만국기), 두더지 = 잔디 들판, 쌍둥이 = 장난감 방 책상, 화살표 = 밤 도로 표지판(네온), 가위바위보 = 놀이터 노을. 배경은 차분하게(눈 피로 줄이기, 체크무늬·강한 대비 금지), 판·조작 버튼이 주인공.
- 글로벌 수준 = 동작이 부드럽고(60fps, transform만), 등장·퇴장에 탄성, 캐릭터 표정 변화(정답 'joy', 오답 'sad', 보스 'wow'), 그림자·하이라이트 일관.
- 상용 게임 이름·그림 금지. 손 모양·깃발·두더지 모두 직접 그린 오리지널.

## 5. 효과팀 규칙
- 효과는 보이기만(게임 상태·rng·시계·대전 통신 변경 금지), `try{}catch(_){}`, 눌림 막지 않기(`pointer-events:none`).
- 정답: 작은 반짝(fxEmit twinkle 8~12개) + 맑은 음(콤보가 오를수록 5음계로 높아짐). 오답: 버저 + 빨간 번쩍(fxFlash 약하게) + 흔들림. 폭탄: 폭발(shard·smoke) + 쿵. 콤보 5·10·20: fxPunch + 팡파르 조각.
- 소리는 Web Audio 합성(`sounds`에 `<id>` 접두 이름). 목소리(청기백기)는 speechSynthesis가 있고 소리가 켜졌을 때만, 없으면 조용히 넘어감.
- 동작 줄이기(`FXR.reduce`)면 흔들림·파티클 생략, 색 표시만.
