# 하루퍼즐 리그 결정 로그

새 결정이 생기면 맨 아래에 한 줄씩 추가한다. 기획서와 충돌하면 이 로그가 우선한다.

기록일: 2026-09-26

1. 컨셉: Meowdoku와 비슷한 플레이 + 여러 게임 일일 합산 점수 + 애니팡식 하트와 친구 네트워크.
2. 첫 버전은 웹 프로토타입(HTML 파일 1개)으로 만든다.
3. 게임은 여우 자리 찾기와 스도쿠 2종으로 시작한다.
4. 난이도는 쉬움·보통·어려움 3단계, 점수 배율 ×0.6 / ×1.0 / ×1.4. (구슬 블록깨기는 22번의 스테이지 방식으로 대체)
5. 스도쿠는 9×9로 하고, 유튜브 영상 속 스도쿠 앱 UI를 기준으로 한다. 핵심은 메모(예비 숫자).
6. 폰 세로 화면에서는 스도쿠 숫자 패드를 1~9 한 줄로 둔다.
7. 모든 줄 높이는 빈칸 여부와 상관없이 같게 한다.
8. 실수(발바닥, 스도쿠 실수)는 판당 3번까지.
9. Claude 프로젝트를 만들어 기획서·결정 로그·레퍼런스·최신 HTML을 프로젝트 지식으로 관리한다.
10. (2026-09-25) 세 번째 게임 "구슬 블록깨기"를 추가한다. 레퍼런스는 사용자가 보낸 벽돌깨기 퀘스트 앱 스크린샷(스테이지 맵, 게임 화면, 일시정지 메뉴, 상점 2장). 원칙: 플레이와 화면은 레퍼런스와 똑같이 만든다.
11. 구슬 블록깨기 플레이는 레퍼런스와 같게: 9칸 너비 검은 판, 네온 테두리 블록(HP 비율로 보라>빨강>분홍>주황>초록), 세모(직각삼각형) 블록, 점선 고리 = 다음 턴 구슬 +1, 조준 점선, 상단 좌측 빠르게·우측 일시정지 원형 버튼, 스테이지 진행 바와 별 3개, "라인"(남은 줄) 표시, 하단 빨간 구슬 회수 버튼과 되돌리기 버튼. 블록이 바닥에 닿으면 실패.
12. 레퍼런스에서 가져오지 않은 것: 앱 이름·로고, 보석 상점·유료 결제·공 스킨, 강제 광고(우리 차별점은 강제 광고 없음). 되돌리기는 보석 대신 판당 1회 무료.
13. 구슬 블록깨기 점수: 클리어 500 + 턴 보너스(최대 350, 최소 턴 초과 1턴당 -35) + 되돌리기 안 쓰면 150, 여기에 스테이지 배율. 실패 0점. 시작 구슬 3개, 블록 HP = 라인 번호. 바닥 직전까지 내려온 고리는 자동 획득.
14. 구슬 블록깨기 조준은 레퍼런스처럼 하단 조준 슬라이더로 한다(판 터치 조준도 유지). 손잡이를 좌우로 끌면 각도가 미세하게 바뀌고(트랙 전체 폭 = 약 70% 각도 범위), 손을 떼면 발사. (하단 배치는 24번으로 갱신)
15. 조준 슬라이더는 매 턴 가운데(정면 위)에서 시작한다. 마지막 각도를 기억하지 않는다.
16. 화면 비율은 레퍼런스 스크린샷과 같게 맞춘다: 판 가로:세로 약 1:1.27(9칸 × 11줄 + 바닥), 블록 사이 간격 좁게, 구슬 개수(×N)는 발사 위치 오른쪽 위. 하단은 3칸(16% / 48% / 16%), 슬라이더 트랙은 가늘게(높이 약 16px)·손잡이 작게(지름 약 22px). 상단 원형 버튼은 40px. 블록이 바닥 바로 위 줄까지 오면 바닥에 빨간 경고 삼각형이 깜빡인다.
17. 구슬 크기는 레퍼런스 실측 비율(지름 = 블록 칸의 약 34%, 반지름 17/100)로 한다. 발사 대기 구슬은 레퍼런스처럼 연두색, 날아가는 구슬은 흰색+보라 빛.
18. 조준선은 블록을 통과해서 보여준다. 옆벽에서만 꺾이고 윗벽에서 끝난다(윗벽 반사는 해보았으나 사용자 요청으로 되돌림). 점 지름 = 칸의 약 12%, 점 간격 = 칸의 36%, 보라색.
19. 발사 후 5초가 지나도 구슬이 움직이고 있으면 자동으로 3배속. 다음 턴에는 원래 속도로 돌아간다(수동 빠르게 버튼은 그대로 유지).
20. (2026-09-26) 블록 모양은 레퍼런스처럼: 둥근 모서리(사각형 반지름 14/100, 세모도 모서리 둥글게), 위가 밝고 아래로 어두워지는 그라데이션, 바깥 네온 빛 + 안쪽 빛 번짐 + 위쪽 하이라이트 + 밝은 테두리. 색·모양별 이미지를 한 번만 그려 재사용(폰 성능).
21. 턴이 끝나면 블록 전체가 한 칸 위에서 부드럽게 미끄러져 내려온다(0.32초, 감속 곡선). 새로 생기는 맨 윗줄은 서서히 나타난다. 내려오는 동안은 조준 입력을 막는다.
22. 구슬 블록깨기는 레퍼런스처럼 번호 레벨(스테이지)로 진행한다. 쉬움/보통/어려움 선택 대신 스테이지 맵(5칸 지그재그, 아래가 1번, 잠긴 칸은 자물쇠, 깬 칸은 별 표시, 지금 도전할 칸은 하늘색 빛). 스테이지 N은 항상 같은 배치(모든 유저 공통). 깨면 N+1 해제. 별: 최소 턴+2 이내 ★3, +6 이내 ★2, 그 외 ★1. 난이도는 N에 따라 증가: 라인 수 = 8 + N/2(최대 40), 줄당 블록 수·세모 비율 증가, 고리 2개 확률 감소. 스테이지 배율 = 0.8 + (N-1)×0.04(최대 ×2.0). 리그 합산에는 오늘 깬 스테이지 중 최고점이 들어간다. 한 판에 하트 1개. 결과창 버튼은 [스테이지 맵] [다음 스테이지 / 다시 도전]. 진행 상황은 브라우저에 저장(서버 연결 시 계정 저장으로 이전).
23. (2026-09-26) 원본 화면 녹화 분석(04_원본분석_벽돌깨기.md) 결과를 반영한다: 구슬 발사 간격 0.033초(거의 붙어서 흐르듯), 구슬 속도 13칸/초, 발사 직후 연두색 → 블록에 한 번 맞으면 흰색+보라, 바닥에 닿은 구슬은 첫 착지점으로 굴러가 모인 뒤 턴 종료. 실패 직전 원본처럼 "아래 3줄을 제거합니다" 이어하기 창을 띄운다(원본은 보석 200/광고, 여기서는 판당 1번 무료). 사용자 화면 녹화는 구글 드라이브 공유 링크(링크가 있는 모든 사용자 보기)로 받아 분석한다.
24. (2026-09-26) 두 번째 영상 분석 반영. 하단 배치: 조준 중 [⚡번개] [슬라이더] [멀티볼], 발사 중 [구슬 회수] [되돌리기]. 번개 = 모든 블록 숫자 80%로 내림 + 가운데 큰 폭발 빛, 턴 안 씀. 멀티볼 = 이번 턴만 구슬 ×2.586(원본 111→287), 주황 구슬 + 발사대 소용돌이, 다음 턴 원래 개수. 아이템은 원본의 보석 구매 대신 판당 1개씩 무료. 되돌리기는 발사 중에 눌러 이번 발사를 취소(쏘기 직전으로 복구), 판당 1번. 자동 3배속이 켜지면 판 가운데 큰 ⏩ 표시.
25. (2026-09-26) 세 번째 영상 분석 반영 — 아이템 블록. 사각 블록 중 약 7%가 주황 아이템 블록(스테이지 배치에 고정). 폭탄 블록(안쪽 네모 무늬) = 깨지면 주변 3×3 블록 모두 파괴 + 폭발 빛. 가로 레이저(◀▶) = 깨지면 그 가로줄 전체 파괴, 세로 레이저(▲▼) = 그 세로줄 전체 파괴 + 레이저 빛. 효과로 다른 아이템 블록이 깨지면 연쇄 발동. 고리(구슬 +1)는 폭발·레이저에 사라지지 않는다.

29. 숲길 디펜스 진행·점수: 번호 스테이지(구슬과 같은 스테이지 맵, 나무색). 스테이지 N은 모든 유저 같은 공격 구성. 맵 2종(갈림길 숲, 굽이 숲길) 번갈아. 공격 수 = 5 + ⌈0.6N⌉(최대 15), 5의 배수 스테이지 마지막에 거인 보스. 적: 고블린·늑대·도적(갑옷)·박쥐(비행)·오크(갑옷, 생명 2)·거인(생명 5). 별: 생명 18 이상 ★3, 6 이상 ★2(원본 규칙). 점수: 클리어 500 + 남은 생명 보너스(350×생명/20) + 별×50, 스테이지 배율(구슬과 같은 식). 실패 0점. 자동 플레이 시뮬레이션으로 1~9 스테이지는 단순 전략으로도 깨지고 10(보스)부터 전략이 필요하도록 맞춤.
