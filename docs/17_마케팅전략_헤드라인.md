# 마케팅 전략 v9 — 헤드라인 재설계 (기획팀 × 마케팅팀 회의)

기록일: 2026-09-30 · 상태: 제안(사용자 선택 대기) · 기준: 결정 로그 144번까지
사용자 지적: "출석 보상이 헤드라인에 너무 강조됐다. 헤드라인이 특색 없다."

## 1. 진단 — 왜 지금 헤드라인이 약한가
대표 문구 "똑똑한 사람보다 꾸준한 사람이 이긴다"(결정 51·98)의 문제:
1. **출석 앱처럼 들린다.** 핵심이 "꾸준함 = 매일 들어오기"라서 듀오링고·만보기·출석체크 앱과 구분이 안 된다.
2. **우리만의 장면이 없다.** 이 문장만 보고는 퍼즐인지, 공부 앱인지, 운동 앱인지 알 수 없다.
3. **실제 재미와 어긋난다.** 끈기 보너스는 최대 +10%로 점수를 좌우하지 않는다(결정 61). 사람을 모으는 건 비교와 대결이다.
4. **공유할 이유가 약하다.** "나 꾸준해"는 자랑거리가 약하고, "나 820점, 너는?"이 대화를 만든다.

## 2. 우리만 할 수 있는 말 (기획팀이 확인한 사실)
| 사실 | 근거 | 다른 퍼즐 앱 |
|---|---|---|
| 매일 모두가 **같은 문제**(날짜 씨앗) | 결정 67·105 | 대부분 판이 사람마다 다름 |
| 같은 문제라서 **점수를 그대로 비교**할 수 있음 | 오늘 점수·친구 순위·세계 상위 % | 비교 불가 |
| 방금 푼 **그 문제를 친구에게 도전장**으로 보냄 | 결정 114 | 없음 |
| 같은 판으로 **1:1 실시간 대전** | 대전 모드 | 일부 |
| 10게임 = **5가지 두뇌 능력** 그래프·두뇌 유형 | 결정 55·106 | 단일 게임 |
| **강제 광고 없음**, 광고 수익 일부는 **모두의 기부** | 결정 95·96 | 광고가 최대 불만 |

→ 결론: 브랜드의 중심을 **"꾸준함"에서 "같은 문제로 붙는 두뇌 대결"로** 옮긴다. 끈기는 광고 문구에서 빼고 게임 안의 장치로만 둔다.

## 3. 헤드라인 후보 (회의에서 나온 8개, 평가)
평가 기준: 특색(우리만 할 수 있는 말) · 진실(실제 기능) · 공유성(비교·대화를 만듦) · 30대 이상 공감 · 금지 표현 없음(의학 효과·돈·나이).

| # | 헤드라인 | 특색 | 공유성 | 한 줄 평 |
|---|---|---|---|---|
| **A** | **같은 문제, 다른 점수.** | ◎ | ◎ | 핵심 기능을 네 단어로. 점수 카드 공유로 바로 이어짐 |
| **B** | **오늘도 전 국민이 같은 시험지를 받았습니다** | ◎ | ○ | 30대 이상의 "시험지" 기억을 건드림. 아침 알림·광고용 |
| C | 핑계 없는 두뇌 대결 | ○ | ○ | 같은 문제라 운 탓·판 탓 불가. 톤이 셈 |
| D | 오늘 문제, 너는 몇 점? | ○ | ◎ | 공유 글 끝줄로 최적. 브랜드 문구로는 가벼움 |
| E | 머리 좋다는 말, 증명해 봐 | ○ | ○ | 도발적. 지능 비교로 불편할 수 있음 |
| F | 퍼즐로 붙자 | △ | ○ | 짧고 친근하지만 어떤 대전 게임에도 쓸 수 있음 |
| G | 오늘의 두뇌 성적표 | ○ | ○ | 5능력 그래프를 살림. 경쟁감은 약함 |
| H | 똑똑한 사람보다 꾸준한 사람이 이긴다(현행) | △ | △ | 출석 앱처럼 들림 → 대표 문구에서 내림 |

## 4. 회의 결론 — 추천 조합
| 자리 | 문구 |
|---|---|
| **대표 헤드라인** | **같은 문제, 다른 점수.** |
| 보조 문구 | 매일 전 국민이 같은 퍼즐 5판을 풉니다. 차이는 실력뿐. |
| 출시 캠페인 · 아침 7시 알림 | 오늘의 시험지가 도착했습니다. |
| 공유 카드 · 도전장 끝줄 | 나 820점. 같은 문제, 너는? |
| 대전 소개 | 같은 판, 같은 시간, 1:1. |
| 신뢰 문구(작게) | 강제 광고 없는 퍼즐 · 광고 수익 일부는 모두의 기부 |
| 해외판 | Same puzzle. Different score. ("전 국민" → "전 세계") |

**왜 A인가:** 오직 이 게임만 참인 문장이다(모두 같은 문제). 읽는 순간 "그럼 내 점수는?"이라는 질문이 생기고, 그 답이 점수 카드·도전장 공유로 이어진다. 사행성·의학 효과·나이 표현이 없다.
**B는 A의 캠페인 짝:** 브랜드 문구로는 길지만 아침 알림·출시 광고·온보딩 첫 화면에 쓰면 매일의 의식이 된다.

## 5. 메시지 순서 (모든 채널 공통)
1. **약속** — 같은 문제, 공정한 비교 (헤드라인)
2. **증거** — 10게임·5능력, 같은 문제 도전장, 1:1 대전, 30명 주간 리그
3. **자랑거리** — 점수 카드, 두뇌 유형("나는 전략형"), 티어
4. **신뢰** — 강제 광고 없음, 모두의 기부
5. **유지 장치(광고에선 말하지 않음)** — 연속 출석 +1%·최대 +10%, 휴식권. 게임 안에서만 "빠져도 괜찮아요" 톤으로.

## 6. 채널별 적용
- **카카오톡**: 도전장 카드 "나 820점. 같은 문제, 너는?" → 링크 누르면 같은 문제로 바로 시작.
- **회사·동호회**: "우리 팀 오늘 시험지 평균은?" — 회사 동료 리그 시범(결정 102 2단계).
- **커뮤니티·인스타**: "오늘 문제 인증" — 매일 같은 문제라 인증글끼리 비교가 됨. 해시태그 #같은문제다른점수.
- **아침 알림**: "오늘의 시험지가 도착했습니다 · 어제 친구 1위는 민지님(3,120점)".

## 7. 게임에 바꿀 곳 (선택 후 반영)
로고 아래 슬로건 · 첫 안내 제목 · 링크 미리보기(og 제목·설명·이미지 문구) · 공유 카드 하단 문구 · 공유 글 끝줄 · 결과 창 끈기 알약은 작게(출석 첫날만) · README 첫 줄 · 결정 98 대표 문구 교체.

## 8. 사용자 결정 대기
- 대표 헤드라인: A(추천) / B / 다른 후보
- "전 국민"(국내) 표현 사용 여부 — 해외판은 "전 세계"
- 현행 문구 "똑똑한 사람보다 꾸준한 사람이 이긴다"의 처리: 완전 삭제 / 끈기 카드 안에서만 유지
