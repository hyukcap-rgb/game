## 1부. 비즈니스 기획팀 보고

### 0. 총평 3줄
1. **게임 본체는 다 됐고, 남은 일은 '스팀용 포장'이다.** 다만 이름(Trump), 영어화, 처음 하는 사람용 튜토리얼 세 가지가 없으면 미국에서 팔 수 없다. 셋 다 지금 바로 시작해야 한다.
2. **가장 이른 출시일은 12월 첫 주(목표 12월 3일 목요일)다.** Steam Direct 대기 기간과 '출시 예정' 페이지 2주 규칙 때문에 이보다 빨리 낼 수 없다. 그래서 대표님이 **이번 주 안에 이름을 정하고 Steamworks에 가입·결제**해야 한다.
3. **포인트 경제는 '돈 안 파는 단품 게임'으로 보면 너무 빨리 부풀고, 순위표를 쉽게 망가뜨린다.** 지금은 고급(×1.5)을 고르면 2~3일 만에 왕 판에 가고, 컴퓨터는 판돈이 무한이라 포인트가 끝없이 늘어난다. 배율 2개·컴퓨터 상한·스테이지 난이도·창 닫기 꼼수를 고치고, 순위표는 '보유 포인트'가 아니라 '별·최고 점수'로 만든다.

### 2. 스팀판 경제 점검

#### 2-1. 어떻게 계산했나
- `tools/tgostop-sim.js`와 같은 규칙 함수(`NG.tgostop._rules`)로, 컴퓨터끼리 난이도 조합마다 3,000판을 두었다(선은 번갈아 잡음). 아래 표에서 '보통 실력'은 컴퓨터 고수 수준, '초보'는 새내기 수준이다. 실제 사람 데이터는 아니고 **기준선**이다.
- '판당 기대값'은 한 판에 평균 몇 점당을 얻는지다. 정산식은 지금 코드 그대로(이기면 최종 점수 × 점당 × 배율, 지면 최종 점수 × 점당, 첫뻑·연뻑 포함, 관리비 0).

| 내 실력 → 상대 | 승률 | 판당 기대값(점당 배수) | 비고 |
|---|---|---|---|
| 보통 실력 → 초급 ×0.5 | 65.6% | **+1.8** | 쉬운데도 이득 |
| 보통 실력 → 중급 ×1 | 50.8% | **0.0** | 손해도 이득도 없음 |
| 보통 실력 → 고급 ×1.5 | 52.3% | **+2.6** | 가장 이득 |
| 초보 → 초급 ×0.5 | 49.1% | −6.1 | |
| 초보 → 중급 ×1 | 35.5% | −9.2 | |
| 초보 → 고급 ×1.5 | 37.6% | −13.1 | |
- 컴퓨터 타짜는 이기는 비율보다는 **크게 이기는 쪽**으로 세다. 질 때 잃는 점수가 평균 14.4점으로, 고수 상대(10.4점)보다 크다.
- 한 판에 20점 이상 잃을 확률은 고수 상대 18%, 타짜 상대 23%다. 입장 최소가 점당의 20배인 작은 판·보통 판에서는 **한 판으로 입장 금액을 다 잃을 수 있다**(올인이 자주 난다).

#### 2-2. 하루·일주일 흐름
**나라에서 그냥 주는 포인트(확정 수입):**

| 수입 | 금액 |
|---|---|
| 시작 | 10,000P + 충전권 3장 |
| 출석 7일 | 1,000 + 1,400 + … + 3,400 = 15,400P, 충전권 하루 1장 |
| 게임 안 업적 6개 | 22,000P (첫 주에 거의 다 받음) |
| 솔로 첫 클리어 50판 | 500 × (10+20+30+40+50) = **75,000P**, 충전권 5장 |
| 합계(업적 + 스테이지 + 출석 1주) | 약 **122,000P** |

**신규 이용자가 왕 판(150,000P)에 들어가기까지** (하루 10판, 이용자 2,000명 모의 실험, 지금 값):

| 고르는 난이도 | 걸리는 판 수(중간값) | 걸리는 날(중간값) | 그동안 올인 |
|---|---|---|---|
| 보통 실력 · 초급 | 49판 | 5일 | 2번 |
| 보통 실력 · 중급 | 51판 | 6일 | 5번 |
| 보통 실력 · 고급 | **20판** | **2일** | 1번 |
| 초보 · 중급 | 60일 안에 41%만 도달 | — | 135번 |
- 고급을 고르면 이틀 만에 왕 판에 간다. 왕 판에서 한 번 이기면 평균 16점 × 5,000 × 1.5 = **약 12만P**가 들어오므로 칭호 '큰손(50만)'이나 '전설의 손(200만)'도 며칠이면 된다. **목표 곡선(왕 판 1~2주)보다 3~5배 빠르다.**
- 반대로 초보는 충전권과 무료 충전으로 버티며 올인을 수백 번 한다. 실력이 늘면 나아지지만, 처음 일주일 경험은 나쁘다.

#### 2-3. 문제 5가지
1. **배율 순서가 거꾸로다.** 보통 실력이면 중급 ×1이 가장 손해다(고급 > 초급 > 중급). 초급 ×0.5도 손해가 아니다.
2. **컴퓨터 판돈이 무한(∞)이다.** 고급 ×1.5에서 기대값이 플러스라 계속 두면 포인트가 끝없이 늘어난다(인플레이션). 웹에는 관리비 5%라는 브레이크가 있었는데 없앴고(대표 지시, 그대로 따름), 대신 다른 브레이크가 필요하다.
3. **솔로 스테이지의 난이도 곡선이 덮어 써진다.** 판 고르기에서 난이도를 누르면 `g.ai = wallet().lv`가 스테이지 세기(`stageLevel`)를 대신하는 것으로 보인다(`tgostop.js` 1217줄, 개발팀 확인 필요). 그러면 스테이지 50과 스팀 업적 '스테이지 30'을 초급으로 깰 수 있다.
4. **창을 닫으면 지는 판에서 빠져나갈 수 있다.** 판 도중 나가기 벌점(`quitPenalty`)은 게임 안 나가기 버튼에서만 매겨진다. PC에서 Alt+F4나 창 ✕로 닫으면 정산도 벌점도 없이 끝나는 것으로 보인다(확인 필요). 지고 있을 때 창을 닫는 습관이 생긴다.
5. **'보유 포인트' 순위표는 쓸 수 없다.** 저장이 이 PC의 localStorage라 고치기 쉽고, 컴퓨터 상대 운에 크게 좌우된다. 순위표에 올리면 첫 주에 조작된 숫자가 1등을 차지한다.

| # | 항목 | 지금 값 | 바꿀 값 | 이유 |

### 6. UI 기획팀에 넘길 것 (무엇을 보여 줄지만, 배치는 UI팀이 정함)
1. 첫 실행 안내: "Simulated gambling. No real money." 한 번, 그다음 튜토리얼 시작(건너뛰기 가능).
2. 튜토리얼 단계: 짝 맞추기 → 뒤집기 → 족보 → 7점 고/스톱 → 정산. 카드 읽는 법 한 장(A~Q = 1~12, 무늬·명패 = 종류, K = 보너스), 선 뽑기에 'Q가 가장 높음'.
3. 난이도는 **자유 판에서만** 고르게 하고, 솔로 스테이지는 그 판의 컴퓨터 이름과 보상 배율을 보여 준다(E-4).
4. 컴퓨터와 둘 때 **'한 판 최대 받는 금액'**을 보여 준다(E-3). 상대 칸의 '∞' 표시는 바꿔야 한다.
5. 새 배율: 초급 ×0.4, 중급 ×1, 고급 ×1.3(E-1·E-2).
6. 다음 실행 때 '지난 판을 끝내지 않고 나가서 벌점이 정산됨' 알림(E-5).
7. 첫 실행 때 작은 판이 미리 선택된 상태(E-7).
8. 순위표 3개(별 합계·최고 점수·주간 대전 승수), 스팀 업적 진행.
9. PC 타이틀 화면: 솔로 / 대전 / 컴퓨터와 / 게임 방법 / 설정(소리·전체 화면·언어·글자 크기) / 크레딧(글꼴 OFL·AI 도구 표기) / 나가기. 키보드 단축키 안내.
10. 영어 용어(docs/31 P0-2)가 화면·도움말·스토어에서 모두 같은지.
11. 데모판 끝 화면: '스테이지 6부터는 본편' + 스토어 열기.

### 7. 대표 결정 필요
1. **스팀판 이름**: 기획팀 추천은 **Go-Stop Duel: Korean Card Game**(로고는 GO-STOP DUEL). USPTO와 스팀 검색에서 겹치는 이름이 없으면 확정.
2. **Steamworks 결제를 언제 할지**: 추천은 **이번 주(10/23까지)**. 30일 대기가 출시일을 정한다.
3. **출시 목표일**: 추천은 **12/3(목)**, 늦어지면 12/10(목). 겨울 할인 날짜를 확인해서 겹치지 않게 한다.
4. **경제 수정 E-1~E-7**: 추천은 **모두 적용하고 웹·고스톱(화투)에도 같이 적용**. 관리비는 다시 넣지 않는다(대표 지시 유지).
5. **웹과 포인트를 함께 쓸지**: 추천은 **따로 쓰기**. 대전 매칭만 함께.
6. **가격·할인**: 추천은 **4.99달러, 출시 할인 20%를 1주**.
7. **데모 범위**: 추천은 **스테이지 1~5 + 작은 판, 실시간 대전 없음, 진행은 넘어가지 않음**. 출시 전에 띄우기.
8. **한국 판매**: 추천은 **출시 때 한국 지역 판매 제외**. 등급분류는 출시 반응을 본 뒤 신청할지 정한다.
9. **AI 생성 콘텐츠 공개와 약관 확인**(Figma AI·ElevenLabs): 추천은 **스팀 설문에 공개하고, 결제 전에 약관을 확인**.
10. **순위표 기준**: 추천은 **별 합계·최고 점수·주간 대전 승수**. 보유 포인트 순위는 서버 검증 뒤로 미룬다.
