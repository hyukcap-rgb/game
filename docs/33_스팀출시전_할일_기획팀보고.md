## 1부. 비즈니스 기획팀 보고

### 0. 총평 3줄
1. **게임 본체는 다 됐고, 남은 일은 '스팀용 포장'이다.** 다만 이름(Trump), 영어화, 처음 하는 사람용 튜토리얼 세 가지가 없으면 미국에서 팔 수 없다. 셋 다 지금 바로 시작해야 한다.
2. **가장 이른 출시일은 12월 첫 주(목표 12월 3일 목요일)다.** Steam Direct 대기 기간과 '출시 예정' 페이지 2주 규칙 때문에 이보다 빨리 낼 수 없다. 그래서 대표님이 **이번 주 안에 이름을 정하고 Steamworks에 가입·결제**해야 한다.
3. **포인트 경제는 '돈 안 파는 단품 게임'으로 보면 너무 빨리 부풀고, 순위표를 쉽게 망가뜨린다.** 지금은 고급(×1.5)을 고르면 2~3일 만에 왕 판에 가고, 컴퓨터는 판돈이 무한이라 포인트가 끝없이 늘어난다. 배율 2개·컴퓨터 상한·스테이지 난이도·창 닫기 꼼수를 고치고, 순위표는 '보유 포인트'가 아니라 '별·최고 점수'로 만든다.

### 2. 스팀판 경제 점검

#### 2-1. 어떻게 계산했나
- `tools/tgostop-sim.js`와 같은 규칙 함수(`NG.tgostop._rules`)로, 컴퓨터끼리 난이도 조합마다 3,000판을 두었다(선은 번갈아 잡음). 아래 표에서 '보통 실력'은 컴퓨터 고수 수준, '초보'는 새내기 수준이다. 실제 사람 데이터는 아니고 **기준선**이다.
- '판당 기대값'은 한 판에 평균 몇 점당을 얻는지다. 정산식은 지금 코드 그대로(이기면 최종 점수 × 점당 × 배율, 지면 최종 점수 × 점당, 첫뻑·연뻑 포함, 관리비 0).

| 내 실력 → 상대 | 승률 | 판당 기대값(점당 배수) | 비고 |
|---|---|---|---|
| 보통 실력 → 초급 ×0.5 | 65.6% | **+1.8** | 쉬운데도 이득 |
| 보통 실력 → 중급 ×1 | 50.8% | **0.0** | 손해도 이득도 없음 |
| 보통 실력 → 고급 ×1.5 | 52.3% | **+2.6** | 가장 이득 |
| 초보 → 초급 ×0.5 | 49.1% | −6.1 | |
| 초보 → 중급 ×1 | 35.5% | −9.2 | |
| 초보 → 고급 ×1.5 | 37.6% | −13.1 | |
- 컴퓨터 타짜는 이기는 비율보다는 **크게 이기는 쪽**으로 세다. 질 때 잃는 점수가 평균 14.4점으로, 고수 상대(10.4점)보다 크다.
- 한 판에 20점 이상 잃을 확률은 고수 상대 18%, 타짜 상대 23%다. 입장 최소가 점당의 20배인 작은 판·보통 판에서는 **한 판으로 입장 금액을 다 잃을 수 있다**(올인이 자주 난다).

#### 2-2. 하루·일주일 흐름
**나라에서 그냥 주는 포인트(확정 수입):**

| 수입 | 금액 |
|---|---|
| 시작 | 10,000P + 충전권 3장 |
| 출석 7일 | 1,000 + 1,400 + … + 3,400 = 15,400P, 충전권 하루 1장 |
| 게임 안 업적 6개 | 22,000P (첫 주에 거의 다 받음) |
| 솔로 첫 클리어 50판 | 500 × (10+20+30+40+50) = **75,000P**, 충전권 5장 |
| 합계(업적 + 스테이지 + 출석 1주) | 약 **122,000P** |

**신규 이용자가 왕 판(150,000P)에 들어가기까지** (하루 10판, 이용자 2,000명 모의 실험, 지금 값):

| 고르는 난이도 | 걸리는 판 수(중간값) | 걸리는 날(중간값) | 그동안 올인 |
|---|---|---|---|
| 보통 실력 · 초급 | 49판 | 5일 | 2번 |
| 보통 실력 · 중급 | 51판 | 6일 | 5번 |
| 보통 실력 · 고급 | **20판** | **2일** | 1번 |
| 초보 · 중급 | 60일 안에 41%만 도달 | — | 135번 |
- 고급을 고르면 이틀 만에 왕 판에 간다. 왕 판에서 한 번 이기면 평균 16점 × 5,000 × 1.5 = **약 12만P**가 들어오므로 칭호 '큰손(50만)'이나 '전설의 손(200만)'도 며칠이면 된다. **목표 곡선(왕 판 1~2주)보다 3~5배 빠르다.**
- 반대로 초보는 충전권과 무료 충전으로 버티며 올인을 수백 번 한다. 실력이 늘면 나아지지만, 처음 일주일 경험은 나쁘다.

#### 2-3. 문제 5가지
1. **배율 순서가 거꾸로다.** 보통 실력이면 중급 ×1이 가장 손해다(고급 > 초급 > 중급). 초급 ×0.5도 손해가 아니다.
2. **컴퓨터 판돈이 무한(∞)이다.** 고급 ×1.5에서 기대값이 플러스라 계속 두면 포인트가 끝없이 늘어난다(인플레이션). 웹에는 관리비 5%라는 브레이크가 있었는데 없앴고(대표 지시, 그대로 따름), 대신 다른 브레이크가 필요하다.
3. **솔로 스테이지의 난이도 곡선이 덮어 써진다.** 판 고르기에서 난이도를 누르면 `g.ai = wallet().lv`가 스테이지 세기(`stageLevel`)를 대신하는 것으로 보인다(`tgostop.js` 1217줄, 개발팀 확인 필요). 그러면 스테이지 50과 스팀 업적 '스테이지 30'을 초급으로 깰 수 있다.
4. **창을 닫으면 지는 판에서 빠져나갈 수 있다.** 판 도중 나가기 벌점(`quitPenalty`)은 게임 안 나가기 버튼에서만 매겨진다. PC에서 Alt+F4나 창 ✕로 닫으면 정산도 벌점도 없이 끝나는 것으로 보인다(확인 필요). 지고 있을 때 창을 닫는 습관이 생긴다.
5. **'보유 포인트' 순위표는 쓸 수 없다.** 저장이 이 PC의 localStorage라 고치기 쉽고, 컴퓨터 상대 운에 크게 좌우된다. 순위표에 올리면 첫 주에 조작된 숫자가 1등을 차지한다.

#### 3-3. 튜토리얼 "Learn in One Hand"
- **정해진 씨앗으로 짠 한 판**(이 판 전용 배패, 8~10수 안에 7점이 나게). 시계 없음, 컴퓨터는 정해진 수를 둠, 포인트 오가지 않음(연습 판).
- 화면: 실제 판 그대로 + **스포트라이트**(나머지 화면 60% 어둡게, 대상만 밝게) + **말풍선**(영어 2줄·60자 이하, 대상 옆, 손패를 가리지 않게 위쪽). 버튼 [Next]는 '보기만 하는' 단계에만, '해 보는' 단계는 그 행동을 해야 넘어감(다른 카드는 눌리지 않음).
- 오른쪽 위 늘 [Skip Tutorial](Esc). 왼쪽 위 단계 점 `● ● ○ ○ ○ ○ ○ ○ ○ ○`.

#### 3-6. 판 위 PC 보강 (판 좌표·연출은 고스톱과 같게, 글자는 늘리지 않음)
1. **마우스 오버 카드 정보**(손패·바닥·먹은 패 칸): 0.3초 머물면 카드 위쪽에 작은 말풍선. 손패를 가리지 않게 늘 위로.
   ```
   ┌───────────────────────────┐
   │ J♠  Bright                │
   │ 2 of 3 Brights → 3 points │
   │ Matches 1 on the table    │
   └───────────────────────────┘
   ```
   먹은 패 묶음 위: "Junk 7 / 10 → 1 point at 10". 키보드·패드 포커스에도 같은 말풍선. Card hints를 끄면 안 나옴.
2. **고/스톱 창**: 버튼마다 한 줄(실제 금액).
   ```
   ┌──────────── 9 points! ────────────┐
   │  [ GO  (2 Go) ]      [ STOP ]      │
   │  +2 points, play on  Win now:      │
   │  Risk: Go Penalty ×2  900 pts      │
   │  [G]                 [S]           │
   └────────────────────────────────────┘
   ```
   상대가 이미 고를 했으면 STOP 줄에 "Opponent called Go: you'd win ×2". 컴퓨터 판은 금액 옆에 "(max 2,000)"(E-3 상한에 걸릴 때만).
3. **키 글리프**: 손패 아래 작은 숫자 1~9·0(키보드를 한 번 누른 뒤부터만 보임, 마우스만 쓰면 숨김 → 판 위 글자 최소화 지킴). 고/스톱 버튼 아래 [G][S].
4. **일시 정지 메뉴(Esc)**: Resume · How to Play · Card Guide · Settings · Leave Table(−1,000 pts 같은 벌점 금액을 버튼 안에). 대전이면 맨 위 "The game keeps going".
5. **상대 칸**: '∞' 대신 컴퓨터 판은 `Max 2,000`, 대전은 상대 보유 pts. 연결 끊긴 상대는 `AUTO` 꼬리표.
6. **선 뽑기**: 제목 "Draw for First"와 꼬리표 "Q is highest" 늘 보임.
7. 판 오른쪽 위 이름표: `Low Table · 100 pts/point`(지금 "19 작은 판 · 1점 100P"에서 19 빼기). Beginner rules 켬이면 `Beginner` 꼬리표.

#### 5-4. 30자 넘는 문구 줄이기 규칙
- 판 위·알림은 **명사 + 숫자**로: "판돈의 5배 500P를 받았어요" → `First Ppeok! +500 pts`.
- 이유·조건은 결과 창 줄이나 도움말 Tips로 내림(판 위 글자 최소화 지시 그대로).
- 지금 30자 넘는 판 밖 문구 중 고쳐야 할 것: 19세 확인 본문 → 첫 실행 안내 2줄, 결과 창 첫뻑 줄 → `Ppeok bonus`, 올인 꼬리 문장 → 결과 창 [Use Refill Ticket] 버튼, `tips` 9칸 → 영어로 칸마다 3문장 이하.
- 영어 화면 넘침 점검: `tools/text-audit.mjs`에 영어(en) 측정과 "버튼 밖으로 넘친 글자" 검사를 더함(개발팀).

#### 8-1. 화면
1. **PC 타이틀**(1920×1080, 16:10에서 잘리지 않는 안전 영역 1920×1080 중 가운데 1728×1080): 로고 GO-STOP DUEL, J·Q·K 부채꼴, 선비·각시. 'Trump', '19', 칩·돈·카지노 그림 없음.
2. 버튼 5상태(기본·오버·눌림·**포커스 링**·잠김), 메뉴 패널, 탭, 슬라이더, 토글.

4. 튜토리얼: 스포트라이트 어둠(60%), 말풍선(꼬리 방향 4가지), 단계 점, 손가락 그림.
5. **카드 읽는 법 한 장**(3-4), 크레딧, 데모 끝 화면, 설정.
6. **영문 글꼴**(제목용 1 + 숫자 고른 폭 1, OFL, 앱 안에 넣기) — 지금 Black Han Sans·Jua는 한글용.
7. **카드 영어 명패**(BRIGHT·ANIMAL·BIRD·CUP·DOUBLE·TRIPLE·BONUS, 띠 RED·BLUE·GRASS·RAIN): 손패 크기(1280×800에서 약 111px 폭)에서 읽히게 글자 수에 맞춰 명패 폭·크기 조정.
8. 마우스 오버 카드 말풍선, 고/스톱 창의 얻는 것/잃는 것 줄, 상대 칸 `Max 2,000`·`AUTO` 꼬리표.
9. 'pts' 표시 방법(글자만 vs 작은 기호) — 대표 결정 D-4에 따름. 칩·동전 모양은 피함.
