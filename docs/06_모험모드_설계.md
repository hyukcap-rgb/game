# 모험 모드·메인 간소화 결정 (02_결정로그 이어서 60~70번)

기록일: 2026-09-27. 02_결정로그.md의 59번 다음 번호로 이어진다. 22번(구슬 스테이지)과 29번(디펜스 스테이지)의 데일리 스테이지 방식은 62~63번으로 대체한다.

60. (2026-09-27) 메인 간소화: 메인은 "바로 시작" 중심으로 줄이고, 나머지 정보는 하단 탭으로 옮긴다. 하단 탭 4개는 [오늘 | 모험 | 리그 | 내 정보]. 상단은 내 정보 버튼(여우 얼굴 + Lv 배지), 작은 로고, 하트, 편지함만 둔다. 크기는 전체적으로 줄인다.
61. 오늘 탭 구성은 다음과 같다(위에서부터).
    - 한 줄 요약: 메달, 두뇌 지수, 순위, 연속, 마감. 누르면 내 정보로 간다.
    - 작은 "다음 한 판" 버튼: 누르면 바로 시작한다.
    - 5게임 한 줄 목록: 썸네일, 상태, 난이도 칩, "시작 ♥1".
    - 모험 안내 카드.
    두뇌 지수 카드, 끈기 카드, 슬로건은 내 정보 탭으로, 친구 리그는 리그 탭으로 옮긴다.
62. 빠른 시작: 시작 버튼은 난이도 창 없이 바로 시작하고, 마지막으로 고른 난이도를 기억한다(처음은 보통, 함대는 실시간 가능하면 실시간). 난이도를 바꾸려면 난이도 칩을 누른다. 22번의 구슬 스테이지와 29번의 디펜스 스테이지를 데일리에서 빼고, 데일리의 구슬·디펜스도 쉬움·보통·어려움 문제로 바꾼다.

    | 게임 | 쉬움 | 보통 | 어려움 |
    |---|---|---|---|
    | 구슬 | 블록 12줄 | 블록 18줄 | 블록 24줄 |
    | 디펜스 | 스테이지 3 난이도, 공격 7번 | 스테이지 6 난이도, 공격 9번 | 스테이지 10 난이도, 공격 11번 |

    디펜스 문제는 날짜와 판 번호로 만든다.
63. 모험(save형)을 새로 만든다. 5게임 모두 스테이지 1부터 끝없이 올라가는 혼자 하기 모드다.
    - 하트를 쓰지 않는다(무료).
    - 리그 점수와 출석(끈기)에는 들어가지 않는다.
    - 스테이지 N은 누구에게나 항상 같은 문제다.
    - 진행 상황은 브라우저에 저장한다. 기존 구슬·디펜스 스테이지 진행은 그대로 이어진다.
64. 모험 난이도 곡선(스테이지 N):

    | 게임 | 난이도가 오르는 방식 |
    |---|---|
    | 여우 | 판 크기 5×5(1~5) → 6×6(6~15) → 7×7(16~30) → 8×8(31~50) → 9×9(51~80) → 10×10(81~) |
    | 스도쿠 | 주는 숫자 = 46 − ⌊(N−1)×0.4⌋, 최소 24개 |
    | 구슬 | 기존 스테이지 식(22번) 그대로 |
    | 디펜스 | 기존 스테이지 식(29번) 그대로 |
    | 함대 | AI 쉬움(1~5) → 보통(6~15) → 어려움(16~) |

    | 게임 | ★ | ★★ | ★★★ |

66. 챕터: 10스테이지가 한 챕터이고, 10번째 스테이지는 보스(왕관 표시)다. 챕터 이름은 게임마다 5개이고, 6챕터부터는 이름 뒤에 II, III을 붙여 다시 쓴다.

    | 게임 | 챕터 이름 |
    |---|---|
    | 여우 | 여우 마을 / 단풍 숲 / 달빛 언덕 / 눈꽃 계곡 / 별빛 성 |
    | 스도쿠 | 숫자 정원 / 고요한 서재 / 수정 동굴 / 시계탑 / 천문대 |
    | 구슬 | 네온 거리 / 보라 터널 / 번개 공장 / 은하 궤도 / 블랙홀 |
    | 디펜스 | 숲 입구 / 갈림길 / 늪지대 / 고블린 요새 / 거인의 계곡 |
    | 함대 | 잔잔한 만 / 안개 해협 / 폭풍 바다 / 빙하 항로 / 해적 섬 |

    모험 맵은 챕터 단위로 보여준다. 10칸이 지그재그로 놓이고, 이전·다음 챕터 화살표가 있다. 잠긴 칸은 자물쇠, 지금 칸은 빛나는 표시다.
67. 모험 레벨: 5게임에서 모은 별 합계로 레벨이 오른다. Lv L+1이 되는 데 필요한 누적 별은 5·L·(L+1)/2다(Lv2 5개, Lv3 15개, Lv4 30개, Lv5 50개…).

    | 레벨 | 칭호 |
    |---|---|
    | 1 | 새싹 퍼즐러 |
    | 3 | 견습 탐험가 |
    | 5 | 숙련 탐험가 |
    | 8 | 퍼즐 기사 |
    | 12 | 두뇌 마법사 |
    | 16 | 전설의 현자 |
    | 20 | 퍼즐 마스터 |

    레벨 방패는 레벨이 오르면 색이 바뀐다(주황 → 파랑 → 금 → 보라).
68. 성장 보상: 레벨이 오르면 하트 +1을 준다. 챕터를 처음 클리어(보스)하면 하트 +2와 챕터 배지를 준다. 배지는 게임 5개 × 챕터 5개 = 25칸이며, 내 정보 탭에 모아 보여준다.
