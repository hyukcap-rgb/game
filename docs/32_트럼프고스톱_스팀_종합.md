# 32. 트럼프 고스톱 — 스팀 출시 종합 (현재 상태 · 레벨 · 할 일)

2026-10-21 기준 · 저장소 `hyukcap-rgb/game` · 게임 `games/tgostop`(v0.13.0) · PC 앱 `steam/` · 근거 문서 `docs/30`, `docs/31`

---

## 1. 무엇을 만들었나
- 우리 고스톱(`games/gostop`)의 **화면 좌표·연출·소리·AI·대전을 그대로** 두고 **카드만 트럼프 52장**으로 바꾼 2인 맞고(19세 이상).
- 하루퍼즐 사이트(성인(19) 묶음, 고스톱 바로 뒤)와 웹 모듈 `embed/tgostop.html`에서 동작 중.
- 스팀용 PC 앱 1단계 완료: `steam/`(Electron, 1600×900·전체 화면, 앱 안 글꼴, 업적 10개, SteamPipe 업로드 설정).

## 2. 규칙 (고스톱과 다른 점만)
| 항목 | 내용 |
|---|---|
| 카드 | A~Q = 1~12월(48장) + **K 4장 = 보너스패**(K♦·K♣ 쌍피, K♠·K♥ 쓰리피) · 더미 24장 |
| 무늬 = 종류 | ♠ 광·열끗 · ♥ 띠(홍단·청단·초단) · ♦♣ 피 |
| 뻑 보너스 | 첫뻑 점당 ×5 → 연뻑 ×10 → **3연뻑 ×15 + 즉시 승리** · 연속 아니어도 한 판 3뻑 = 승리 |
| 시작 뻑 | 처음 바닥에 같은 월 3장 = 뻑(주인 없음), 4번째로 먹으면 상대 피 1장 |
| 판 미션 | 씨앗으로 정한 패 2장을 이긴 사람이 다 먹으면 최종 점수 ×2(25% 확률 ×3) |
| 속도 | 한게임 신맞고 수준, 차례 시계 8초 |

## 3. 레벨·포인트 체계 (최종)

### 3-1. 난이도 (솔로·컴퓨터 대전에서 선택)
| 난이도 | 컴퓨터 | 이길 때 보상 | 영어(미국판) |
|---|---|---|---|
| 초급 | 컴퓨터 새내기 | ×0.5 | Easy · Rookie |
| 중급 | 컴퓨터 고수 | ×1 | Normal · Pro |
| 고급 | 컴퓨터 타짜 | ×1.5 | Hard · Card Shark |
- 질 때는 배율 없이 그대로 잃음. 실시간 대전은 배율 없음.
- **관리비 5%는 없앰**(`FEE = 0`, 2026-10-21 사용자 지시).

### 3-2. 판 크기 (입장 = 보유 포인트 기준)
| 판 | 점당 | 입장 최소 | 영어 |
|---|---|---|---|
| 연습 판 | 0(±0) | 0 | Practice |
| 작은 판 | 100P | 2,000P | Low Table |
| 보통 판 | 500P | 10,000P | Mid Table |
| 큰 판 | 1,000P | 30,000P | High Table |
| 왕 판 | 5,000P | 150,000P | Royal Table |
- 정산: 이기면 최종 점수 × 점당 × 난이도 배율(상대 보유까지), 지면 잃음(내 보유까지). 판 도중 나가면 점당 ×10 벌점.

### 3-3. 솔로 스테이지 (50판 · 5챕터 · 별 3개)
| 챕터 | 스테이지 | 이름 | 영어 |
|---|---|---|---|
| 1 | 1~10 | 동네 사랑방 | Neighborhood Parlor |
| 2 | 11~20 | 시장 골목 | Market Alley |
| 3 | 21~30 | 장터 한마당 | Village Fair |
| 4 | 31~40 | 명절 큰집 | Holiday at Grandma's |
| 5 | 41~50 | 고수의 방 | Master's Room |
- 스테이지 컴퓨터 세기(`stageLevel`): 챕터1 기본 새내기, 챕터2 고수, 챕터3~5 타짜. 각 챕터 5·10번째 판 한 단계↑, 1·9번째 판 한 단계↓.
- 선(`aiFirst`): 5·10번째 판은 컴퓨터가 선, 챕터3부터는 짝수 판 모두 컴퓨터 선.
- 별: 이기면 1개 · 10점 이상 2개 · 20점 이상 3개.
- 첫 클리어 보상: 500P × 챕터 번호(챕터1 500P … 챕터5 2,500P), 챕터 마지막 판(10·20…) 첫 클리어 = 충전권 +1장.

### 3-4. 포인트 얻기·구제
| 항목 | 내용 |
|---|---|
| 시작 | 10,000P · 충전권 3장 |
| 출석 | 매일 1,000P + 연속일마다 400P(최대 +2,400P) + 충전권 1장 |
| 충전권 | 올인(2,000P 미만)일 때 1장으로 10,000P 채움 · 최대 5장 |
| 무료 충전 | 충전권이 없을 때만, 3시간마다 3,000P |
| 업적 보상 | 첫 승리 3천 · 3고 이상 승 5천 · 피박/광박 2천 · 흔들기/폭탄 승 2천 · 한 판 20점 5천 · 솔로 챕터1 5천 |
| 판매 | **포인트·충전권은 돈으로 팔지 않음**(미국 소셜 카지노 규제·국내 결제 규제 회피) |

### 3-5. 칭호 (최고 보유 포인트 기준)
| 최고 보유 | 칭호 |
|---|---|
| 0 | 동네 새내기 |
| 30,000 | 사랑방 고수 |
| 100,000 | 장터 명인 |
| 500,000 | 큰손 |
| 2,000,000 | 전설의 손 |
- 하루퍼즐 사이트의 '솔로 레벨(별 → Lv)'·대전 레벨 제한은 고스톱류에 적용 안 함(`duelNoPts`) — 보유 포인트로만 겨룸.

### 3-6. 스팀 업적 (앱, 10개)
첫 승리 · 10승(동네 타짜) · 50승(고수) · 200승(전설의 손) · 5연승 · 스테이지 10 · 스테이지 30 · 첫 대전 · 대전 10승 · 100판.
- 2단계: 게임 속 사건 업적(3연뻑·5고·광박 주기·고도리) + 스팀 순위표(보유 포인트·최고 점수·연승).

## 6. 작업 규칙 (이 프로젝트에서)
- 고칠 곳: `games/tgostop/` → `node tools/build.js` → `npm test -- tgostop` → `steam/`에서 다시 빌드. 화투 고스톱과 화면·연출은 같이 맞춘다.
- 규칙 함수는 무작위·시간 금지 → `node tools/tgostop-sim.js 3000`.
- 영어화처럼 공용 엔진(core·embed/shell)을 고치면 모든 게임 점검 + 게임 이름 분기 금지.
