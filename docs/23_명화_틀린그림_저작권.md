# 23. 명화 틀린그림 — 저작권 점검과 만드는 규칙 (2026-10-10)

> 개발팀 정리입니다. 법률 자문이 아니므로 **돈을 받는 서비스로 내기 전에는 변호사 확인**을 받으세요.

## 1. 참고한 책(「명화 틀린그림 찾기 세계 편」)에서 쓸 수 있는 것 / 없는 것
| 항목 | 판단 |
|---|---|
| 보티첼리 등 **명화 자체** | 쓸 수 있음. 작가가 사망한 지 70년이 지나 한국 저작권법 보호기간(제39조)이 끝났고, 미국도 1929년 이전 공표작은 공공 영역. |
| **책 표지·편집·글자·배치**, 책 속 **차이를 만든 그림 파일**, 책이 고른 **차이 위치** | **쓰면 안 됨**(출판사 저작물). 사진을 캡처해 쓰거나, 같은 자리를 따라 틀리게 만들지 않는다. |
| 책이 고른 **30점 그대로** | 같은 목록을 그대로 복사하지 않는다. 우리가 직접 40점을 골랐다(`tools/masterpiece/catalog.json`). |
| 책 제목·디자인 | 따라 하지 않는다. 게임 안에는 우리 이름·우리 화면을 쓴다. |

## 2. 우리가 지키는 규칙
1. **작가가 1955년 이전에 사망한 작품만**(한국 70년 기준). 이번 40점은 모두 해당(가장 늦은 작가: 뭉크 1944).
2. **원본 사진 출처**: 위키미디어 공용(Commons)에서 받고, 라이선스가 **공공 영역(PD)/CC0**인 파일만 쓴다(`export.py`가 아니면 자동으로 거른다). 평면 명화를 충실히 찍은 사진은 새 저작권이 생기지 않는 것이 일반적이지만, 한국 법원의 확정 판단은 없어서 Commons의 PD 표시와 소장 기관의 이용 조건을 함께 확인한다. 한국 소장품(간송·리움·국립중앙박물관)은 **공공누리 유형·기관 이용 조건**을 따로 확인한다.
3. **차이를 만든 그림은 우리가 직접 편집한 것**임을 밝힌다(`CREDITS.md`). 작품을 놀리거나 망치는 변형은 하지 않는다(사망 후에도 작가의 명예를 해치는 행위는 금지, 저작권법 제128조). 차이는 색·밝기·위치·방향 정도로만.
4. **작가·작품명·제작 연도·소장처 표기**(성명표시). 결과 화면에 작은 설명과 함께 보여 준다.
5. 소장 기관의 상표·로고는 쓰지 않는다.

## 3. 게임 종료 시 작은 설명
`answers.json`의 작품마다 `title`·`artist`·`made`·`place`·`desc`(쉬운 말 두세 문장)가 있다. 결과 창에서 "오늘의 명화" 카드로 보여 준다(그림 이름·작가·연도·소장처 한 줄 + 설명).

## 4. 만드는 법
`python3 -I tools/masterpiece/export.py` → `out/masterpiece/`에 작품마다 원본·틀린그림·정답 JPG, `answers.json`, `CREDITS.md`.
이 환경은 위키미디어에 접속하지 못해서 **원본을 받는 단계는 접속이 열린 뒤 실행**해야 한다(`commons.wikimedia.org`, `upload.wikimedia.org`). 받은 뒤 사람이 꼭 확인할 것: ① 맞는 작품·온전한 전체 그림인지(잘린 사진·다른 버전 아닌지) ② 차이가 눈에 띄고 어색하지 않은지.
