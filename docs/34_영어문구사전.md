# 34-부록. 영어 문구 사전 최종판 (Go-Stop Duel · games/tgostop)

2026-10-22 · UI 기획팀 · `docs/34` 2부에서 링크 · 근거: `games/tgostop/tgostop.js`(v0.14.0) 화면 글을 주석 빼고 전부 뽑아 대조(문자열 318개), `tgostop-art.js` 명패, `tgostop-fx.js` 판 위 큰 글자, `core/engine.js`·`embed/shell.js` 중 스팀판 흐름에 보이는 공용 글, `docs/33` 2부 5절, `docs/34` 1부.

개발팀은 이 표의 **키 이름 그대로** `T('키', { 값 })`로 옮긴다. `ko`는 지금 화면 글(바꿀 것은 바꾼 글), `en`은 스팀 화면 글이다.

## 0. 쓰는 법

### 0-1. 키 이름 규칙
| 앞부분 | 어디 | 사전 위치(DEV-01) |
|---|---|---|
| `core.*` | 공용 엔진·모듈 껍데기(도움말 창, 솔로 맵, 그만하기 창, 결과 창 버튼) | core 공용 사전(모든 게임) |
| `tg.*` | 이 게임만 | 게임 정의 선택 항목 `i18n:{ en:{…} }` |
| `app.*` | 이름·안내처럼 스토어·크레딧·앱이 같이 쓰는 글 | `tg.*`와 같은 곳. **게임 이름은 `app.name` 한 곳**에서만 바꾼다(R-3 이름 확정 대비) |

### 0-2. 바꿔 넣는 값
| 자리 | 뜻 | 예 |
|---|---|---|
| `{g}` | 골드 금액. **`fmtG(n)` 결과를 그대로**(숫자 + 띄어쓰기 + G) | `2,000 G` |
| `{sg}` | 부호 붙은 골드 | `+1,500 G`, `−2,000 G` |
| `{n}` `{m}` | 그냥 숫자(`fmt`) | `7`, `1,234` |
| `{name}` | 닉네임·컴퓨터 이름(이미 `esc` 한 것) | `CPU Pro`, `Maya` |
| `{table}` | 판 이름 키의 결과 | `Easy`, `Low Table` |
| `{r}` | 카드 숫자 | `A`, `10`, `Q` |
| `{t}` | 남은 시간 | `2h 14m`, `0:08` |

### 0-3. 골드·숫자 표기 규칙 (대표-3 반영)
| 무엇 | 규칙 | 맞음 | 틀림 |
|---|---|---|---|
| 돈 이름 | 문장에서는 **Gold**(대문자 G로 시작, 고유명사처럼). 숫자 뒤에는 **G** | Not enough Gold · `12,400 G` | gold, coins, chips, credits, $, pts |
| 숫자와 G | 천 단위 쉼표(en-US) + **띄어쓰기 1칸(줄바꿈 안 되는 공백 U+00A0)** + `G` | `12,400 G` | `12,400G`, `12.400 G`, `12K G` |
| 증감 | 부호를 숫자 앞에, 빼기는 진짜 빼기 기호 `−`(U+2212) | `+1,500 G` · `−2,000 G` | `- 2,000 G`, `-2000G` |
| 점당 | 목록·버튼·이름표: `{g}/point`(빗금 앞뒤 띄우지 않음). 문장: `{g} per point` | `100 G/point` · "100 G per point" | `100G/pt`, `x100` |
| 상한 | `Max ±{g}`(목록), `Max win reached` / `Max loss reached`(결과 창) | `Max ±2,000 G` | `Cap`, `Limit` |
| 줄임 | 순위표처럼 좁은 칸만 `1.2M G`. 그 밖에는 줄이지 않음 | `1.2M G` | `2K G`, `2천 G`(ko도 `2,000 G`로 통일) |
| 한국어 | 같은 규칙: `12,400 G`, `점당 100 G`, `최대 ±2,000 G` | | `2천 골드`, `1만 G` |
| 게임 점수 | 늘 **points**(1이면 point). 판 위 점수 칸의 작은 단위만 `pts` 허용(칸이 좁음, 돈은 G라 헷갈리지 않음) | `9 points` · `0 / 7` | score, pt |
| 배수 | 곱하기 기호 `×` | `×2` | `x2` |
| 시간 | 대전 찾기 `0:08`, 무료 충전 `2h 14m`, 1시간 안이면 `14m` | | `14분` |
