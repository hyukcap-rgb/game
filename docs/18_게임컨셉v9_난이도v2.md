# 게임 컨셉 v9 "오늘의 시험지" + 난이도 v2 "5판마다 새 개념"

기록일: 2026-09-30 · 근거: 17_마케팅전략_헤드라인.md(대표 헤드라인 A "같은 문제, 다른 점수.")
사용자 지시: "마케팅 전략에 맞게 게임 컨셉을 새롭게 구성. 기획팀은 오로지 마케팅팀 전략에 맞게 룰을 수정. 비슷한 게임의 난이도를 벤치마킹해 판이 바뀔 때 자주 새 레벨 컨셉에 도전하게."

## 1부. 컨셉 v9 — 오늘의 시험지

### 한 줄
매일 아침 전 국민에게 **같은 5과목 시험지**(논리·집중·공간·전략·추리)가 도착한다. 첫 판이 공식 답안, 점수는 누구와도 그대로 비교되고, 과목마다 **수·우·미·양·가** 성적표가 나온다.

### 마케팅 전략 → 규칙 (기획팀이 바꾼 것)
| 마케팅 약속 | 막고 있던 규칙 | v9 규칙 |
|---|---|---|
| **같은 문제** | 문제 씨앗에 난이도·판 번호가 들어가 친구와 문제가 달랐음. 난이도를 각자 고름 | 씨앗 = 날짜 + 게임. 난이도는 **요일로 고정**(월·화 쉬움 · 수·목·금 보통 · 토·일 어려움). 난이도 선택 칩 삭제 |
| **다른 점수(실력 차이만)** | 오늘 점수에 솔로·대전 점수와 출석 보너스(+10%)가 섞임. 하트로 여러 번 풀어 최고점 | 오늘 점수 = **5과목 공식 점수 합**. 공식 = 과목마다 **그날 첫 판(무료)**. 다시 풀기는 같은 문제 연습(♥1, 기록 없음). 배율 삭제 |
| 공정한 마무리 | 실패·그만하기 = 0점 | 첫 판 실패·중간 제출은 **진행률 × 300 부분 점수** |
| **"너는 몇 점?"** 공유 | 점수 숫자·색 칸만 | **성적표**: 같은 문제 푼 사람 중 등수로 수(상위 10%)·우(30%)·미(60%)·양(85%)·가. 공유 카드·글이 "논리 수 · 집중 우 …" |
| 시험지 은유(캠페인 B) | "오늘의 문제 5게임" 무작위 | **5과목**: 과목마다 게임 2개 중 1개(같은 게임 3일 넘게 연속 금지). 화면 이름 "오늘의 시험지" |
| 출석은 헤드라인에서 뺀다 | 끈기 보너스가 점수에 들어감 | 점수에서 삭제. 연속 3·7·14·30·50·100·200·365일에 **하트 선물**, 휴식권은 유지 |
| 솔로·대전의 자리 | 오늘 점수에 더해짐 | 솔로 = 별·레벨·5판마다 새 규칙(실력 키우는 곳), 대전 = 대전 포인트·전적(오늘 점수와 따로) |

### 화면 문구
- 로고 아래: **같은 문제, 다른 점수.**
- 첫 안내: "오늘의 시험지가 도착했습니다" + 4단계(5과목 · 첫 판 공식 · 요일 난이도 · 성적표와 도전장)
- 홈: "오늘의 시험지" / "9월 30일 수요일 · 보통 · 전 국민 같은 문제 · 첫 판이 공식 답안(무료)". 목록마다 과목 배지, 성적 도장, [시작 무료] / [연습 ♥1]
- 결과: "공식 답안으로 기록됐어요" + "논리 수 · 같은 문제 푼 사람 중 상위 8%"
- 공유 글 끝줄·카드: "같은 문제, 다른 점수. 너는 몇 점?" / 링크 미리보기 og.png 교체
- 도전장: 친구가 아직 안 푼 과목이면 "도전하기 · 무료"(그 판이 공식 답안)

## 2부. 난이도 v2 — 5판마다 새 개념

### 벤치마크 (조사: 출처는 맨 아래)
| 게임 | 난이도 운영 | 가져온 원칙 |
|---|---|---|
| 로얄 매치 1~100판 | 신규 블록 11종(약 8판마다 1개). Hard 39·45·49·55…, Super Hard 59·69·79·89·99(10판 주기). 평균 시도 일반 1.2 · Hard 1.6 · Super Hard 2.5회 | 10판 톱니, 5번째 어려움·10번째 아주 어려움, **목표 첫 도전 성공률** 일반 ≈80% · 어려움 ≈60% · 보스 ≈40% |
| 툰 블라스트 | 10판 사이클 중간 Hard, 끝 Super Hard | 사이클 끝 보스 |
| 컷 더 로프 | 박스(25판)마다 새 기믹 1~3개 | 챕터 = 새 기믹 |
| 닌텐도 기승전결(마리오 3D) | 소개 → 전개 → 반전 → 정리, 기믹 하나를 다 쓰고 버림 | 챕터 안 자리별 역할 |
| 캔디크러시 | Hard / Super Hard / Nightmare 표시, 65판 이탈 → 너프로 유지율 개선 | 난이도 표시, 너무 센 판은 고친다 |
| NYT 크로스워드 | 월(쉬움) → 토(가장 어려움) 요일 곡선 | 시험지 요일 난이도 |
| 워들 | 모두 같은 문제 하루 1개, 이모지 공유 그리드 | 같은 문제 + 성적표 공유 |
| 스타 배틀 / 스도쿠 / 노노그램 / 배틀쉽 / 기억 카드 / 2048 | 2성 스타 배틀, 기법 기반 스도쿠 등급·대각선 등 변형, 컬러 노노그램·시간 벌칙, 연발(Salvo)·소나, 트리플 등 | 게임별 새 규칙은 장르 공통 변형에서만(결정 135) |

### 사이클 규칙(모든 게임 공통, 코드 `cyclePlan`)
| 챕터 안 자리 | 역할 | 목표 첫 도전 성공률 |
|---|---|---|
| 1 | **새 규칙 소개** — 그 규칙만, 쉽게 (첫 만남에 규칙 카드) | ≈90% |
| 2~3 | 익히기 | 80~85% |
| 4 | 섞기 — 앞 챕터 규칙과 함께 | ≈80% |
| 5 | **어려움**(빨간 칸) | ≈60% |
| 6 | **새 변주 소개** — 익숙한 판 + 조건 하나 | ≈90% |
| 7~8 | 규칙 + 변주 | ≈80% |
| 9 | 쉬어가기 | ≈90% |
| 10 | **보스**(보라 칸) — 이번 규칙 + 앞 규칙 + 변주 | ≈40% |
- 새 규칙은 11·21·31·41판, 변주는 6·16·26·36·46판 → **5판마다 새 개념**.
- 51판부터 **리믹스**: 배운 규칙 2개를 챕터마다 바꿔 섞는다(끝없는 조합).
- 공통 변주 3종: 번개(시간·기준 짧게) · 외줄 타기(실수 1번만) · 맨손(힌트·아이템 없음) + 게임별 변주 2~3종.
- 스테이지 맵: NEW 표시·어려움 빨강·보스 보라, 판 설명 아래 "새 규칙: …" 한 줄.

### 알려진 한계
- 모든 성공률은 **봇 기준**. 베타(11월)에서 실제 재도전 횟수로 다시 맞춘다(King 방식: 가장 막히는 판부터 손봄).
- 여우 리믹스 보스(60·70판)가 매우 어렵다. 스도쿠 50판 보스(부등호+창문+메모 없이)도 가혹할 수 있다.
- 숫자 합치기 3×3 판은 목표 64↔128 사이 조절 폭이 거칠다(45판 39%).
- 함대 침묵 함대 규칙은 AI를 가장 약하게 해도 목표보다 어렵게 나온다(64판 69%).
- 성적표 등수는 서버 전까지 **점수 분포 가정**(요일 평균 700/590/480, 표준편차 170). 서버 연결 후 실제 분포로 바꾼다.
- 오늘의 문제 함대는 적 배치는 날짜 고정이지만 AI 사격은 아직 무작위.
