# 31. 트럼프 고스톱 — 스팀 미국 출시 점검

2026-10-21 · 대상: `games/tgostop` · `steam/` · 목표 시장: **미국(영어)**

## 0. 한눈에
- **이름부터 바꿔야 한다.** 'Trump'는 미국에서 대통령 이름으로 먼저 읽혀 정치 논쟁·검색 오염·상표 문제가 생긴다. 카드 용어로도 trump = '으뜸패'라 뜻이 틀린다.
- **경쟁작**: 스팀에 화투 고스톱 로그라이크 'GO, STOP'(Moon Shin Ho, 2026년 11월 예정)이 있음 → 'Go Stop'만으로는 검색에서 묻히고 헷갈림.
- **게임 글자 전부 영어로**: 게임 파일 한글 줄 385줄(전체 1,708줄) + 공용 엔진(첫 화면·대전·도움말) 약 490줄.
- **미국인은 고스톱을 모른다**: '판을 두며 배우는 튜토리얼'과 영어 용어 사전이 판매의 핵심.
- **포인트를 돈으로 팔지 않는다**: 미국은 가상 칩을 파는 '소셜 카지노'가 소송·주 규제 대상(예: 워싱턴주) — 충전권·포인트는 게임 안에서만.

### P0-3 처음 하는 미국인을 위한 장치
- **판을 두며 배우는 튜토리얼**(첫 실행 자동, 스킵 가능): 짝 맞추기 → 뒤집기 → 족보 → 7점 고/스톱까지 실제 한 판. (카지노 스터디에서 만든 스포트라이트·말풍선 방식)
- **카드 읽는 법 한 장**: "A–Q = 1~12월(같은 숫자끼리 짝), 무늬·명패 = 패 종류, K = 보너스". 미국인은 A가 가장 높다고 생각 → 선 뽑기에서 'Q가 가장 높음'을 화면에 표시.
- **판 위 도움**: 낼 수 있는 패 빛내기(있음), 마우스를 올리면 카드 종류·점수 기여 말풍선, 점수판에 '7점까지 남은 점수'(있음), 고/스톱 창에 '고 하면 얻는 것/잃을 수 있는 것' 한 줄.
- **초보 규칙 켜기/끄기**(선택): 첫뻑·연뻑 보너스, 박(피박·광박) 끄기 → 처음엔 단순하게.

## 5. 순서 제안
1. 이름 확정(상표 검색) → 로고·캡슐 그림.
2. 언어 사전(엔진+게임) + 카드 영문 명패 → 영어판 첫 빌드.
3. 튜토리얼·카드 읽는 법·초보 규칙.
4. PC 타이틀·설정·키보드/컨트롤러·연령 안내.
5. 스팀 클라우드·순위표·친구 초대 → 미국에서 대전 지연 점검.
6. '출시 예정' 페이지 2주 이상 → 데모 → 출시.
