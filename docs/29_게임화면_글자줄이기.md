# 29. 게임 화면 글자 줄이기 (UI팀, 2026-10-18)

> 대표 지시: "게임 화면에 너무 많은 내용들이 글자로 나와 있어서 복잡해 보여. UI팀은 게임 안에 text를 최소화하고 도움말을 만들어서 그곳에서 볼 수 있게 해. 화면에 글자를 지금의 50%는 줄여. 모든 화면에 적용해. 모든 게임에."

## 목표
- 모든 게임의 **플레이 화면**(오늘의 문제 · 솔로 · 대전)에서 읽어야 하는 글자(한글·영문 글자 수, 숫자·기호 제외)를 **지금의 50% 이하**로.
- 뺀 글은 사라지지 않고 **도움말(제목 막대 오른쪽 ? 버튼)** 에서 본다.
- 측정: `node tools/text-audit.mjs` (390×844 화면, 판 시작 직후, 창 닫은 상태). 기준값 `docs/text-audit-before.json`.

## 판 위에 남기는 것 / 빼는 것

| 남긴다 | 뺀다 → 도움말로 |
|---|---|
| 게임 이름(제목) | 제목 아래 긴 부제(“공간 · 보통 · 공식 답안”) → 한 단어(“보통”, “12판”, “VS 별명”) |
| 숫자(점수·시간·남은 수) | 칩 이름표(“깬 블록”, “남은 줄”) → 그림(아이콘)으로 바꾸고 이름은 숨김 |
| 핵심 행동 버튼 1~2개(“발사”, “확인”) | 조작 설명 문장(“한 번 누르면 ✕ · 빠르게 두 번…”) |
| 문제 그 자체(낱말 퀴즈의 뜻풀이, 초성, 끝말잇기 단어) | 규칙 설명 문장, 안내 문장, “~해요” 문장 |
| 짧은 도구 이름(4글자 이하) | 별 목표 문장(“기준 턴+3 이내”) → 별(★★★)만, 누르면 잠깐 보임 |
| 이번 판 규칙 꼬리표(새 규칙 이름, 4글자 이하) | 꼬리표 뒤 설명(“· 2마리씩”) |

**문장은 판 위에 두지 않는다.** 판 위에 “~요”, “~세요”로 끝나는 글이 있으면 도움말로 옮긴다. 순간 알림(토스트·말풍선: “틀렸어요”, “완성!”)은 그대로 둔다(잠깐 보이고 사라짐).

## 공용 엔진이 해 주는 것(core, 모든 게임 자동)
1. **제목 부제 한 단어**: 솔로 `N판`, 오늘의 문제 `보통`, 대전 `VS 별명`. 전체 문구(챕터 이름·공식 답안 등)는 도움말 맨 아래 "이번 판" 줄.
2. **별 목표선**: 별만 보이고, 누르면 토스트로 목표 글. 도움말에 "별 목표" 칸.
3. **칩 이름표 숨기기**: `.hchip` 안 `.hv`에 그림(`.ico` 또는 `svg`)이 있거나, 시간 칩(`.hchip.time`, 시계 그림 자동), 기회 칩(`.hlives`)이면 `<em>` 이름표가 화면에서 숨겨진다(읽기 프로그램에는 남음). 그림이 없는 칩도 숨기려면 칩에 `ic` 클래스.
4. **도움말 "표시 안내"**: 숨겨진 칩 이름표를 그림과 함께 자동으로 모아 보여 준다.
5. **도움말 "화면 안내"**: 게임 정의 `tips:[[이름, 설명], …]`(또는 함수) — 판 위에서 뺀 조작·규칙 문장을 여기에 넣는다.

## 게임마다 할 일
1. `node tools/text-audit.mjs <게임>`으로 지금 글자를 본다.
2. 판 위 문장(팁·안내)을 지우고 `NG.<id>.tips`에 옮긴다.
3. 칩에 그림을 넣어 이름표를 숨긴다(그림은 직접 그린 24×24 선 그림, `ic()` 공용 그림 또는 게임 `SVG`).
4. 도구 버튼 글은 4글자 이하로(예: “한 줄 올리기” → “올리기”, “빠르게 보기” → “빠르게”). 원래 이름은 `aria-label`과 `tips`에.
5. 같은 게임의 대전 화면도 같이 본다.
6. 판 상태(G)·씨앗·시계·대전 통신은 건드리지 않는다. 글과 표시만 바꾼다.
7. 게임 `CLAUDE.md` 사용자 지시 맨 위에 “2026-10-18 판 위 글자 최소화(문장 금지, 설명은 도움말 tips)” 한 줄, 바뀐 기록에 한 줄.
