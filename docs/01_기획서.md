# 하루퍼즐 리그 기획서

기록일: 2026-09-25 (프로토타입 v0.4 기준)

## 1. 한 줄 소개
여러 퍼즐 게임을 매일 풀고, 게임별 최고점을 합산해 친구와 겨루는 두뇌 리그. 애니팡식 하트와 친구 네트워크를 넣는다.

## 2. 레퍼런스
- **Meowdoku (App Store id6761760135)**: 색깔 구역마다 하나씩 배치하는 논리 퍼즐. 플레이 방식의 기준. 리뷰에서 가장 큰 불만은 과도한 광고.
- **애니팡 / 모두의게임**: 하트 충전, 친구에게 하트 보내기, 친구 랭킹과 추월 알림.
- **스도쿠 UI**: 유튜브 영상 속 스도쿠 앱 화면(스크린샷 첨부). 메모(예비 숫자) 기능이 핵심.

## 3. 게임 목록

### 3-1. 여우 자리 찾기
- 규칙: 색깔 구역마다 여우를 1마리씩 놓는다. 같은 행과 열에 둘 수 없고, 대각선을 포함해 서로 붙으면 안 된다.
- 조작: "여우 놓기"와 "✕ 표시하기" 모드 전환. 맞게 놓으면 규칙상 불가능해진 칸에 ✕가 자동 표시된다.
- 판정: 놓은 여우들로 규칙상 끝까지 풀 수 있으면 정답(답이 두 개인 판이 생겨도 억울한 오답이 없게).
- 실수: 발바닥 3개. 틀리면 1개 감소, 0개면 실패.

### 3-2. 스도쿠 (9×9)
- 규칙: 가로줄, 세로줄, 3×3 굵은 칸 안에 1~9를 한 번씩.
- 상단: 난이도, 실수 n/3, 점수(실시간), 시간, 일시정지.
- 도구: 실행 취소, 지우기, 메모(ON/OFF 배지), 힌트(판당 3개, 남은 개수 배지).
- 메모: ON일 때 숫자를 누르면 칸 안에 작은 예비 숫자로 적힌다(1은 왼쪽 위 ~ 9는 오른쪽 아래 고정 위치). 다시 누르면 지워진다. 메모는 실수로 치지 않는다. 진짜 숫자를 맞게 넣으면 같은 줄·칸의 해당 메모가 자동 삭제된다.
- 틀린 숫자: 빨간색으로 칸에 남고 실수 +1. 지우기로 제거 가능. 실수 3번이면 실패.
- 강조: 선택 칸 진한 파랑, 같은 줄·칸 옅은 파랑, 같은 숫자 중간 파랑.
- 숫자 패드: 폰 세로 화면이라 1~9 한 줄 배치(레퍼런스는 3×3). 9개 다 채운 숫자는 사라진다.
- 일시정지: 판을 가리고 시간 정지.

## 4. 난이도

| 난이도 | 여우 자리 찾기 | 스도쿠 | 점수 배율 |
|---|---|---|---|
| 쉬움 | 6×6, 제한 2분 | 숫자 38개 제공, 제한 7분 | ×0.6 |
| 보통 | 7×7, 제한 3분 | 숫자 30개 제공, 제한 10분 | ×1.0 |
| 어려움 | 8×8, 제한 5분 | 숫자 최소(22~26개), 제한 15분 | ×1.4 |

"제한"은 시간 보너스가 0이 되는 시간이다. 제한을 넘겨도 계속 풀 수 있다.

## 5. 점수
- 여우: 클리어 500 + 시간 보너스(최대 350, 제한 시간까지 선형 감소) + 남은 발바닥 1개당 50. 여기에 난이도 배율.
- 스도쿠: 칸 채우기(빈칸을 맞힐 때마다 500 ÷ 빈칸 수, 힌트로 채운 칸은 0) + 시간 보너스(최대 350) + 남은 기회 1개당 50. 여기에 난이도 배율.
- 실패 또는 그만하기: 0점.
- 일일 합산: 게임별 오늘 최고점의 합. 매일 자정 초기화.

## 6. 공정 경쟁 (같은 문제)
- 문제는 "날짜 + 게임 + 난이도 + 오늘 몇 번째 판"으로 정해진다. 오늘 보통 3번째 판은 모든 유저에게 같은 문제.
- 재도전하면 새 문제가 나와서 외워서 푸는 이득이 없다.

## 7. 하트
- 최대 5개, 한 판에 1개, 10분마다 1개 충전.
- 친구가 보낸 하트는 5개를 넘겨서 쌓인다.
- 친구 1명에게 하루 1번 하트 보내기.
- 보상형 광고로 하트 1개, 하루 5번까지. 강제 광고는 없다.

## 8. 친구 네트워크
- 친구 일일 랭킹(합산 점수).
- 친구를 제치면 추월 알림.
- 받은 하트함.

## 9. 현재 구현 상태 (프로토타입)
- HTML 파일 1개. 기록은 브라우저 저장소(localStorage)에만 저장.
- 친구 6명은 가상 데이터(날짜로 점수 생성, 시간대에 따라 오름).
- claude.ai 링크로 공개. 아이폰에서 Claude 앱 뷰어가 로딩만 도는 문제가 있어 Safari(로그인 상태)로 확인 중.

## 10. 열린 과제 (팀 회의에서 나온 것)
- 게임 시간 불균형: 여우 1~3분, 스도쿠 5~15분인데 하트와 만점이 비슷해 여우 반복이 유리함.
- 제안: 스도쿠는 하루 1판 무료 "오늘의 메인", 짧은 게임만 하트 사용. (미결정)
- 제안: 절대 점수 대신 "같은 문제를 푼 사람 중 상위 %"로 환산. (미결정)
- 제안: 세 번째 게임 추가(지뢰찾기형 또는 숫자 잇기). (미결정)
- 제안: 주간 리그와 승급·강등. (미결정)
- UI: 홈·여우(보라·노랑 캐주얼)와 스도쿠(파랑·회색) 스타일 통일 필요. 여우 판에도 실행 취소·힌트 도구 줄. 첫 실행 튜토리얼.
- 마케팅: 워들식 결과 공유 카드, "강제 광고 없음" 차별점, 웹으로 지인 50~100명 먼저 테스트.
- 서버: 하트·점수 서버 저장, 풀이 기록 검증(점수 조작 방지), 실제 친구 연결, 푸시.
