# 원본 벽돌깨기 퀘스트 영상 분석

기록일: 2026-09-26 · 자료: 사용자 화면 녹화(49.6초, 1290×2796, 60fps, 스테이지 1958 플레이)

## 흐름
1. 스테이지 맵에서 1958 선택 → 게임 화면.
2. 조준: 하단 슬라이더. 조준 중 하단에 "광고 보고 추가공 50개 받기"(+50) 또는 좌우 아이템(번개 ×47, 멀티볼 ×21)이 보인다.
3. 발사 → 구슬 줄줄이 발사, 블록 맞히면 숫자 감소·블록 밝게 번쩍, 점수(우상단) 증가, 파괴 시 점수 팝업("10","20","30").
4. 구슬이 바닥에 닿으면 첫 착지점으로 굴러가 모이고 "×N" 표시.
5. 턴 끝 → 블록 한 줄 내려옴, 라인 수 감소(31→28).
6. 블록이 바닥에 닿으면 "아래 3줄을 제거 합니다" 이어하기 창(보석 200 또는 광고 보고) → 포기 시 "스테이지 실패" 창(별 3개 표시, 재도전, 광고 보고 보석 ×30).

## 실측 수치 (칸 = 블록 한 칸 폭)
- 구슬 속도: 약 18.3칸/초 (60fps 프레임별 추적으로 재측정. 처음 10fps로 잰 12.4칸/초는 과소 측정이었음)
- 발사 간격: 약 0.023초 (구슬 사이 간격 ≈ 0.41칸, 거의 붙어서 흐르듯 발사)
- 구슬 지름: 약 0.34칸
- 구슬 색: 발사 직후 연두색, 블록에 한 번 맞으면 흰색+보라 빛

## 반영함 (프로토타입)
- 발사 간격 0.023초, 속도 18.3칸/초 (재측정 반영)
- 연두 → 흰/보라 색 변화
- 바닥 착지 후 첫 착지점으로 굴러 모이기
- 실패 직전 "아래 3줄 제거" 이어하기 (보석 대신 판당 1번 무료)

## 아직 반영 안 함 / 확인 필요
- 번개·멀티볼 아이템: 영상에서 사용 장면이 없어 효과 불명. 사용하는 영상 필요.
- 점수 팝업("10/20/30")과 우상단 점수 방식: 블록 맞힐 때마다 +10인지 확인 필요(0→10→30→60→270…로 증가).
- 광고 보상(추가공 50개, 보석): 우리 원칙상 강제 광고 없음 — 보상형 광고로 넣을지 결정 필요.
- 클래식·100볼·멀티플레이 모드: 영상에 없음.

## 두 번째 영상 분석 (2026-09-26, 20.8초, 스테이지 1959)
- **멀티볼**: 조준 중 오른쪽 버튼. 누르면 발사대에 소용돌이 빛 → 이번 턴 구슬 ×111 → ×287(약 2.586배), 구슬이 주황색. 다음 턴은 다시 ×111. 사용 후 버튼 회색(한 턴 1번).
- **번개**: 조준 중 왼쪽 버튼. 판 가운데서 흰·노랑·빨강 큰 폭발 빛 → 모든 블록 숫자 80%로 내림(133→106, 131→104, 121→96, 107→85, 71→56, 12→9, 8→6 등 17개 확인). 턴을 쓰지 않음.
- **하단 배치**: 조준 중 [번개] [슬라이더] [멀티볼], 발사 중 [구슬 회수] [되돌리기]. 되돌리기는 발사 중에 쓰는 버튼(이번 발사 취소).
- **자동 빨리감기**: 발사 후 한참 지나면 판 가운데 큰 ⏩ 표시가 뜨며 빨라짐.
- 블록 맞힐 때 점수 팝업(80, 100, 120 등)이 뜸 — 점수 규칙은 아직 불명.

## 반영함 (2차)
- 번개(모든 블록 ×0.8 내림, 폭발 빛), 멀티볼(×2.586, 주황 구슬, 소용돌이) — 판당 1개씩 무료
- 되돌리기를 발사 중 버튼으로 변경(쏘기 직전으로 복구)
- 자동 3배속 시 판 가운데 ⏩ 표시

## 세 번째 영상 분석 (2026-09-26, 42초, 아이템 블록)
- 아이템 블록은 주황(호박색) 사각 블록에 무늬가 있음. 숫자는 그 줄 블록과 비슷(103~108). 첫 화면 블록 약 40개 중 3개(약 7%).
- **폭탄 블록**(안쪽에 작은 네모 테두리): 깨지면 흰·노랑·빨강 폭발과 함께 주변 3×3 블록 모두 파괴. 확인: 13→5→파괴 순간 240·130·211·115·13이 한꺼번에 사라지고 점수 팝업 10~60.
- **레이저 블록**(◀숫자▶ 가로, ▲숫자▼ 세로): 깨지면 화살표 방향 줄 전체 파괴. 확인: 세로 레이저 103→101→75→55→15→파괴 후 같은 세로줄의 216·214·208 등 전부 사라짐.

## 반영함 (3차)
- 아이템 블록 약 7%(사각 블록만), 폭탄 = 3×3 폭발, 가로·세로 레이저 = 줄 전체 제거, 연쇄 발동, 폭발 빛·레이저 빛 효과
