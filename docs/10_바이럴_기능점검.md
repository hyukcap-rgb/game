## 2. 기획팀 개발 명세(구현 완료)

1. **링크 미리보기**: og 제목 "하루퍼즐 리그 · 오늘의 문제, 나랑 붙어 볼래?", 설명, 1200×630 이미지(`og.png`), 앱 아이콘(`icon.png`). 주소 기준 `https://hyukcap-rgb.github.io/game/`.
2. **공유 시트**(모든 공유 공통): 카드 미리보기, "보이는 이름"(처음엔 "꾸준한 여우" 같은 자동 이름, 바꾸면 카드·링크에 바로 반영), [공유하기](휴대폰 공유 창 — 카카오톡·메시지·인스타 등, 지원 안 되는 곳은 글+링크 복사), [이미지 저장], [글·링크 복사], 보내질 글 보기.
3. **이미지 카드** 1080×1350: 로고, 날짜·이름, 큰 점수, 불꽃 띠(연속 출석·끈기), 오늘의 5게임 색 칸(백 단위 점수), 슬로건, 주소.
4. **도전장**: 결과 창 [친구에게 도전장]. 링크 `?n=이름&c=게임&d=날짜&s=점수&lv=난이도`. 받은 사람은 "OO님의 도전장" 창 → [도전하기] → 그날 1번째 판(공식 기록) 문제로 시작. 끝나면 결과 창에 "나 vs OO" 비교(이기면 "도전 성공! N점 차") + [되갚기 도전장]. 날짜가 지난 도전장은 오늘 문제로 새 대결 안내. 도전장 버튼은 그날 1번째 판(또는 도전장 판)에만 — 같은 문제임을 보장.
5. **초대**: 리그 탭 친구 목록 아래 [친구 초대하기]. 이름이 담긴 링크로 들어온 사람은 ① 초대한 사람이 친구 리그에 추가 ② 하트 2개 선물(기기당 1번) ③ 환영 창 "OO님이 초대했어요" → [OO님 점수 넘으러 가기]. 모든 공유 링크에 이름이 들어가므로 결과 카드·도전장도 초대 역할을 함.
6. **자랑 순간**: 연속 3·7·14·30·50·100·200·365일 달성 시 결과 창에 "연속 N일 달성!" + [연속 N일 자랑하기]. 레벨 업·주간 승급(또는 1~3위) 축하 창에 [자랑하기].
7. **공유 보상**: 하루 첫 공유(공유·저장·복사 중 하나)에 하트 +1. 게임 안 재화만, 현금성 없음.
8. **문구**: 주간 결과 창의 "모두의 상금 당첨" 삭제, 환영 창의 상금 문구를 "친구와 도전장"으로 교체(결정 96).

## 3. 서버가 필요해서 남긴 것 (0단계 서버 작업에 추가)
- 초대한 사람 쪽 보상(친구가 가입·첫 판 완료 시 하트 +3), 초대 수 집계, 초대 랭킹.
- 초대·도전장으로 들어온 친구의 **실제 점수** 연결(지금은 이름만 추가, 점수는 가상).
- 도전장 결과를 보낸 사람에게 알림("OO님이 도전장에 응했어요 · 결과 보기").
- 카카오톡 전용 공유(카카오 앱 키 필요, 결정 101 "카카오톡 우선"). 지금은 휴대폰 공유 창에서 카카오톡 선택.
- 공유·유입 지표: 공유율(목표 10%+), 링크당 유입, 초대 전환율, K-factor. 링크에 `n`(보낸 사람)이 있어 서버 붙이면 바로 집계 가능.
- 카드별 링크 미리보기 이미지(점수가 박힌 미리보기)는 서버 렌더링 필요. 지금은 공통 `og.png`.
