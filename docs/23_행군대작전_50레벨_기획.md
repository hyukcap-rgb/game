## 총평
1. **50판을 5챕터(새벽 들판 → 서리 고개 → 안개 늪 → 불꽃 협곡 → 구름 성채)로 나누고, 거의 모든 판에 새로운 것이 하나씩 나온다** — 지금 있는 기믹 14개 + 새 기믹 26개 + 새 판 방식 3개(추격전·버티기·보스 연전) = 43개, 50판의 기믹 조합은 모두 다르다(자동 점검함).
2. **보스는 4종 → 12종**(새 8종: 눈보라 큰뿔·빙산 거북·늪 두꺼비 왕·그림자 쌍둥이·용암 골렘·쇠바퀴 공성차·폭풍 매 기수·쇠구름 대장군). 예고 모양을 3종(원·줄·틈) → 8종(원·줄·부채꼴·틈·고리·추적·반쪽·연속)으로 늘리고, 기존 4종도 공격을 1개씩 더했다. 대장 보스 4종은 2페이즈(껍질 회전·분열·하늘·망토 찢김)가 있다.
3. **리듬은 사이트 공통 10판 사이클(docs/18)에 맞춘다**: 3판 미니 보스로 초반 긴장감을 지키고, 이후 5판마다 중간 보스 · 10판마다 대장 보스, 9번째 판은 쉬어가기. 첫 도전 성공률 목표는 일반 80~90% · 어려움 60% · 중간 보스 55% · 대장 40% · 최종 35%.

## 1. 기믹(룰) 사전

단위: 부대 속도 초당 24 · 길 폭 ±50(부대는 ±44까지) · 화살 사거리 적 부대 58 / 상자·통 70 / 탑·성문 72 / 보스 85 · `E` = 기대 병력(생성기 값) · `R` = 부대 반지름 `3×√min(N,120)×0.85+2` · `n` = 레벨 번호 · `%` = 그때 내 병력 비율.
공통: 새 기믹이 **처음 나오는 판**은 나오는 빈도 60%, 피해 ×0.7(첫 만남 완화). 새 기믹은 지금처럼 판 안 시작 카드(2.6초)로 알린다.

## 2. 보스 로스터 (12종)

### 2-1. 예고 모양 8종 (모든 보스 공통 언어)
| 모양 `tele` | 뜻 | 보이는 법(색) | 피하는 법 |
|---|---|---|---|
| `circle` 원 | 한 곳 내려침 | 빨간 원이 안쪽부터 차오름(지금과 같음) | 원 밖 |
| `multi` 연속·여러 개 | 원 여러 개, 또는 순서대로 터짐 | 빨간 원 여러 개, 순서가 있으면 1·2·3 번호 | 원 사이 / 지나간 자리 |
| `line` 줄 | 길 따라 한 줄 | 빨간 띠(지금과 같음) | 줄 밖 |
| `gap` 틈 | 길 전체 공격, 한 곳만 안전 | 길 전체 빨강 + **초록 틈** | 초록 틈 안 |
| `cone` 부채꼴 | 보스 앞으로 퍼지는 부채, 쓸어가기도 | 주황-빨강 부채꼴 + 쓸어가는 방향 화살표 | 부채 밖 / 지나간 뒤쪽 |
| `ring` 고리 | 도넛 모양. 가운데와 바깥은 안전(저주 고리는 조여듦) | 빨간 도넛, 안쪽 원은 초록 | 가운데 가만히 또는 바깥으로 크게 |
| `track` 추적 | 나를 따라오다 멈춘 뒤 공격 | **노란 줄이 따라옴 → 빨강으로 바뀌며 멈춤** | 빨강으로 바뀐 순간 옆으로 |
| `side` 반쪽 | 길 왼쪽 또는 오른쪽 반 | 반쪽 전체 붉은 막 | 반대쪽 |
- 색 약속: 빨강 = 맞으면 피해 · 초록 = 안전 · 노랑 = 아직 조준 중 · 보라 = 상태 변화(저주·뒤바뀜) · 하늘색 = 얼음/밀림.
- 예고 크기는 판정 크기와 정확히 같게(보이는 것 = 맞는 것). 예고는 바닥 위 옅은 막(눈 아프지 않게, 깜박임 없이 차오름).

## 4. 난이도 곡선

### 4-1. 공식
| 값 | 공식 | 메모 |
|---|---|---|
| 보스 앞 기대 병력(목표) | `E_boss(n) ≈ 15 + 4.5n` (±30%) | 1·10·20·30·40·50판 ≈ 20·60·105·150·195·240. **설계 목표치**이며 `NG.march._sim(n, 씨앗)`으로 맞춘다(실측값 아님) |
| 일반 적 부대 | `E × 0.5~0.95 + 2 + 0.6n`, 솔로는 `≤ 내 병력×0.9 + 3 + n/2` | 지금 그대로 |
| 마지막 대군 | `0.7E + 6 + n` → 21판부터 `0.8E + 6 + n` | 후반 마무리 긴장 |
| 보스 체력 | `hpk × max(E,12) × 유형 계수 + 60 + 12n` · 유형 계수 미니 0.75 · 중간 0.9 · 대장 1.0 · 최종 1.15 | 솔로는 지금처럼 실제 병력 기준 상한(`max(N,12)×1.05`)도 적용 |
| 보스 공격 간격 | `max(1.0, 2.2 − 0.024n)`초, 분노 ×1/1.45 | |
| 예고 시간 | 공격별 값 × `max(0.75, 1 − 0.005n)` × 분노 0.8 | 50판 대장 0.75 × 0.8 = 0.6배까지 |
| 보스 피해 | 공격 비율 × `(1 + 0.012n)`, 하나 ≤ 60%, 한 순간 ≤ 70% | |
| 새 기믹 첫 판 | 빈도 60%, 피해 ×0.7 | |

| 유형 | 첫 도전 성공률 목표 | 라이벌 AI(`_sim`) 승률 기준(8판 중) |

| 섞기 | 80% | 6~7 |

| 쉬어가기 | 92% | 8 |
| 미니 보스(3판) | 75% | 6~7 |

| 대장 보스 | 40% | 3~4 |
| 최종(50판) | 35% | 2~3 |
- 근거: 사이트 공통 난이도 v2(docs/18) — 로얄 매치식 10판 톱니(일반 ≈80% · 어려움 ≈60% · 보스 ≈40%), 캔디크러시 "너무 센 판은 고친다". 군중 행군 장르의 공개된 판별 실패율 수치는 확인하지 못해 쓰지 않았다.
- 라이벌 AI는 관문 80%·회피 70%로 사람 평균보다 조금 약하게 잡힌 봇이라, 사람 목표보다 한 칸 낮게 맞춘다. 새 기믹마다 AI 판단(뗏목 고르기·번개 기둥 타이밍 등)을 넣어야 시뮬이 의미 있다(개발팀).
- 1판 "처음부터 긴장감": 성공률은 90%로 두되, 1명 시작 + 2초 갈림길 + 대군 끝으로 **아슬아슬하게 이기는** 판(남은 병력 40~60%)을 목표로 한다.

### 4-4. 51판부터(리믹스)
- 챕터(10판) 단위로 반복: 배운 기믹 중 2개를 씨앗으로 골라 "이번 챕터 주제", 5판 중간 보스·10판 대장 보스는 12종을 돌되 **분노 시작**·**예고 0.9배** 같은 변주 1개를 붙인다. 시작 병력 10, 구간 20.

1. **예고는 "빨강 = 맞음 · 초록 = 안전 · 노랑 = 아직 조준 중"을 색과 모양(빗금·실선/점선·번호·화살표)으로 함께 말한다.** 8종 모두 깜박이지 않고 "차오름 하나"로 남은 시간을 보여 주고, 부대가 예고를 가리지 않게 테두리만 병사 위에 한 번 더 그린다.
2. **보스 공격 52개(2페이즈 공격 포함)를 한 표로 묶어 이펙트 칸·흔들림·번쩍·소리·회피 글자를 정했다.** 번쩍은 "내가 맞았을 때만", 초당 2번 이하, 빨간 화면 번쩍 금지(가장자리 비네트로) — 사용자 지시 "눈 아프지 않게"를 보스전에도 적용.
3. **맵·결과·HUD는 대부분 게임 정의 선택 칸(`stageTag`·`cardNote`·`winTitle` getter)으로 풀 수 있고, core를 건드려야 하는 건 2개뿐**(맵 챕터 배경 `chapterTag`, 사이트 공통 "흔들림·번쩍 줄이기" 설정) — 둘 다 대표 결정으로 올린다.

### U1-1. 공통 규칙 (모든 예고)

### U1-4. 예고가 겹칠 때
1. **같은 자리 빨강 겹침은 진해지지 않는다**: 채움은 "더하기"가 아니라 겹친 곳에서 큰 값 하나만(최대 42%). 테두리는 각자 그림.
2. **먼저 터지는 예고가 위에.** 같은 시각이면 피해가 큰 쪽이 위.
3. **초록이 다른 빨강과 겹치면 초록을 지운다**: 그 부분은 빨강 빗금으로 덮고 ✓를 뺀다(보이는 것 = 맞는 것). 즉 초록은 "지금 진행 중인 모든 예고에서 안전한 곳"에만 남는다.
4. 노랑(조준 중)은 항상 맨 아래 — 아직 확정이 아니므로.
5. 동시에 진행되는 예고 **최대 3개**. 4번째는 생성 규칙에서 미루기(비즈니스 확인 3). 기믹 예고(낙석·투석기·기병·폭탄 수레)도 이 수에 포함.
6. 보스 예고와 기믹 예고가 겹칠 때 기믹 쪽 테두리는 흰색 `#FFFFFF` 2px(보스 원소 색과 구분).

## U2. 보스 공격 전체 표 (12종 · 52개, 2페이즈 공격 포함)

### U2-1. 표를 읽는 법·공통 규칙
- **흔들림**: 2-2 등급(약 0.25~0.35 · 중 0.45~0.55 · 강 0.6~0.75). **맞았을 때** 이 등급, **피했을 때**는 한 단계 낮게(약이면 없음).
- **번쩍**: **내가 맞았을 때만**(지금 코드도 맞을 때만), 표의 색으로. 세기 = 약 0.2 · 중 0.35 · 강 0.5(2-2의 0.25/0.45/0.6에서 한 단계 낮춤 — 눈부심 지시). 1초 안 두 번째 번쩍은 세기 절반, 세 번째는 생략. **연속 공격(분화 사슬·하늘 번개·불덩이 연속)은 마지막 한 번만** 번쩍.
- **빨강 계열 번쩍 금지**: 빨강·진홍 번쩍은 화면 전체를 칠하지 않고 **가장자리 비네트**(화면 테두리 안쪽 18%만, 세기 0.25 이하)로. 지금 분노 때 `#ff3b30` 0.35 전체 번쩍도 같은 규칙으로 바꿈.
- **이펙트 그리기**: 검정 배경 시트를 '더해 그리기'(`lighter`)로. 한 이펙트 최대 크기 = 화면 폭 60%, 최대 불투명도 0.9. 느린 폰은 같은 칸을 한 번만(겹쳐 그리기 생략).
  - **칸 크기**: fx_a 384×384 · fx_b 384×256 · **fx_c 230.4×384(가로 칸 폭이 정수가 아님)** → 칸을 자를 때 반올림하고 안쪽 4px 여백을 두어 옆 칸이 비치지 않게.
  - **밝은 바닥 주의**: 먼지·연기·그림자 연기(fx_a 1-2, fx_a 2-2의 먼지, fx_b 3-3, fx_c 1-1, fx_c 1-5)는 '더해 그리기'로는 모래색 바닥에서 거의 안 보이거나 뿌옇게 날아간다 → 디자인팀에 **알파(투명 배경) 판 5칸**을 따로 요청(U8 P0). 받기 전에는 해당 칸을 '보통 그리기'+불투명도 0.6으로.
- **피했을 때 표시**: 부대 위에 흰 글자 18px(검정 2px 테두리) + 초록 알약 배경, 0.6초 동안 20px 떠오르며 사라짐. 기본 "회피!". 연속 성공은 "회피 ×2!", "회피 ×3!"(보이기만, 점수 없음). 쏴서 없앤 것은 "깼다!"·"터뜨림!".
- **효과음 느낌**: 효과·사운드팀이 만들 소리의 느낌. **예고 시작 소리**를 공격마다 다르게 해서 화면을 안 봐도 무엇이 오는지 알게 한다(접근성).

### U3-3. 보스가 둘일 때
**그림자 쌍둥이(30판) — 한 판에 막대 둘**
```
┌────────────────────────┬──────────────────────┐  높이 64px
│[달] 달그림자      660  │  별그림자 [별]   660 │  얼굴 36px, 이름 14px, 숫자 18px
│ ████████████▌░░░░░     │     ░░░░░████████████│  왼쪽 막대는 왼→오, 오른쪽은 오→왼(가운데로 줄어듦)
│      ▼조준             │                      │  ← 화살이 노리는 쪽에 ▼조준 13px
└────────────────────────┴──────────────────────┘
```
- 왼쪽 칸 테두리 청록, 오른쪽 진홍(쌍둥이 그림의 가면 줄 색과 같게). 화면 위치(보스 x −22 · +22)와 칸 순서를 같게.
- 그림자 상태인 쪽: 칸 전체 회색 + "그림자 3초" 칩. 쓰러진 쪽: 얼굴 흑백 + 굵은 X + 숫자 0 · 칸 폭이 0.4초에 걸쳐 1/3로 줄고 남은 쪽이 넓어지며 "외톨이 분노" 칩.

**용암 골렘 2페이즈 — 막대가 둘로 갈라짐**: 큰 막대가 50%에 가운데서 둘로 쪼개지는 애니(0.4초) → 쌍둥이와 같은 두 칸(왼·오), 얼굴은 작은 골렘 그림. 하나 쓰러지면 남은 쪽 칩 "빨라짐 ×1.2".

**보스 연전(47판)**
- 체력판 왼쪽 위 작은 알약 "보스 1/2"(13px), 얼굴 옆에 다음 보스 얼굴 28px **어둡게**(실루엣).
- 첫 보스 격파 → "1/2 격파! 다음: 방패 기사" 1.2초 → 체력판 숨김 → 사이 구간 동안 진행 막대에 두 번째 보스 깃발 → 두 번째 등장은 U3-1 등장 순서 그대로(카드 문구 "보스 2/2").

**추격전(44판) 화면**
```

```

**버티기(46판) 화면**

## U9. 비즈니스 기획팀에 확인할 것 (규칙·숫자라 UI팀이 정하지 않음)
1. 여러 원(multi) 사이 틈이 부대 지름보다 좁게 생기지 않도록 생성 규칙에 최소 틈 넣기.
2. 분노 0.8배를 곱해도 초록 틈 폭 ≥ 11단위(≈36px)가 되게 하한.
3. 동시에 진행되는 예고(보스 + 기믹) 최대 3개.
4. 보스 등장 뒤 첫 공격까지 2초 유예.
5. 2페이즈 넘어갈 때 1.8초 무적·무공격, 진행 중 예고 취소(피해 없음) / 보스가 쓰러질 때 날아오던 공격 취소.
6. 꺼지는 발판(27판) "0.8초 깜박" → "0.8초 동안 금이 퍼지며 한 번 어두워짐"으로 표현 바꾸기(판정 시간은 그대로) — 초당 2번 넘는 깜박임 금지 때문.
7. 2-2의 번쩍 세기(0.25/0.45/0.6)를 0.2/0.35/0.5로 낮추고 빨강 번쩍은 비네트로 — 효과 등급 표 숫자 수정.
8. 회피 연속 표시("회피 ×3!")는 보이기만, 점수·별에 넣지 않음(맞는지 확인).
