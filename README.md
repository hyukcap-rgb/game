# 하루퍼즐 리그

> 똑똑한 사람보다 꾸준한 사람이 이긴다

10가지 퍼즐 게임으로 겨루는 두뇌 리그입니다. 매일 10게임 중 5게임이 "오늘의 문제"로 뽑히고, 솔로(스테이지)와 1:1 대전 점수까지 더해 친구·주간 리그와 겨룹니다. 애니팡식 하트와 친구 네트워크가 들어가 있습니다.

## 모드
| 메뉴 | 내용 | 점수 |
|---|---|---|
| 오늘 | 10게임 중 날짜별 5게임, 전 세계 같은 문제 | 게임별 오늘 최고점 합 |
| 솔로 | 모든 게임을 스테이지로(무료) | 새 스테이지 첫 클리어 +100 + 별×50 (하루 최대 1,000) |
| 대전 | 모든 게임 1:1, 같은 문제를 동시에 풀기(함대는 턴제) | 승리 +400 · 무승부 +250 · 패배 +150 |

오늘 점수 = (오늘의 문제 + 솔로 + 대전) × 끈기 보너스

## 게임
| 게임 | 능력 |
|---|---|
| 여우 자리 찾기 | 논리력 |
| 스도쿠 | 집중력 |
| 구슬 블록깨기 | 공간지각 |
| 숲길 디펜스 | 전략력 |
| 함대 결전 | 추리력 |
| 동물 팡 (3매치) | 추리력 |
| 네모 그림 (노노그램) | 논리력 |
| 블록 채우기 | 공간지각 |
| 카드 짝 맞추기 | 집중력 |
| 숫자 합치기 (2048식) | 전략력 |

## 실행
`index.html` 파일 하나로 된 웹 프로토타입입니다. 브라우저로 열면 바로 플레이할 수 있습니다. 기록은 브라우저 저장소(localStorage)에만 남습니다.

GitHub Pages를 켜면(Settings → Pages → Branch: `main` / root) 링크로 공유할 수 있습니다.

## 공유·초대 링크
- 결과 카드·도전장·초대 링크는 `https://hyukcap-rgb.github.io/game/?n=보낸사람` 형식입니다. 도전장은 `&c=게임&d=날짜&s=점수&lv=난이도`가 붙어 같은 문제로 바로 시작합니다.
- 링크 미리보기 이미지는 `og.png`, 아이콘은 `icon.png`입니다.

## 실시간 대전 서버
함대 결전의 사람 대 사람 대전은 Railway에 올린 중계 서버(`server/index.ts`, Bun)를 거칩니다.
- 주소: `wss://battle-production-c11b.up.railway.app/ws` (상태 확인: `/stats`)
- Railway 프로젝트 `haru-puzzle-league` → 서비스 `battle` (Railway Function)
- 서버는 방마다 접속자와 각자 올린 작은 데이터만 전달하고, 게임 규칙은 브라우저가 처리합니다.
- 대전 탭의 다른 게임들도 같은 서버로 상대를 찾습니다(대기실에서 같은 게임끼리 짝 → `du-…` 방에서 진행도·결과 교환). 서버 코드는 바꿀 필요가 없습니다.
- Claude 링크로 열면 Claude의 room 기능을, 그 밖(GitHub Pages 등)에서는 이 서버를 씁니다. 연결이 안 되면 AI 대전으로 넘어갑니다.
- 서버 코드를 바꾸면 Railway의 `battle` 함수 코드도 같이 바꿔야 합니다.
