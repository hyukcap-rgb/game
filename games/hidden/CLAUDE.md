## 한 줄 소개
꾸밈 도형·선·무늬가 가득한 장면(숲속·바닷속·다락방·장터·꽃밭·눈 마을) 속에 숨은 물건을 아래 목록을 보고 찾아 누르는 집중력 게임(약 2분). 물건 26종(숟가락·열쇠·우산·물고기·별·안경·연필·양말·초승달·머그컵·종·망치·가위·장갑·모자·깃털·바나나·사과·양초·연·병·반지·장화·낚싯바늘·비행기·깃발)과 장면 꾸밈은 모두 직접 그린 오리지널 SVG.

## 규칙 (플레이어가 보는 것)
- 장면 아래 목록(아이콘+이름)의 물건을 장면에서 찾아 누르면 동그라미가 그려지고 목록에 ✔.
- 판정은 너그럽게: 물건 반지름 + 화면 14px(최소 화면 22px) 안이면 찾음. 확대하면 판정 반지름도 화면 기준으로 그대로.
- **빗나간 누르기 = 실수**: 점수 −15, 잠깐 못 누름(0.7초, 연속으로 빗나가면 1.05·1.4·1.75초까지) — 마구 누르기 막기. 장면 위에 빨간 ✕와 남은 시간이 줄어드는 "잠깐! 0.6초" 표시와 막대(`coolShow`).
- 💡 힌트: 남은 물건 하나의 **근처**(정확한 자리에서 조금 비켜서)를 2.6초 동안 밝힘(판마다 3번, 점수 −40). 확대 중이면 그쪽으로 화면을 옮김.
- 확대/이동: 오른쪽 아래 돋보기 +/− 단추(1배 ~ 3배), 두 손가락 벌리기, 마우스 휠. 확대 중에는 끌어서 이동(끌기는 누르기로 치지 않음).
- 제한 시간 안에 목록의 물건을 모두 찾으면 성공. 시간이 끝나면 못 찾은 물건 자리를 파란 점선 동그라미로 보여 줌.

## 판 만들기 (모든 판은 반드시 풀 수 있음)
`gen(cfg, rng)` — rng만 쓴다. 순서: 테마 → 물건 종류(`POOL` 섞기) → 물건 자리 → 움직임 → 배경 → 큰 꾸밈 → 작은 꾸밈 → 위 가는 선 → 걸치는 조각.
- 물건: 크기 = `size`×(0.88~1.1), 반지름 `IR(18)`×크기. 장면 가장자리 여백 안, **서로 겹치지 않게**(반지름 합 ×1.12, 250번 뒤 ×0.98), **오른쪽 아래 확대 단추 자리(`ZX`·`ZY`)는 피함**. 회전 −55~55°(20%는 거꾸로). 채움·포인트 색 = 테마 색(`T.c`), 선 = 테마 선 색(`T.k`)·굵기 2.2 → 꾸밈과 같은 선이라 섞여 숨는다.
- 꾸밈: 큰 꾸밈(`BIG`, 테마별 `big`·하늘 쪽 `up`) 약 `dens`×0.16개(+하늘), 작은 꾸밈(`SM`) `dens`개(크기 0.9~1.75배로 섞어 물건만 눈에 띄지 않게), 물건 **위**에 가는 선(`TOP`) `dens`×0.35개와 작은 조각 `dens`×0.12개(물건 중심 0.7r 안은 피함 → 모양은 늘 알아볼 수 있음).
- 꾸밈에는 물건과 닮은 모양(별·초승달·물고기 등)을 쓰지 않는다.
- `check()`: 모든 물건이 장면 안(움직임 포함)·서로 안 겹침·확대 단추 밖·목록 개수 일치 → `sc.ok`. 생성 점검 3,780판(난이도 3개 + 솔로 1~60판 × 씨앗 60개)에서 실패 0, 평균 약 8ms(최대 150ms 미만).

## 모드별 동작
**오늘의 문제·연습·대전**(`levels`):

| 난이도 | 물건 | 크기 | 꾸밈(dens) | 제한 시간 | 힌트 |
|---|---|---|---|---|---|
| easy | 7 | 1.02 | 90 | 120초 | 3 |
| normal | 9 | 0.9 | 120 | 150초 | 3 |
| hard | 11 | 0.8 | 150 | 180초 | 3 |

테마는 씨앗으로 6개 중 하나. 오늘의 시험지 과목(`SUBJ`)에는 아직 넣지 않음(제안: '집중' 과목).

**솔로**(`stageCfg(n)`, 개념 사이클 `planOf('hidden', n)`, 개념 표 `CONC`):

| 스테이지 | 종류 | 이름(key) | 내용 |
|---|---|---|---|
| 6 | 변주 | 번개(flash) | 시간 ×0.65 |
| 11 | 새 규칙 | 그림자 목록(shadow) | 목록에 이름 없이 까만 그림자만(찾으면 이름이 보임) |
| 16 | 변주 | 깨알(tiny) | 물건 ×0.8 크기, 꾸밈 ×1.25, 시간 ×1.2 |
| 21 | 새 규칙 | 여러 개 찾기(many) | 목록의 1종(k=5·10은 2종)이 ×3: 장면에 3개, 모두 찾아야 ✔ |
| 26 | 변주 | 맨손(bare) | 힌트 0 |
| 31 | 새 규칙 | 움직이는 물건(swim) | 물건 2개(k=5·10은 3개)가 진폭 18~30, 주기 5~9초로 왔다 갔다(장면 밖으로 안 나감) |
| 36 | 변주 | 차례대로(order) | 목록 순서대로만 찾음(차례 아닌 물건은 "차례가 아니에요", 벌칙 없음), 지금 차례 칸이 반짝임 |
| 41 | 새 규칙 | 밤 손전등(night) | 장면이 깜깜, 반지름 `LIGHT_R(66)` 불빛만 보임. 끌면 손전등 이동, 불빛 **밖**을 누르면 손전등만 옮겨 감(실수 아님), 불빛 **안**에서만 판정. 확대 단추 숨김 |
| 46 | 변주 | 외줄 타기(tight) | 기회 2번(두 번 빗나가면 끝) |

- 사이클 자리 k: 1 소개(쉬움) · 5 어려움 · 6 변주 소개 · 9 쉬어가기 · 10 보스. 51부터 리믹스.
- 물건 수: 챕터 1 = `LT.ch1[k−1]`(5·6·6·7·8·5·6·7·6·9), 챕터 2~ = `LT.base[c] + LT.kOff[k]`(기본 7·8·9·9·10), 5~12개. 크기 `LT.size[c]`(1.06 → 0.8), 꾸밈 `LT.dens[c]`(75 → 140), 어려움·보스는 크기 −0.05·꾸밈 +14, 쉬운 자리는 크기 +0.04·꾸밈 −10.
- 제한 시간 = (물건 + 여분 개수×0.5) × `LT.spp[c]`(15·14·13·12.5·12·11.5초) × `kTime[k]` × 규칙 배수(`mjTime`) × 변주 배수(`twTime`), 5초 단위, 최소 45초. **아직 봇·플레이 데이터로 맞추지 않은 첫 값**.
- 테마: 챕터별 숲속·바닷속·다락방·장터·눈 마을(`CH_THEME`), k=9(쉬어가기)는 꽃밭.
- 힌트 3(보스 2, 맨손 0).
- 챕터 이름: 숲속 소풍 · 바닷속 탐험 · 다락방 보물 · 왁자지껄 장터 · 눈꽃 마을.

**별**: 힌트 0이고 실수 ≤1 → ★★★, 힌트 ≤1이고 실수 ≤4 → ★★, 그 외 ★.

**대전**: normal(물건 9개, 150초), 같은 씨앗 = 같은 장면. 기본 대전 방식(먼저 다 찾은 쪽 점수, 둘 다 못 찾으면 진행도). 대전은 기회 제한 없음(`lives:0`). `duelStat = { unit:'개', v:찾은 개수, t:전체 개수 }`, `duelPace:[105, .75]`, `duelHow:'같은 장면에서 누가 먼저 다 찾나'`.

## 점수
엔진 `calcScore()` = round((base + time + extra) × 배율). `score()`:
- base 500
- time = max(0, 350 − floor(sec × 350 / 제한 시간))
- extra = max(0, 150 − 40×힌트 − 15×실수)

## 고칠 때 지킬 것
- 장면·물건 자리·색은 **`init`의 rng에서만**(Math.random 금지). 힌트 위치는 rng에서 뽑은 씨앗의 별도 난수(`m.hr`).
- `gen`의 rng 쓰는 순서, `POOL`·`TK`·각 목록 순서를 바꾸면 같은 씨앗의 장면이 달라진다(물건·테마 추가는 끝에).
- 물건 모양을 바꾸면 반지름 18 안에 들어오는지, 꾸밈과 헷갈리지 않는지 본다. 꾸밈에 물건과 닮은 모양을 넣지 않는다.
- 판정은 `hitAt`의 장면 좌표 거리로만 한다(DOM 눌림 아님) → 꾸밈이 위를 덮어도 눌린다. 그래도 위에 얹는 조각은 물건 중심을 피한다.
- NG.hidden 계약과 `duelStat`을 지킨다. CSS는 `css` 문자열 안에만, `.ng-hidden` / `body[data-mode="hidden"]`로 범위를 묶는다(키프레임 `hidden-…`).
- 그림·이름은 오리지널만(docs/13_법무검토_IP.md).

## 확인 방법
- `node tools/build.js` → index.html 목록과 `embed/hidden.html` 다시 만들기.
- 브라우저: `index.html`, `embed/hidden.html?mode=daily|practice|solo|duel`(옵션 `&level=…`, `&stage=n&unlock=1`).
- `npm test -- hidden` (사이트·모듈에서 모든 모드를 한 판씩 자동 점검).
- 생성 점검(콘솔): `NG.hidden._gen(NG.hidden._stage(n), mulberry(1)).ok`, 게임 중 `NG.hidden._solveForTest()`로 끝까지 자동 풀기.
