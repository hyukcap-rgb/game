## 한 줄 소개
(v2.0) 세계 여행 그림책 장면 20곳(서울·도쿄·베이징·방콕·하노이·타지마할·싱가포르·두바이·카이로·이스탄불·파리·런던·로마·바르셀로나·산토리니·암스테르담·알프스·뉴욕·리우·시드니) 속에서, 그림에 원래 그려져 있는 물건(장면마다 12개)을 아래 목록을 보고 찾아 누르는 집중력 게임(약 2분). **2026-10-10부터 모든 모드(오늘의 문제·연습·솔로·대전)가 이 장면만 쓴다.** 예전 그림(직접 그린 SVG 장면)은 지웠다.

## 규칙 (플레이어가 보는 것)
- 장면 아래 목록(그림에서 잘라 낸 아이콘 + 이름)의 물건을 장면에서 찾아 누르면 동그라미가 그려지고 목록에 ✔.
- 판정은 너그럽게: 물건 반지름 + 화면 14px(최소 화면 22px) 안이면 찾음. 확대하면 판정 반지름도 화면 기준으로 그대로.
- **빗나간 누르기 = 실수**: 점수 −15, 잠깐 못 누름(0.7초, 연속으로 빗나가면 1.05·1.4·1.75초까지) — 마구 누르기 막기. 장면 위에 빨간 ✕와 "잠깐! 0.6초" 표시와 막대(`coolShow`).
- 💡 힌트: 남은 물건 하나의 **근처**를 2.6초 동안 밝힘(판마다 3번, 점수 −40). 확대 중이면 그쪽으로 화면을 옮김.
- 확대/이동: 오른쪽 아래 돋보기 +/− 단추(1배 ~ 3배), 두 손가락 벌리기, 마우스 휠. 확대 중에는 끌어서 이동.
- 제한 시간 안에 목록의 물건을 모두 찾으면 성공. 시간이 끝나면 못 찾은 물건 자리를 파란 점선 동그라미로 보여 줌.

## 장면(v2.0) — `hidden-photo.js` + `img/` + `gen3`
- 그림: `img/<key>.webp`(960×1280, 세로 3:4, 장면당 약 0.5MB) — AI 일러스트(Figma 이미지 생성, 2026-10-10). 실제 유명 캐릭터가 섞인 그림(뉴욕·도쿄 1차본)은 버리고 다시 만듦.
- 그림 주소: 사이트는 `games/hidden/img/`, 모듈(`embed/hidden.html`)은 `../games/hidden/img/`(`HIDDEN_PHOTO.src`). 그림은 빌드에 넣지 않고 GitHub Pages에서 따로 받는다(모듈 크기 그대로).
- 물건: 장면마다 그림 속 물건 12개 `[id, 이름, x, y, 반지름]`(장면 좌표 360×480 = 그림 픽셀 × 0.375). 사람이 확대해서 하나씩 확인한 값(그림 안에 하나뿐인 것만, 장면 위아래 끝·확대 단추 자리 피함). **그림을 바꾸면 좌표도 다시 잡아야 한다.**
- 목록 아이콘: `img/icons_<key>.webp`(4×3칸, 칸마다 96px, 물건 순서대로) — 그 물건을 그림에서 잘라 낸 것. 그림자 목록은 같은 아이콘을 까맣게(`.hd-ph.sh`).
- `gen3(cfg, rng, 장면)`: 장면의 물건 12개를 rng로 섞어 앞에서 `items`개(서로 다른 물건, 겹침 없음). 물건은 따로 그리지 않음(그림 속에 있음). `cfg.mirror`면 그림 좌우 반전·x를 뒤집음, `cfg.gray`면 흑백(SVG 색 필터).
- 장면 고르기: 오늘의 문제·연습 = 씨앗으로 20곳 중 하나. 솔로 = 챕터별 장면 4곳을 차례로(`CH_SCENE`). 대전 = 최근 본 장면 3개(`G.duel.avoid`)를 빼고 rng로.

## 점수
엔진 `calcScore()` = round((base + time + extra) × 배율). `score()`:
- base 500
- time = max(0, 350 − floor(sec × 350 / 제한 시간))
- extra = max(0, 150 − 40×힌트 − 15×실수)

## 고칠 때 지킬 것
- 장면·물건 고르기는 **`init`의 rng에서만**(Math.random 금지). 힌트 위치는 rng에서 뽑은 씨앗의 별도 난수(`m.hr`).
- `HIDDEN_PHOTO.SC`의 장면 순서·물건 순서를 바꾸면 같은 씨앗의 판이 달라진다(장면 추가는 끝에). 아이콘 판 칸 순서 = 물건 순서.
- 그림을 바꾸거나 새 장면을 넣으면 물건 좌표·아이콘 판을 다시 만들고, 실제 유명 캐릭터·상표·글자가 그림에 없는지 확인한다.
- 판정은 `hitAt`의 장면 좌표 거리로만 한다(DOM 눌림 아님).
- NG.hidden 계약과 `duelStat`을 지킨다. CSS는 `css` 문자열 안에만, `.ng-hidden` / `body[data-mode="hidden"]`로 범위를 묶는다(키프레임 `hidden-…`).

## 확인 방법
