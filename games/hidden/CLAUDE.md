## 규칙 (플레이어가 보는 것)
- 장면 아래 목록(아이콘+이름)의 물건을 장면에서 찾아 누르면 동그라미가 그려지고 목록에 ✔.
- 판정은 너그럽게: 물건 반지름 + 화면 14px(최소 화면 22px) 안이면 찾음. 확대하면 판정 반지름도 화면 기준으로 그대로.
- **빗나간 누르기 = 실수**: 점수 −15, 잠깐 못 누름(0.7초, 연속으로 빗나가면 1.05·1.4·1.75초까지) — 마구 누르기 막기. 장면 위에 빨간 ✕와 남은 시간이 줄어드는 "잠깐! 0.6초" 표시와 막대(`coolShow`).
- 💡 힌트: 남은 물건 하나의 **근처**(정확한 자리에서 조금 비켜서)를 2.6초 동안 밝힘(판마다 3번, 점수 −40). 확대 중이면 그쪽으로 화면을 옮김.
- 확대/이동: 오른쪽 아래 돋보기 +/− 단추(1배 ~ 3배), 두 손가락 벌리기, 마우스 휠. 확대 중에는 끌어서 이동(끌기는 누르기로 치지 않음).
- 제한 시간 안에 목록의 물건을 모두 찾으면 성공. 시간이 끝나면 못 찾은 물건 자리를 파란 점선 동그라미로 보여 줌.

## 새 장면(v1.1) — `hidden-art.js` + `gen2`
- 장면 = `HIDDEN_ART.SC`의 12개(`key`·`name`·`ban`(장면에 그려진 것과 헷갈리는 물건 빼기)·`noSpot`(하늘·글자 등 숨기지 않을 곳)·`draw(u)`). 3층 구도, 외곽선 한 색 `#2D2440`·2.2, 반복 무늬는 고정 씨앗(문제와 무관).
- 색 규칙(디자인팀 11-4): 광택(흰 빛 `Hl`)·그라데이션 없음(`grad`는 두 색 가운데 **단색**), 넓은 면과 밝은 색(명도 74% 이상)은 `calm()`으로 HSL 채도 0.35 이하(불빛 색 `LIGHTS`만 예외). 장면 그림은 한 번 그려 캐시(`svgOf`, id 자리 `UQZ`).
- 디자인 점검(2026-10-06, 360×480 그려서 잼): 평균 명도 공원 69·교실 62·부엌 73·도서관 61·시장 65·장터 69·김장 67·바닷가 75·캠핑 67·놀이공원 75·기차역 66·눈 마을 80, 면적 1% 넘는 유채색 계열 4~7개, 넓은 배경 면 채도 ≤35%.
- `ban`(장면에 그려진 것과 같은 물건은 숨기지 않음): 공원 새 / 교실 연필·물고기·시계 / 부엌 숟가락·컵 / 도서관 연필·시계 / 시장 사과·물고기·당근·컵 / 장터 달·사과 / 김장 장갑·사과·당근 / 바닷가 우산·깃발·별·물고기 / 캠핑 촛불·전구 / 놀이공원 깃발·풍선 / 기차역 종·시계·새 / 눈 마을 모자·장갑·양말·새.
- 숨길 자리 `SPOTS`(장면마다 30~36곳): `node games/hidden/art-tool.mjs`가 그림을 브라우저로 그려 뽑아 `@spots` 구역에 적는다(손으로 고치지 않기, **그림을 고치면 꼭 다시 실행**). 자리 = 선 밀도 5~32%, 사람 얼굴(`kid()`가 자동 등록)·noSpot·확대 단추 자리(`ZX 72`·`ZY 140`) 밖, 자리끼리 44 이상 떨어짐 → 어느 자리를 골라도 물건이 겹치지 않음.
- `gen2(cfg, rng, 장면)`: 물건 종류(`POOL2` 30종 − `ban`, 한 장면에 같은 물건 한 번만 — 솔로 '여러 개 찾기'만 ×3) → 자리 순서(난수 + `busy`×선 밀도: 쉬움은 빈 곳, 어려움은 복잡한 곳) → 크기 `IR×size`(반지름 `minR`~20, `minR` 14 = 화면 28px, 쉬움 16 = 32px) → 물건 색 = 자리 바탕색에서 밝기만 `tone`만큼(밝은 바탕엔 어둡게), 외곽선 = 장면 선 색을 바탕색 쪽으로 `ink`만큼 섞음, 기울기 ±`rot`(어려움만).
- 예전 장면(`gen`)은 예전 물건 26종 `POOL`(순서 고정)을 그대로 쓴다. 새 물건 12종은 `ITEMS`에 더하기만 했다(이름만 '초승달→달', '머그컵→컵', '양초→촛불').
- 물건마다 고유 번호 `i`·종류 `k` → 다음 단계 "선점 대전"에서 `duelClaim('o'+i)`로 쓰기 좋게 해 둠(이번엔 만들지 않음).
- 생성 점검(2026-10-06): 장면 12 × 난이도 3 × 씨앗 1,000 + 솔로 1~60판 × 씨앗 5 = 39,600판 — 실패 0, 겹침 0, 자리 모자람 0, 28px 미만 0, 쉬움 32px 미만 0, 보통·쉬움 기울기 0, ban 물건 0, 같은 물건 두 번 0, 30종 모두 나옴, 평균 0.5ms.

- 장면 고르기: 오늘의 문제·연습 = 씨앗으로 12개 중 하나(2026-10-07부터, `NEW_FROM`). 솔로 = 챕터별 장면(`CH_SCENE`: 공원·캠핑 / 바닷가·놀이공원 / 교실·부엌·도서관 / 시장·장터·김장 / 눈 마을·기차역, 챕터 안에서 차례로, k=9 쉬어가기는 공원). 솔로 표 `LT.tone·rot·busy·ink`로 챕터마다 조금씩 어려워짐(밝기 차 .25~.33 → .15~.20, 최소 .15. 어려움·보스 자리는 −0.02, 쉬운 자리 +0.03). 기울기는 어려움·보스 자리에만(챕터 12° → 25°), 챕터 1과 쉬운 자리는 최소 반지름 16.
- **다시 대전 = 같은 그림 고침**(v1.2부터 엔진: 판마다 새 씨앗 + `G.duel.avoid` 최근 장면 3개 피하기. 아래는 v1.1 기록, `duelBoard`는 없앰): 컴퓨터 대전은 이 기기에서 최근 본 장면 3개(`hp:hidden:seen`)를 피함. 실시간 대전은 같은 상대와 다시 하면 씨앗(`du-두 사람:날짜`)이 같아서, 이 씨앗으로 몇 번째 판인지(`hp:hidden:rounds`, 두 기기가 똑같이 셈)를 씨앗에 붙이고(`#r1`…) 앞 판 장면 3개를 피함 → 두 사람 같은 판 + 매번 다른 장면. 공용 엔진이 `G.duel.avoid`(또는 `cf.av`)를 주면 그것도 피하고, 판 번호 `G.duel.round`를 주면(대전 v3) 기기마다 센 값 대신 그것을 쓴다. 날짜가 `NEW_FROM` 전이면 예전 장면에도 같은 판 번호 씨앗을 쓴다. 점검(2026-10-06, 사람 둘 브라우저, 날짜 10-07): 같은 두 사람 10판 연속 → 씨앗 10번 같음, 장면 캠핑→눈→도서관→시장→김장→캠핑→놀이공원→교실→눈→시장(연달아 같은 장면 0), 두 사람 늘 같은 판.
- 화면(v1.1): 찾을 목록 한 줄 가로 칸(64×54, 남은 물건이 앞, 넘치면 옆으로 밀기·오른쪽 흐림), 확대 단추 56px, 첫 3판은 "돋보기로 크게 볼 수 있어요" 말풍선(5초), 찾으면 동그라미가 크게 튀며 그려짐(반지름 +8, 굵기 4.6) + 반짝 고리 2개. 대전은 빗나가면 1.5초부터 못 누름(막 누르기 막기). 도움말 = 그림 1장 + 3줄.

## 판 만들기 (예전 장면 legacy — 모든 판은 반드시 풀 수 있음)
`gen(cfg, rng)` — rng만 쓴다. 순서: 테마 → 물건 종류(`POOL` 섞기) → 물건 자리 → 움직임 → 배경 → 큰 꾸밈 → 작은 꾸밈 → 위 가는 선 → 걸치는 조각.
- 물건: 크기 = `size`×(0.88~1.1), 반지름 `IR(18)`×크기. 장면 가장자리 여백 안, **서로 겹치지 않게**(반지름 합 ×1.12, 250번 뒤 ×0.98), **오른쪽 아래 확대 단추 자리(`ZX`·`ZY`)는 피함**. 회전 −55~55°(20%는 거꾸로). 채움·포인트 색 = 테마 색(`T.c`), 선 = 테마 선 색(`T.k`)·굵기 2.2 → 꾸밈과 같은 선이라 섞여 숨는다.
- 꾸밈: 큰 꾸밈(`BIG`, 테마별 `big`·하늘 쪽 `up`) 약 `dens`×0.16개(+하늘), 작은 꾸밈(`SM`) `dens`개(크기 0.9~1.75배로 섞어 물건만 눈에 띄지 않게), 물건 **위**에 가는 선(`TOP`) `dens`×0.35개와 작은 조각 `dens`×0.12개(물건 중심 0.7r 안은 피함 → 모양은 늘 알아볼 수 있음).
- 꾸밈에는 물건과 닮은 모양(별·초승달·물고기 등)을 쓰지 않는다.
- `check()`: 모든 물건이 장면 안(움직임 포함)·서로 안 겹침·확대 단추 밖·목록 개수 일치 → `sc.ok`. 생성 점검 3,780판(난이도 3개 + 솔로 1~60판 × 씨앗 60개)에서 실패 0, 평균 약 8ms(최대 150ms 미만).

## 고칠 때 지킬 것
- 장면·물건 자리·색은 **`init`의 rng에서만**(Math.random 금지). 힌트 위치는 rng에서 뽑은 씨앗의 별도 난수(`m.hr`).
- 새 장면 그림을 고치면 `node games/hidden/art-tool.mjs`로 숨길 자리를 다시 뽑는다. 장면에 물건과 닮은 것을 그리면 그 물건을 `ban`에 넣는다. 사람은 `kid()`로 그려야 얼굴 자리가 자동으로 빠진다.
- `gen`의 rng 쓰는 순서, `POOL`·`TK`·각 목록 순서를 바꾸면 같은 씨앗의 장면이 달라진다(물건·테마 추가는 끝에).
- 물건 모양을 바꾸면 반지름 18 안에 들어오는지, 꾸밈과 헷갈리지 않는지 본다. 꾸밈에 물건과 닮은 모양을 넣지 않는다.
- 판정은 `hitAt`의 장면 좌표 거리로만 한다(DOM 눌림 아님) → 꾸밈이 위를 덮어도 눌린다. 그래도 위에 얹는 조각은 물건 중심을 피한다.
- NG.hidden 계약과 `duelStat`을 지킨다. CSS는 `css` 문자열 안에만, `.ng-hidden` / `body[data-mode="hidden"]`로 범위를 묶는다(키프레임 `hidden-…`).
- 그림·이름은 오리지널만(docs/13_법무검토_IP.md).
