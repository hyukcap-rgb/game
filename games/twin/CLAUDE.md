## 한 줄 소개
위·아래 둥근 카드 두 장에 그림이 흩어져 있고, 두 카드에 **똑같은 그림이 딱 하나** 있다. 그 그림을 찾아 누르는 순발력 게임(능력: 순발력, 약 2분). 맞히면 위 카드가 아래로 내려오고 새 카드가 위로 날아 들어온다. 그림 39종 = 공용 3D 캐릭터 12종 + 직접 그린 사물 27종(사과·별·달·우산·열쇠·컵…), 그림마다 색만 다른 짝이 있다(닮은꼴 함정). 배경 세계는 장난감 방 책상(차분한 나무색, 햇빛 먼지).

## 규칙 (플레이어가 보는 것)
- 한 판 = 카드 N장(문제 N개). 같은 씨앗이면 모두 같은 카드를 같은 순서로 받는다.
- 문제마다 **판단 시간(창)**: 위쪽 막대가 초록 → 노랑 → 빨강으로 줄고, 남은 0.4초부터 떨린다. 판 안에서 뒤로 갈수록 창이 짧아지고 함정이 늘어난다.
- **같은 그림이라도 카드마다 크기가 다를 수 있다**(크기 차이 = 난이도, 아래 표). 크기·방향이 달라도 모양과 색이 같으면 쌍둥이.
- 같은 그림을 **어느 카드에서든** 누르면 정답: 두 카드의 그 그림이 초록 고리로 반짝 + 두 그림을 잇는 노란 "쌍둥이 실", "+점수", 진행자 기쁨 표정.
- 다른 그림 = 바로 오답, 창이 끝남 = 시간 초과 오답: 누른 그림에 빨간 ✕, 정답 그림에 노란 점선 + 점선 실(가르쳐 주기), 화면 가장자리 붉게, 짧은 흔들림, 기회 별 −1. 판정 뒤 다음 카드까지 정답 0.38초 · 오답 0.6초(0.5초 잠금 포함, 판단 시간에 안 들어감).
- 카드 빈 곳 누르기 = 아무 일 없음. 0.25초 안에 3번 넘게 누르면 "천천히!" + 0.5초 잠금(벌점 없음, 그동안 창은 계속 흐름).
- **기회 3개**(공용 `.hlives` 별). 0이면 실패, N장을 다 하면 성공. 외줄 타기 변주는 기회 2개.
- 말풍선 판정 문구: 닮은꼴 가짜를 누르면 "색이 다른 가짜!", 세 장 규칙에서 두 장에만 있는 그림을 누르면 "두 장에만 있어요". 평소 말풍선 = 이번 판 규칙 알림(짧으면 두 개, 길면 카드마다 번갈아).
- 연속 정답 5·10·20(그 뒤 10마다): "좋아요!/대단해요!/완벽해요!" + 칩·판 펀치 + 팡파르(점수엔 영향 없음).
- 성공하면 판 위에 "평균 판단 속도 · 내 최고"(새 기록이면 "새 최고 기록!")를 1.3초 보여 주고 결과 창.

## 카드 만들기 (rng만, 공통 그림은 늘 정확히 하나)
`gen(cfg, rng)`:
- 그림 번호 `id = 그림×2 + 색 변형`. `id ^ 1` = 색만 다른 가짜. 같은 그림 = 번호와 색이 모두 같음.
- 두 장(기본): 첫 아래 카드를 만든 뒤, 문제마다 새 위 카드 = 아래 카드의 그림 하나(바로 전 정답 제외)가 정답 + (함정이면) 아래 카드 그림 1~2개의 색 가짜 + 아래 카드에 없는 그림으로 채움. 문제 i의 아래 카드 = 문제 i−1의 위 카드.
- 세 장: 세 장 모두에 있는 그림 1개 + 두 장에만 있는 가짜 1~3개 + (함정이면) 색 가짜 + 나머지는 겹치지 않는 그림. 문제마다 세 장 모두 새로.
- 함정 확률(문제 i) = trap × (0.4 + 1.2 × i/(N−1)), 최대 0.9 → 평균은 trap, 뒤로 갈수록 많아짐.
- **크기(v1.1)**: 판 설정 `sz:[작게, 크게]`(그림 크기 배율 범위, 다른 그림도 모두 이 안에서 제각각), `gap`(공통 그림이 카드끼리 적어도 이만큼 다름: 큰 것/작은 것 ≥ 1 + gap), `lure`(닮은꼴 가짜를 원래 그림과 거의 같은 크기 0.94~1.06배로 → 크기로 짝 맞추는 눈을 속임), `tilt`(기울기 폭).
  - 두 장: 새 위 카드의 정답 크기 = 아래 카드의 그 그림 반지름 × 또는 ÷ (1+gap)×(1.03~1.2)(둘 다 되면 rng, 안 되는 쪽은 피함). 자리가 모자라 줄어들어 차이가 모자라면 작게 하는 쪽으로 다시, 그래도 안 되면 크게 + 다른 그림 줄이기(최대 6번, rng로 다시 배치).
  - 세 장: 공통 그림을 작게·중간·크게로 세 장에 나눔(가장 큰 것/가장 작은 것 ≥ 1 + gap), 모자라면 같은 방식으로 다시.
- 배치 `layout`: 그림 수별 자리 틀(`TPL`: 가운데 1 + 둘레, 반지름 R·그림 반지름 s) → 둘레 회전·자리 섞기·작은 흔들림(rng) → 크기(`sz`, 없으면 0.93~1.07) → 정해 둔 크기(정답·가짜) → 바닥·한계 → `relax`로 겹침 밀어내기(rng 안 씀, 안 되면 정해 두지 않은 그림부터 0.94배로 줄여 다시). 그림끼리 틈 0.03, 카드 안쪽 0.9 안.
- 그리는 반지름 `r`과 **누르는 자리 반지름 `b` = max(r, HB)** 가 따로: 배치는 `b`끼리 안 겹치게 하므로 작은 그림도 자기만의 누르는 자리를 가진다. HB = 두 장 0.19 · 세 장 0.225(카드 반지름 = 1), 그리는 바닥 RMIN = 두 장 0.135 · 세 장 0.16, 가장 큰 반지름 0.42, 누르는 자리 넓이 합 ≤ 카드 안쪽의 56%.
  - 가장 작은 카드(360×740: 두 장 지름 228px, 세 장 188px)에서 그리기 최소 지름 약 30px, 누르는 자리 최소 지름 42px.
- 점검 `_check(P, cfg)`: 공통 그림 정확히 1개(= 정답), 한 카드 안 같은 그림 없음, 누르는 자리까지 겹침 없음, 크기 바닥(r ≥ RMIN, b ≥ HB), 크기 차이(`gap`), 함정 아닌 문제는 색 가짜도 없음. `_ratio(p)` = 공통 그림 크기비(가장 큰 것/가장 작은 것).
- 누르는 자리: 반지름 = max(b × 1.05, 20px), 가장 가까운 그림(거리/한계 비율)으로(누르는 자리가 안 겹쳐서 자기 자리 안이면 늘 그 그림). 판정은 카드 **제자리**(`slot`) 기준이라 날아오는 효과가 느린 폰에서 밀려도 엉뚱한 카드가 눌리지 않는다.

## 점수
엔진 `calcScore()` = round((base + time + extra) × 배율). `score()`:
- base = 500 × 정답 수 / N
- time = 350 × (정답 문제의 남은 창 비율 합) / N (오답은 0으로 평균에 들어감 → 막 누르는 사람이 못 이김)
- extra = 50 × 남은 기회(최대 150)
- 줄: `정답 a/N` · `판단 속도 보너스 (평균 0.xx초)` · `남은 기회 n개`
- 내 최고 평균 판단 속도: `store` `hp:twin:best`(초, 성공한 판만).

## 고칠 때 지킬 것
- 카드 내용·배치는 **주어진 rng에서만**(Math.random 금지, 공용 효과 연출 안쪽만 예외). `gen`/`layout`의 rng 쓰는 순서, `TWIN_ART.S` 순서·색 묶음을 바꾸면 같은 씨앗의 카드가 달라진다(새 그림은 끝에 더하기).
- 새 그림: 0..100 안, 외곽선 없이 색 하나 + 큰 실루엣, TOY 필터(pb·pm·ps)와 `GL` 하이라이트, 바닥 그림자는 `SHD()`로(카드에서는 자동으로 빠짐). 색 짝은 한눈에 다른 색으로. 하트 모양 금지(사이트 재화).
- 배치·크기 규칙을 바꾸면 `tools/twin-check.mjs`로 실패 0과 가장 작은 그림·누르는 자리(지름 40px 이상)를 다시 본다. 화면 틀(HUD 줄 수 등)이 바뀌어 가장 작은 카드가 작아지면 도구의 `RPX`와 `HB`를 같이 맞춘다.
- 디자인: 눈이 편하게(차분한 나무색 책상, 강한 대비·번쩍임 적게), 판정 순간만 또렷하게(쌍둥이 실·초록 고리). 판 아래쪽은 화면 틀 여백을 조금 끌어 써서(`.ng-twin` margin-bottom −30px) 카드를 키우고, 390×844·360×740에서 스크롤이 없어야 한다.
- 효과는 보이기만(`try{}catch(_){}`, `pointer-events:none`), 동작 줄이기(`FXR.reduce`·prefers-reduced-motion)면 흔들림·파티클·날아오기 없이 색 표시만.
- CSS는 `css` 문자열 안에, `.ng-twin` / `body[data-mode="twin"]`로 범위(키프레임 `twin-…`). 도움말 그림은 `.tw-hp`(대전 규칙 목록에서는 숨김).
- 새 문구에 대시(—, –) 쓰지 않기. 상용 게임 이름·그림 금지(docs/13).
