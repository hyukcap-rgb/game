## 한 줄 소개
위·아래 둥근 카드 두 장에 그림이 흩어져 있고, 두 카드에 **똑같은 그림이 딱 하나** 있다. 그 그림을 찾아 누르는 순발력 게임(능력: 순발력, 약 2분). 맞히면 위 카드가 아래로 내려오고 새 카드가 위로 날아 들어온다. 그림 39종 = 공용 3D 캐릭터 12종 + 직접 그린 사물 27종(사과·별·달·우산·열쇠·컵…), 그림마다 색만 다른 짝이 있다(닮은꼴 함정). 배경 세계는 장난감 방 책상(차분한 나무색, 햇빛 먼지).

## 규칙 (플레이어가 보는 것)
- 한 판 = 카드 N장(문제 N개). 같은 씨앗이면 모두 같은 카드를 같은 순서로 받는다.
- 문제마다 **판단 시간(창)**: 위쪽 막대가 초록 → 노랑 → 빨강으로 줄고, 남은 0.4초부터 떨린다. 판 안에서 뒤로 갈수록 창이 짧아지고 함정이 늘어난다.
- 같은 그림을 **어느 카드에서든** 누르면 정답: 두 카드의 그 그림이 초록 고리로 반짝, "+점수", 진행자 기쁨 표정.
- 다른 그림 = 바로 오답, 창이 끝남 = 시간 초과 오답: 누른 그림에 빨간 ✕, 정답 그림에 노란 점선(가르쳐 주기), 화면 가장자리 붉게, 짧은 흔들림, 기회 별 −1. 판정 뒤 다음 카드까지 정답 0.38초 · 오답 0.6초(0.5초 잠금 포함, 판단 시간에 안 들어감).
- 카드 빈 곳 누르기 = 아무 일 없음. 0.25초 안에 3번 넘게 누르면 "천천히!" + 0.5초 잠금(벌점 없음, 그동안 창은 계속 흐름).
- **기회 3개**(공용 `.hlives` 별). 0이면 실패, N장을 다 하면 성공. 외줄 타기 변주는 기회 2개.
- 말풍선 판정 문구: 닮은꼴 가짜를 누르면 "색이 다른 가짜!", 세 장 규칙에서 두 장에만 있는 그림을 누르면 "두 장에만 있어요".
- 연속 정답 5·10·20(그 뒤 10마다): "좋아요!/대단해요!/완벽해요!" + 칩·판 펀치 + 팡파르(점수엔 영향 없음).
- 성공하면 판 위에 "평균 판단 속도 · 내 최고"(새 기록이면 "새 최고 기록!")를 1.3초 보여 주고 결과 창.

## 카드 만들기 (rng만, 공통 그림은 늘 정확히 하나)
`gen(cfg, rng)`:
- 그림 번호 `id = 그림×2 + 색 변형`. `id ^ 1` = 색만 다른 가짜. 같은 그림 = 번호와 색이 모두 같음.
- 두 장(기본): 첫 아래 카드를 만든 뒤, 문제마다 새 위 카드 = 아래 카드의 그림 하나(바로 전 정답 제외)가 정답 + (함정이면) 아래 카드 그림 1~2개의 색 가짜 + 아래 카드에 없는 그림으로 채움. 문제 i의 아래 카드 = 문제 i−1의 위 카드.
- 세 장: 세 장 모두에 있는 그림 1개 + 두 장에만 있는 가짜 1~3개 + (함정이면) 색 가짜 + 나머지는 겹치지 않는 그림. 문제마다 세 장 모두 새로.
- 함정 확률(문제 i) = trap × (0.4 + 1.2 × i/(N−1)), 최대 0.9 → 평균은 trap, 뒤로 갈수록 많아짐.
- 배치 `layout`: 그림 수별 자리 틀(`TPL`: 가운데 1 + 둘레, 반지름 R·그림 반지름 s) → 둘레 회전·자리 섞기·작은 흔들림(rng) → 크기(기본 0.93~1.07, 크고 작게 0.62~1.38) → `relax`로 겹침 밀어내기(rng 안 씀, 안 되면 모두 0.94배로 줄여 다시). 그림끼리 틈 0.03, 카드 안쪽 0.9 안.
- 점검 `_check(P)`: 공통 그림 정확히 1개(= 정답), 한 카드 안 같은 그림 없음, 겹침 없음, 함정 아닌 문제는 색 가짜도 없음. 3,000+ 씨앗 × 난이도 3개 + 스테이지 1~70 × 60 씨앗(약 20만 문제)에서 실패 0, 같은 씨앗 = 같은 카드.
- 누르는 자리: 그림 반지름 × 1.08, 최소 반지름 22px(지름 44px). 가장 가까운 그림(거리/한계 비율)으로. 판정은 카드 **제자리**(`slot`) 기준이라 날아오는 효과가 느린 폰에서 밀려도 엉뚱한 카드가 눌리지 않는다.

## 모드별 동작
**오늘의 문제·연습·대전**(`levels`, 시간 제한 없음 `limit:0`). 닮은꼴 함정은 처음부터 섞임(이 게임의 판단 포인트, 도움말 3번에 그림으로 설명).

| 난이도 | 카드 N | 그림 수 | 판단 창(시작 → 끝) | 함정 |
|---|---|---|---|---|
| easy | 20 | 5 | 6.0 → 4.5초 | 15% |
| normal | 25 | 6 | 5.0 → 3.5초 | 25% |
| hard | 30 | 7 | 4.2 → 3.0초 | 35% |

오늘의 시험지 과목(`SUBJ`)에는 아직 넣지 않음(사용자 확인 후). 진행자: 부엉이.

**솔로**(`stageCfg(n)`, 개념 사이클 `planOf('twin', n)`):

| 스테이지 | 종류 | 이름(key) | 내용 |
|---|---|---|---|
| 6·36 | 변주 | 빠른 판(flash) | 판단 창 ×0.75 |
| 11 | 새 규칙 | 빙글(spin) | 그림이 제각각 −180~180° 돌아감(바닥 그림자는 돌지 않음) |
| 16·46 | 변주 | 깜빡(blink) | 카드가 0.6초 보이고 0.3초 덮임(문제 시작 기준), 덮인 동안 누르기 무시(벌칙 없음) |
| 21 | 새 규칙 | 크고 작게(size) | 그림 크기 0.6~1.4배 |
| 26 | 변주 | 외줄 타기(tight) | 기회 2개 |
| 31 | 새 규칙 | 닮은꼴(look) | 색만 다른 가짜가 섞임(이 규칙이 켜진 판만 함정) |
| 41 | 새 규칙 | 세 장(three) | 카드 3장(지그재그 배치), 세 장 모두에 있는 그림. 그림 수 최대 6 |

- 카드 수 = min(32, 12 + 2×(챕터−1) + `KOFF[k]`), KOFF = 0·1·2·3·4·1·4·5·2·6(k=1~10) → 챕터 1은 12장에서 18장(보스 = 기본+6).
- 그림 수 = 4 + (챕터−1)(최대 8), k≥4 +1, 쉬운 자리(k=1·6·9) −1, 4~8.
- 판단 창 = 6.2초 × 0.94^(챕터−1) × (0.55 + 0.075×그림 수) × 자리(k5 ×0.9 · 보스 ×0.85 · k9 ×1.15 · k1·k6 ×1.08) × 규칙(빙글 1.08 · 크기 1.05 · 닮은꼴 1.1 · 세 장 1.35) × 번개 0.75. 끝 창 = 시작 × 0.75. 바닥: 시작 2.6초 · 끝 2.2초(그림 찾기라 다른 순발력 게임보다 높음). **아직 플레이 데이터로 맞추지 않은 첫 값.**
- 함정(닮은꼴 판만) = 0.1 + 0.075×(챕터−1), 보스 +0.1, 최대 0.5.
- 챕터 이름: 장난감 상자 · 소풍 바구니 · 별빛 서랍 · 거울 방 · 쌍둥이 성 / 진행자: owl · cat · rabbit · panda · fox(진행자마다 말투·카드 테두리 색 `HOST_LOOK`). 보스 판: 진행자 'wow' 표정 + 붉은 띠 + "보스!" 딱지 + 보스 소리.

**별**: 오답(시간 초과 포함) 0 → ★★★, 1 → ★★, 그 외 ★.

**대전**: normal 설정(25장) 같은 씨앗 = 같은 카드, 끝났을 때 점수가 높은 쪽 승(엔진 기본 대전). 카운트다운 동안 `G.paused`라 첫 카드는 시작 뒤에 나온다. `duelStat = { unit:'개', lfMax:3, v:정답 수, t:N, lf:남은 기회 }`, `duelPace:[60, .78]`, `duelHow:'같은 카드 · 정확하고 빠르게 찾으면 승리'`.

## 점수
엔진 `calcScore()` = round((base + time + extra) × 배율). `score()`:
- base = 500 × 정답 수 / N
- time = 350 × (정답 문제의 남은 창 비율 합) / N (오답은 0으로 평균에 들어감 → 막 누르는 사람이 못 이김)
- extra = 50 × 남은 기회(최대 150)
- 줄: `정답 a/N` · `판단 속도 보너스 (평균 0.xx초)` · `남은 기회 n개`
- 내 최고 평균 판단 속도: `store` `hp:twin:best`(초, 성공한 판만).

## 고칠 때 지킬 것
- 카드 내용·배치는 **주어진 rng에서만**(Math.random 금지, 공용 효과 연출 안쪽만 예외). `gen`/`layout`의 rng 쓰는 순서, `TWIN_ART.S` 순서·색 묶음을 바꾸면 같은 씨앗의 카드가 달라진다(새 그림은 끝에 더하기).
- 새 그림: 0..100 안, 외곽선 없이 색 하나 + 큰 실루엣, TOY 필터(pb·pm·ps)와 `GL` 하이라이트, 바닥 그림자는 `SHD()`로(카드에서는 자동으로 빠짐). 색 짝은 한눈에 다른 색으로. 하트 모양 금지(사이트 재화).
- 배치·크기 규칙을 바꾸면 점검(아래)으로 실패 0과 가장 작은 그림 크기를 다시 본다.
- 효과는 보이기만(`try{}catch(_){}`, `pointer-events:none`), 동작 줄이기(`FXR.reduce`·prefers-reduced-motion)면 흔들림·파티클·날아오기 없이 색 표시만.
- CSS는 `css` 문자열 안에, `.ng-twin` / `body[data-mode="twin"]`로 범위(키프레임 `twin-…`). 도움말 그림은 `.tw-hp`(대전 규칙 목록에서는 숨김).
- 새 문구에 대시(—, –) 쓰지 않기. 상용 게임 이름·그림 금지(docs/13).
