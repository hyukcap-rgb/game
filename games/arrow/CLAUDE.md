## 한 줄 소개
밤 도로의 둥근 표지판에 화살표가 하나씩 나오면, **파랑은 그 방향, 빨강은 반대 방향**으로 미는 순발력 게임(약 1분). 화살표는 공용 3D 비닐 장난감 질감(TOY 조명 필터)으로 직접 그린 오리지널. 능력 `abil:'순발력'`.

## 규칙 (플레이어가 보는 것)
- 한 판 = 화살표 N개(시간 대신 개수). 문제마다 판단 시간(창)이 있고, 화살표 바로 아래 막대가 줄어든다(초록 → 노랑 → 빨강, 마지막 0.4초 살짝 떨림).
- 파란 화살표 = 그 방향, 빨간 화살표 = 반대 방향. 빨강은 꼬리에 **되돌이(↺) 표시**, 회색(멈춤)은 **멈춤(‖) 표시**가 함께 있어 색을 못 구분해도 똑같이 할 수 있다.
- 맞는 방향 = 정답, 다른 방향 = 실수, 창이 끝나면 시간 초과 실수(회색 멈춤만 가만히가 정답).
- 기회 3개(공용 별, 하트 아님). 실수마다 1개, 0이면 실패. N개를 다 하면 성공.
- 막 누르기 방지: 문제가 없는 순간·판정 뒤 누른 것은 무시. 0.25초 안에 4번 이상 누르면 "천천히!" + 0.5초 잠금(벌점 없음).
- 다음 화살표까지 간격: 정답 0.42초, 실수 0.6초(판단 시간에 안 들어감).
- 실수하면 이유를 글자로 보여 준다("빨강은 반대로!", "자리 말고 방향!", "회색은 가만히!" 등) + 정답 방향 표시 + 정답 버튼 점선 테두리.
- 조작: 화면 어디서든 밀기(24px, 손을 떼기 전에 판정) · 엄지 자리 십자 버튼(누르는 순간 판정, 최소 64px, 간격 10px 이상) · 키보드 화살표·WASD.
- 판 안 콤보 5·10·20(이후 10마다): "좋아요!/대단해요!/완벽해요!" + 진행자 기쁨 표정(점수 영향 없음).
- 개인 기록: 성공하면 평균 판단 속도를 `store` `hp:arrow:best`에 저장(대전 제외), 결과 줄에 "평균 0.62초 · 최고 0.58초".

## 모드별 동작
**오늘의 문제·연습·대전**(`levels`, 시간 제한 없음 `limit:0`):

| 난이도 | 문제 N | 판단 창(처음 → 끝) | 함정 | 켜진 것 |
|---|---|---|---|---|
| easy | 20 | 2.6 → 2.0초 | 15% | 파랑·빨강(가운데) |
| normal | 25 | 2.2 → 1.5초 | 25% | + 엉뚱한 자리 |
| hard | 30 | 1.9 → 1.2초 | 35% | + 엉뚱한 자리 + 회색 멈춤 |

- 판 안에서 창은 선형으로 짧아지고 함정(빨강 비율·위치 함정·멈춤)은 뒤로 갈수록 늘어난다(`trap × (0.6 + 0.8×진행)`).
- 글자 문제 +0.2초, 두 개 중 하나 +0.25초 창을 더 준다.
- 오늘의 시험지 과목(`SUBJ`)에는 아직 넣지 않음(사용자 확인 후, 기획서 docs/20).

**솔로**(`stageCfg(n)`, `planOf('arrow', n)`):

| 스테이지 | 종류 | 이름(key) | 내용 |
|---|---|---|---|
| 6 | 변주 | 번개(flash) | 판단 창 ×0.8 |
| 11 | 새 규칙 | 엉뚱한 자리(side) | 화살표가 가장자리(위·오른·아래·왼)에 나옴. 위치 함정: 파랑은 반대쪽 가장자리, 빨강은 가리키는 쪽 가장자리 |
| 16 | 변주 | 순간(ghost) | 화살표가 0.35초만 보이고 사라짐(창 그대로) |
| 21 | 새 규칙 | 글자 화살표(word) | "왼쪽" 같은 글자. 노란 글자 = 뜻대로, 빨간 글자(↺) = 반대로. 글자와 다른 쪽을 가리키는 점선 화살표 틀(모양 함정) 안에 나오기도 함 |
| 26 | 변주 | 외줄 타기(tight) | 기회 2번 |
| 31 | 새 규칙 | 정지 표지(stop) | 회색 화살표(‖) = 가만히가 정답(참으면 빠르기 1.0) |
| 41 | 새 규칙 | 두 개 중 하나(pair) | 화살표 2개, 금색 테두리 + "이거" 표시 쪽만(다른 쪽은 흐리고 작게) |

- 문제 수: `12 + 2×(챕터−1) + round(6×(k−1)/9)`(최대 32), 쉬어가기 −2, 보스 +6.
- 판단 창(처음): `2.6 × 0.94^(챕터−1)`, k=5 ×0.9 · 보스 ×0.85 · 쉬어가기 ×1.15 · 소개 판 ×1.08, 글자 ×1.12, 두 개 ×1.15, 번개 ×0.8. 최저 1.12초, 끝 = 처음 ×0.8(최저 0.9초).
- 함정: `0.10 + 0.075×(챕터−1)`(최대 0.45), 보스 +0.10, k=5 +0.05, 쉬운 판 −0.04.
- 새 규칙 소개 판(k=1)은 그 규칙이 더 자주 나온다(`focus`).
- 챕터 이름·진행자: 표지판 길(고래) · 미로 정원(개구리) · 거울 터널(호랑이) · 바람개비 언덕(부엉이) · 나침반 탑(여우). 챕터마다 말투·표지판 테두리 색·배경 색이 바뀐다(`TALK`, `TINT`). 오늘의 문제·대전 진행자는 고래.
- 보스: 진행자 'wow' 표정 + 말풍선 줄 붉은 띠 + "보스!" + 표지판 테두리 장밋빛.
- **아직 플레이 데이터로 맞추지 않은 첫 값.**

**별**: 실수 0 → ★★★, 1 → ★★, 그 외 ★.

**대전**: normal 같은 씨앗, 끝났을 때 점수 높은 쪽 승(엔진 기본 대전). `duelStat = { unit:'개', lfMax:3, v:정답 수, t:N, lf:남은 기회 }`, `duelPace:[50,.75]`, `duelHow:'같은 화살표 · 누가 더 빠르고 정확하게'`. 대전 중엔 멈추지 않음(엔진), 시작 전 카운트다운 동안 `G.paused`라 화살표가 안 나온다.

## 점수
엔진 `calcScore()` = round((base + time + extra) × 배율). `score()`:
- base = 500 × 정답 수 / N
- time = 350 × (문제마다 "남은 창 비율"의 합) / N. 실수 = 0, 회색 멈춤을 참은 것 = 1.0
- extra = 50 × 남은 기회(최대 150)
- 줄: `정답 a/N` · `판단 속도 보너스 (평균 0.xx초 · 최고 …)` · `남은 기회 n개`
- 정답마다 떠오르는 "+점수"는 그 문제 몫(500/N + 350×비율/N), 보이기만.

## 고칠 때 지킬 것
- 문제는 **주어진 rng에서만**(Math.random 금지, 효과 연출 제외). `gen`의 rng 쓰는 순서를 바꾸면 같은 씨앗의 화살표가 달라진다.
- 시간은 모두 `elapsed()`로 잰다(도움말·다른 앱으로 갔다 오면 멈춤, 대전은 멈추지 않음). `performance.now()`는 막 누르기 판단에만.
- 색만으로 구분하지 않는다: 빨강 = 되돌이 표시, 회색 = 멈춤 표시, 두 개 중 하나 = 금색 테두리 + "이거" + 크기, 판정 = 도장 그림 + 글자.
- 눈 피로: 빛·번쩍임은 약하게(fxFlash 0.1), 깜빡임·체크무늬 금지, 테두리 네온은 흐리게.
- 효과는 `try{}catch(_){}`(`safe`)로 감싸고 `pointer-events:none`. 움직임은 transform·opacity만.
- 새 문구에 대시(—, –) 쓰지 않기. 그림·이름은 오리지널만(docs/13_법무검토_IP.md).
