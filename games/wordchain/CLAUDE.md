## 한 줄 소개
앞 낱말의 끝 글자로 시작하는 낱말을 AI(또는 사람)와 번갈아 잇는 전략 말놀이(약 3분, 전략력). 정한 수만큼 버티거나, 상대가 이을 낱말이 사전에 없는 끝 글자로 끝내는 **한방**으로 이긴다. 사전·그림·이름은 모두 직접 만든 오리지널.

## 규칙 (플레이어가 보는 것)
- 시작 낱말이 나오면 내가 먼저 이어요. 앞 낱말 끝 글자(입력 칸 왼쪽 주황 글자)로 시작하는 낱말을 넣고 [잇기] 또는 Enter.
- **두음법칙** 허용: 끝 글자가 ㄹ로 시작하면 ㅑㅕㅖㅛㅠㅣ 앞은 ㅇ, 나머지는 ㄴ(력→역, 라→나, 로→노, 리→이), ㄴ+ㅑㅕㅖㅛㅠㅣ → ㅇ(녀→여, 뇨→요, 니→이). 입력 칸 왼쪽에 `력·역`처럼 같이 보여 줌.
- 한 글자 낱말 금지, 이미 나온 낱말 금지. **사전에 없는 말은 “사전에 없어요”** — 실수가 아니라 다시 입력(시간은 흐름).
- 내 차례마다 제한 시간. **시간 초과·포기(깃발 두 번)·이을 낱말이 사전에 하나도 없음(AI의 한방)** 이면 실패.
- 목표 수만큼 이으면 성공. AI가 이을 낱말이 없으면 **한방 승리**(+100점).
- 💡 힌트: 이을 수 있는 낱말 하나의 첫 두 글자(2글자 낱말은 첫 글자)와 글자 수(`대가○ (3글자)`). 판당 3번(어려움·보스 2, 맨손 0), −30점.

## 사전 (wordchain-words.js `WC_DICT`)
- 2026-10-09 국어사전 맞춤: 표기 고침(공기밥→공깃밥·국수집→국숫집·삐에로→피에로·뒷풀이→뒤풀이), 띄어 써야 하는 말(과일가게·김밥집 등)·형용사 어근(간단·독특 등)·부사(갑자기·손수 등) 약 80개 뺌. **`more` 약 16,200개**: 맞춤법 검사 사전(hunspell-dict-ko)에 명사로 실리고 Kiwi 형태소 사전(Apache-2.0)에서도 일반 명사인 2~4글자 낱말(비속어·차별어 뺌) — 사람이 넣으면 인정, 컴퓨터는 core·extra가 없을 때만. 합계 약 23,700개. 입력은 `normalize('NFC')`.
- **직접 모은 일반 명사** 2~4글자. `core` 약 3,600개(누구나 아는 말: AI 응답·힌트·시작 낱말은 여기서), `extra` 약 3,900개(사람이 넣으면 인정하는 말: 한자어·덜 흔한 말, AI는 core에 이을 낱말이 없을 때만). 합계 약 7,500개. 고유명사(지명·인명·나라)·형용사 어근·부사는 넣지 않았다.
- 불러올 때 정렬·중복 제거하므로 아무 데나 더해도 된다. 단, 낱말을 더하거나 빼면 같은 씨앗의 시작 낱말·AI 응답이 바뀐다(오늘의 문제는 날마다 새로 정해지니 큰 문제 없음).
- 한방 낱말(끝 글자로 시작하는 낱말이 사전에 없음): core에 약 160개(…름·…슴·…릇·…늬·…획·…칙·…을·…늘 등). 사전에 낱말을 더하면 한방이 풀릴 수 있다 — 아래 점검 스크립트로 확인.

## 판 만들기 (모든 수는 rng로)
`setup(cfg, rng)`: 금지 글자(`BAN_POOL`에서) → 황금 글자(`GOLD_POOL`에서 3개) → 시작 낱말(core를 rng로 섞어, 규칙에 맞고 3글자 이하이며 이어 받을 core 낱말이 12개 이상(긴 낱말·거꾸로 잇기는 6개) 있는 첫 낱말) → 판 씨앗 `seed`.
- 규칙 조합마다 `tables(rule)`(낱말마다 뒤에 올 수 있는 낱말 수 어림값)를 한 번 만들어 시작 낱말 고르기와 AI 판단에 쓴다. 판 만들기 평균 약 8ms, 최악 약 95ms(첫 표 만들기 포함).
- **AI 응답은 `seed + 지금까지 이은 낱말`로 만든 rng** → 같은 날 같은 수를 두면 같은 응답(`histRng`).

- 상대 찾기·준비 화면·결과 창은 공용(엔진 `duelSearch` → v3 대기실 `w3/h3/j3`, 방 `fl-d3-…`). 예전 자체 1:1(`duelLaunch`·`fleet`·대기실 `'wait'`·방 `fl-w-…`·presence `mv/sw`)은 없앰 → 지난 버전과 섞이지 않음. `duelLaunch`가 없으니 대전 방(WP2, `portal/rooms.js` `rmOk`)에도 그대로 나옴(`duelRoom` 필요 없음).
- 판 `duelCfg` = `{ goal:8, limit:18, ai:1, hints:0 }`(힌트 없음), 느긋하게 `duelSlow` = 차례 36초. `G.limit = 0`(판 전체 시간 없음). 시작 낱말은 대전 씨앗 rng → 모든 기기 같음. 엔진 카운트다운이 끝나는 순간(`G.duel.go`) `startChain`.
- 차례 순서 = 엔진 참가 순서(`duelTurn`). 수: `act('w', { w })` · 탈락 `act('out', { k:'kill'|'give'|'miss'|'stuck' })` · 이미 탈락한 사람 차례는 그 기기가 바로 `act('p')`(넘김, 탈락한 사람은 끝날 때까지 구경). 차례 바뀜은 `dPoll`(0.2초 + 그림 틀마다)이 보고 `dTurnStart`.
- 탈락: 시간 초과(엔진 `timeout` 사건, 모든 기기 같음) · 포기(깃발 두 번, 내 차례에만) · 이을 낱말이 사전에 없음(끝내기 낱말을 받음, 차례 시작에 확인) · 규칙 실수(첫 글자 틀림·이미 쓴 말) 2번째(첫 번째는 "한 번 더 틀리면 탈락!") · 차례인 사람이 나감(엔진 `skip`). 사전에 없는 말은 실수 아님(다시 넣기).
- 끝: 남은 사람이 1명(그 사람 1위) 또는 남은 사람 모두 정한 수(`duelCap`: 2명 8 · 3명 6 · 4~5명 5개)를 이으면 글자 점수로 순위 → 각 기기가 `duelEndNow(이유)`.
- 순위: `duelRank` = 순위 열쇠 `lf`(남은 사람 1000 + 글자 수, 탈락 = 몇 번째 탈락) 큰 순 → 이은 낱말 → 실수. 끝나기 전에 나간 사람은 엔진이 맨 뒤.
- 컴퓨터 상대(사람이 없을 때 1:1): 엔진 흉내 끔(`duelAi:() => null`), `aiTurn`이 보통 컴퓨터 + 끝내기 25% + 차례마다 5%(이을 낱말 3개 이하면 +25%) 못 찾음, 생각 1.5~3.5초. 수치는 `G.duel.P.ai.st`에 직접.
- 화면: 위 칩 = 내 낱말/정한 수 · 차례 시간(누구 차례든 엔진 차례 시계) · 남은 사람 · 포기, 그 아래 차례 순서 줄(`#wcOrder`: 얼굴·이름·이은 수, 지금 차례 '차례' 꼬리표, 탈락 회색). 말풍선은 참가자 얼굴·자리 색, 탈락은 기록 칸에 빨간 줄.
- `duelStat.get` = 대전 `{ v:내가 이은 수, mis, lf }`(t 없음), 그 밖 `{ v, t:목표 }`. `duelPace:[150, .6]`.


## 점수
엔진 `calcScore()` = round((base + time + extra) × 배율). `score()`:
- base = 400 + 100 × min(1, 이은 낱말 / 목표)
- time = round(250 × 내 차례마다 남긴 시간 비율의 평균)
- extra = min(250, max(0, 긴 낱말 보너스 min(150, (글자 수 − 2×낱말 수) × 15) + 한방 승리 100 − 30 × 힌트))

| `return { … }` | NG.wordchain 계약 + `_dict`·`_stage`·`_solveForTest`(점검용) |
| 파일 끝 | `duelPace`·`duelStat`·`scene`(물방울 배경) |

## 고칠 때 지킬 것
- 문제 내용(시작 낱말·황금/금지 글자·AI 응답·힌트)은 **rng(init의 rng, histRng)로만**. `Math.random` 금지(대전 상대 이름 `duelNick`은 엔진 것).
- `setup`의 rng 쓰는 순서, `GOLD_POOL`·`BAN_POOL` 순서를 바꾸면 같은 씨앗의 판이 달라진다.
- 대전 사건 형식(`w`·`out`·`p`)·순위 열쇠(`lf`)를 바꾸면 다른 버전 기기와 판이 어긋난다 → 바꿀 땐 엔진 v3 방이 버전으로 나뉘는지 확인하고 함께 올린다. 시간 초과 탈락은 반드시 엔진 timeout 사건으로(내 기기 시계로 따로 탈락시키지 않기).
- 효과는 보이기만(`try{}catch(_){}`), 입력 칸은 글자 크기 16px 이상(아이폰 확대 방지), [잇기]·힌트·포기 단추는 `pointerdown` 기본 동작을 막아 키보드가 내려가지 않게.
- CSS는 `css` 문자열 안에만, `.ng-wc` / `body[data-mode="wordchain"]`로 범위를 묶는다(키프레임 `wc-…`).
- 사전 표기는 국어사전 기준(2026-10-09). `more`는 Kiwi(Apache-2.0) 명사 중 맞춤법 사전에 있는 말만 — 출처 주석을 지우지 않는다. 고유명사·비속어 넣지 않기.

## 확인 방법
- `node tools/build.js` → `npm test -- wordchain`(사이트·모듈 모든 모드 한 판씩).
- 브라우저: `index.html`, `embed/wordchain.html?mode=daily|practice|solo|duel`(옵션 `&level=…`, `&stage=n&unlock=1`).
