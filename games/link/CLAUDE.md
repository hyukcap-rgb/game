## 한 줄 소개
같은 그림 타일 두 개를 **두 번까지 꺾이는 길**(빈칸·판 바깥 테두리로만)로 이어 지우는 공간지각 게임(약 3분). 장르 이름(사천성)·마작 패 그림은 쓰지 않고, 그림 28종은 모두 직접 그린 오리지널 SVG(굵은 외곽선 #1A0F45).

## 규칙 (플레이어가 보는 것)
- 타일 하나를 누르면 골라짐(들림). 같은 그림을 누르면 길이 그려지고 둘 다 사라짐. 고른 타일을 다시 누르면 취소(벌칙 없음).
- **실수** = 다른 그림을 고르거나, 같은 그림인데 길이 없음 → 기회(★) 하나를 잃고 점수 −25. **기회 3번(`LIVES`), 세 번째 실수에서 게임 끝**(마구 누르기 막기). 외줄 타기 변주는 기회 1번. **대전은 기회 제한 없음**(`lives:0`, 별 안 보임), 대신 틀리면 점수 −25 + **1초 못 누름**(`FREEZE_MS`, 판이 흐려짐).
- 💡 힌트: 지울 수 있는 짝 하나를 점선 길로 보여 줌(판마다 3번, 점수 −40). 섞기: 남은 타일 자리를 섞음(판마다 2번, 점수 −25).
- 지울 짝이 하나도 없으면 **저절로 섞임**(벌칙 없음).
- 제한 시간 안에 판을 모두 비우면 성공.

## 판 만들기 (모든 판은 처음에 반드시 다 지울 수 있음)
`deal(cfg, rng)` = **거꾸로 쌓기**: 빈 판에서 시작해, 이미 놓인 타일 사이로 길이 이어지는 빈칸 두 곳에 짝을 하나씩 놓는다. 마지막에 놓은 짝부터 지우면 언제나 길이 있다.
- 안쪽(테두리에서 먼 칸)부터 채워서, 나중에 놓는(=먼저 지울) 짝은 바깥쪽에 온다.
- **난이도**: 짝의 두 번째 타일은 길이 닿는 칸 중 가장 먼 곳(거리 + 안쪽 + 약간의 운)에 놓고, 같은 그림이 바로 옆에 붙는 칸은 피한다 → 처음에 바로 보이는 짝이 적다(보통 판 기준 처음 지울 수 있는 짝 약 21 → 10개, 바로 붙은 짝 약 10 → 3개).
- 판에는 늘 빈칸 2칸 여유(돌이 있으면 더)를 둔다. 꽉 찬 판은 멀리 놓기와 함께 쓰면 자주 못 만든다.
- 그림 하나 = 보통 2짝(타일 4개). 닮은꼴은 두 번째 짝을 점 찍힌 다른 색 타일로. 시계 짝은 따로.
- 돌은 테두리 바로 옆을 피하고 서로(대각선 포함) 붙지 않게 → 칸 하나를 가두지 못함.
- 40번 시도해도 못 만들면 그냥 섞어 놓음(지금 표의 판은 생성 점검에서 0건, 막히면 저절로 섞기).

- 힌트 3(보스 2, 맨손 0), 섞기 2(맨손 0).
- 챕터 이름: 꽃밭 산책 · 과일 장터 · 별빛 정원 · 바닷가 마을 · 눈꽃 궁전.

**별**: 힌트·섞기·실수 모두 0 → ★★★, 힌트+섞기 ≤1이고 실수 ≤1 → ★★, 그 외 ★.

**대전**(1:1 경주, 지금 엔진 v2 그대로): `init`이 `G.duel`을 보면 대전 전용 판 `DUEL_CFG` = **6×8 · 20짝 · 120초**(힌트 3·섞기 2), 비슷한 파랑 그림(`BLUE` = 물방울·눈송이·닻·구름·보석)은 한 판에 2개까지(`blueMax`, 섞은 뒤 거르기라 다른 모드의 rng 순서는 그대로). 누가 먼저 다 지우면 엔진이 둘 다 끝냄.
- **상대 판 미니 화면**: 판 위 줄 왼쪽 72×64 카드(얼굴 20 + 판 48×64, 칸 8px). 판 상태 글자열(0 빈칸·1 타일·2 얼음). 상대가 짝을 지우면 두 칸이 0.3초 노랗게 반짝.
- **콤보 얼음 공격**: 3초(`COMBO_MS`) 안에 연달아 지우면 2콤보 → 얼음 2장, 3콤보 → +1(모두 3장), 4콤보 → +1(모두 4장) + 상대 판 섞기 1번. 받는 쪽은 알림("○○님 공격! 3콤보 · 얼음 3장") 1초 뒤 얼음이 덮임.
- **얼음 덮개**: 덮인 타일은 6초(`ICE_MS`) 못 고름(누르면 "꽁꽁 얼었어요", 실수 아님), **바로 옆(상하좌우) 짝을 지우면 바로 녹음**. 판에 최대 6장(`ICE_MAX`). 얼음 칸 = `icePick(판, 얼음, 장수, 열쇠, 판 씨앗)` → 판 씨앗 + 보낸 사람 + 사건 번호로 정해 어느 기기에서 계산해도 같은 칸. 길 찾기에서 얼음 타일은 그냥 타일(길을 막음). 힌트·테스트 풀이는 얼음 안 덮인 짝 먼저.
- **섞기 공정성**: 대전의 섞기(직접·저절로·공격)는 `판 씨앗 + ':mix:' + 섞기 번호` 난수 → 같은 상황이면 누구나 같은 섞기. 섞은 뒤 지울 짝이 없으면 저절로 섞기.
- **전달**(지금 엔진 방 presence에 게임 키, 오목 `om`과 같은 방식): `lk = { v:1, mv:판 글자열, ev:[[번호, 'ice', 장수, 섞기, 시각, 콤보]…최근 20개] }`. 받는 쪽은 번호가 더 큰 사건만 차례로 처리(`evSeen`). 0.15초마다 읽고, 바뀌면 0.3초 간격으로 올림(공격은 바로).
- **컴퓨터 상대**: 같은 판을 미리 푼 순서(`m.ai.ord`)로 미니 판을 보여 줌(엔진 AI 진행도 × 20짝). 씨앗(`판 씨앗:ai-ice`)으로 정한 때(지운 짝 4~6 → 2장, 10~13 → 3장, 30% 확률로 15~17 → 4장+섞기) 얼음을 보냄. 내가 보낸 얼음은 컴퓨터 미니 판에만 보임(엔진 AI 결과는 미리 정해져 있어 늦출 수 없음).
- `duelStat = { unit:'짝', get:() => ({ v:지운 짝, t:전체 짝, lf:null, mis:틀린 횟수 }) }`(기회가 없어 `lfMax` 뺌 → 컴퓨터 상대 기회 점·"한 번 틀렸어요" 알림도 안 나옴), `duelPace:[85,.72]`.
- 대전 v3 선택 항목도 미리 적어 둠: `duelKind:'race'`, `duelMax:2`(1단계 1:1, v3에서 5로), `duelEnd:'first'`, `duelCfg()`(= `DUEL_CFG` + `duelOwn`), `duelSlow(cfg)`(시간 ×2 = 240초). init은 `cfg.duelOwn`이 있으면 받은 설정을 그대로 씀.
- 꾸밈(보이기만): 공격 보낼 때 "2콤보!" 알림·얼음 조각이 미니 카드로 날아감, 받을 때 반대로 날아옴. 판 위 30% 지점 반투명 알림(1.2초, `pointer-events:none`).

## 점수
엔진 `calcScore()` = round((base + time + extra) × 배율). `score()`:
- base 500
- time = max(0, 350 − floor(sec × 350 / 제한 시간)), sec = 경과초 + 벌칙초(째깍) − 시계 보너스
- extra = max(0, 150 − 40×힌트 − 25×섞기(직접 누른 것만) − 25×실수)
- 화면(2026-10-06): 이을 때 '슝' 소리를 키우고 선 양 끝 반짝, 지울 때 두 타일이 가운데로 모이며 터짐(보이기만 함).

## 고칠 때 지킬 것
- 판 배치·그림 선택·섞기는 **주어진 rng(`init`의 rng, `m.rng`)에서만**(Math.random 금지) → 같은 날짜 씨앗이면 모두 같은 판.
- `deal`의 rng 쓰는 순서나 `POOL` 순서를 바꾸면 같은 씨앗의 판이 달라진다(그림 추가는 끝에).
- 판 크기·짝 수를 바꾸면 아래 확인 방법의 생성 점검으로 "못 만든 판"이 거의 0인지 본다.
- NG.link 계약과 `duelStat`을 지킨다. CSS는 `css` 문자열 안에만, `.ng-link` / `body[data-mode="link"]`로 범위를 묶는다(키프레임 `link-…`).
- 그림·이름은 오리지널만(상용 게임 이름·마작 패·캐릭터 그림 금지, docs/13_법무검토_IP.md).
