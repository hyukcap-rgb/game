# 로열 홀덤 — 게임 프롬프트 (games/holdem)

> 이 파일은 이 게임의 **프롬프트**예요. 개발팀(Claude)은 이 게임을 고칠 때 항상 이 파일을 먼저 읽고 따릅니다.

## 사용자 지시
- 2026-10-12 사이트 공용 목록 화면을 홀덤에 맞게 고친다(챕터·판 고르기 칸 없애기).
- 2026-10-12 하루퍼즐에서 **성인게임으로도** 넣는다(성인(19) 묶음, 트럼프 고스톱 바로 뒤).
- 2026-10-12 홀덤 본체는 하루퍼즐과 **별개의 독립 게임**(저장소 `holdem/` 폴더, Railway `royal-holdem`). 룰은 텍사스 홀덤 노리밋, 모드는 AI 대결·친구 대전·오늘의 토너먼트.

## 한 줄 소개
독립 서비스 로열 홀덤(https://holdem-production-ada3.up.railway.app)을 사이트 안에서 꽉 찬 창(iframe)으로 여는 입구. 19세 확인 → 솔로는 AI 대결, 대전은 친구 대전으로 바로 시작.

## 동작
- 19세 확인: 고스톱과 같은 `hp:age19` 기록을 쓴다(한 번 확인하면 성인 게임 모두 통과). `startGate`·`duelLaunch`에서 확인.
- 열기: `?embed=1&start=solo|friends&name=<하루퍼즐 닉네임>`. 홀덤 첫 화면에 [‹ 하루퍼즐] 버튼이 생기고, 누르면 `postMessage({ holdem:'exit' })` → `HOST.exit()`로 사이트에 돌아온다.
- 하루퍼즐 점수·별·하트·대전 포인트와 연결하지 않는다(`duelNoPts`, 점수 0). 홀덤 칩·랭킹은 홀덤 서버에만.
- 게임 규칙·화면을 바꾸려면 이 폴더가 아니라 저장소의 `holdem/`(독립 서비스)을 고친다 — `holdem/CLAUDE.md`.
