# 트럼프 고스톱 — 게임 프롬프트 (games/tgostop)

> 이 파일은 이 게임의 **프롬프트**예요. 개발팀(Claude)은 이 게임을 고칠 때 항상 이 파일을 먼저 읽고 따릅니다.

## 사용자 지시
- 2026-10-31 **'뻑 보너스'가 아니라 '첫뻑'이라고 부른다**. 컴퓨터 판에서는 **첫뻑(연뻑·3연뻑 포함)으로 오간 골드도 한 판 상한 안**: 첫뻑 + 판 정산 합이 이기든 지든 ±입장 금액을 넘지 않는다(2026-10-22 '뻑 보너스는 상한 밖'을 이것으로 바꿈). 실시간 대전은 상한 없음 그대로.
- 2026-10-25 패 돌리기는 **사용자가 보낸 다른 맞고 영상처럼**: 더미에서 한 장씩 뒷면으로 날아가 자리에 닿으며 뒤집히고, 내 손패는 받은 순서대로 왼쪽부터 채운 뒤 정리, 상대 남은 패 수가 하나씩 올라감.
- 2026-10-25 **패 돌리기 연출 = 실제 나눠 주는 순서**: 선 아닌 사람 5장 → 선 5장 → 바닥 4장 → 다시 5 · 5 · 4를 아주 빠르게. 그 뒤 바닥에 보너스가 있으면 선에게 가고 더미에서 새 카드가 나와 채운다(선을 잡는 이유 = 바닥 보너스를 가져가서).
- 2026-10-25 **무늬 = 패 종류로 통일**: 광 5장은 모두 ♠, 열끗은 ♦, 띠는 ♥, 피(쌍피·보너스 K 포함)는 ♣ — 헷갈리지 않게(2026-10-11 '♠ 광·열끗, ♥ 띠, ♦♣ 피'를 이것으로 바꿈). 같은 숫자·무늬 카드가 겹칠 수 있음(화투의 같은 피처럼).
- 2026-10-25 **게임을 나갔다 들어오면 무조건 선을 새로 뽑는다**(솔로·컴퓨터·실시간 대전 모두, 기억하지 않음). 이어지는 판(한 판 더·연속 판)은 지난 판 이긴 사람이 선(나가리면 그대로).
- 2026-10-22 **모바일·PC 두 가지로 서비스**한다. 화면 해상도(휴대폰 세로·가로, 태블릿, PC 720p~4K, 스팀 덱 1280×800)에 따라 **잘림·넘침·겹침 같은 오류가 없어야** 한다 — 화면을 고치면 해상도 점검을 다시 돌린다.
- 2026-10-21 **게임 돈 단위 = 골드(Gold, `G`)** — 달러 같은 현실 화폐 이름은 쓰지 않는다(현실 돈 오해·도박 심사). 영어로 스팀 출시하므로 '냥' 같은 한국어 단위도 쓰지 않는다. 게임 점수(7점)는 points, 돈은 Gold로 나눈다. **컴퓨터와 둘 때는 난이도 = 판돈: 초급 점당 100 G**(중급 500 G · 고급 1,000 G는 기획팀 추천으로 정함). 스팀에서 서비스한다.
- 2026-10-21 **난이도 보상 배율은 없앤다**("그런 거 없어도 돼") — 초급·중급·고급은 컴퓨터 세기만 다르고, 이기고 지는 포인트는 모두 같다(2026-10-21 '보상 ×0.5·×1·×1.5'를 이것으로 바꿈).
- 2026-10-21 **판마다 미션**을 넣는다(한게임처럼 오른쪽 패널에 패 2장 + ×2). 2026-10-03의 "미션은 넣지 않음"을 이 지시가 바꿈 — 그림·이름은 우리 것. **판 시작 때 2~3초 경쾌한 시작음**을 낸다.
- 2026-10-21 트럼프 카드 그림을 **고급스럽게**, **홍단·청단·초단은 화투처럼 카드 그림 안에 띠(단책)로** 보이게.
- 2026-10-21 **관리비 5%는 없앤다**(사용자 반발만 삼). 이긴 금액은 전부 받는다.
- 2026-10-21 상대 목소리가 **가림막에 가려진 것처럼 먹먹하면 안 된다** — 두 캐릭터 목소리가 똑같이 또렷하게.
- 2026-10-21 **난이도 초급·중급·고급**(솔로·컴퓨터 대전에서 고름, 이길 때 보상 ×0.5·×1·×1.5) · **솔로에서 모은 포인트로 대전** · **올인하면 충전권(아이템)으로 1만P 충전** · **이긴 금액의 5%는 관리비**로 빠짐(포인트 인플레이션 막기).
- 2026-10-21 **스팀 출시 준비 시작** — PC 앱은 `steam/`(Electron), 출시 순서·스토어 문구는 `docs/30_스팀출시_준비.md`. 게임을 고치면 `node tools/build.js` 뒤 `steam/`에서 다시 빌드.
- 2026-10-19 상대 이름을 부르는 목소리는 **하지 않음**(기기 음성 읽기는 너무 어색 — 물결도 '물결'로 읽음). 대신 **녹음 대사를 늘려 반복을 줄이는 쪽**으로(서버 성우 생성은 사람이 늘면 다시 검토).
- 2026-10-19 사운드팀: **성우 목소리**로 상황마다 재미있는 한마디(빨리빨리 하자구요~ · 윽, 쌌네 · 아싸 고도리~ 등). 맞고 게임에서 목소리가 나오는 상황을 모두 정리해 우리 대사로(다른 게임 대사·목소리는 베끼지 않음).
- 2026-10-18 판 위 글자 최소화: 문장은 판 위에 두지 않고 도움말(tips)로, 칩 이름표는 그림으로(docs/29).

- 2026-10-17 **표정은 상황에 따라 달리**(뻑 = 낸 사람 울상·상대 웃음, 큰 일 = 웃음·상대 울상/놀람, 피 뺏김 = 울상, 고 = 상대 놀람, 스톱 = 상대 울상). **소리는 사운드 플러그인(Creative Claw)으로 만든 녹음 효과음**을 쓰고, **이벤트 이펙트는 더 실감 나게**.

- 2026-10-17 게임 속도를 **한게임 신맞고처럼 빠르게**(사람들이 그 속도에 익숙함). 연출은 짧고 경쾌하게, AI도 빨리 둔다(차례 시계 8초는 그대로).
- 2026-10-16 오른쪽 캐릭터 메뉴는 **Figma 개편안**(https://www.figma.com/design/EYEXYENh4epiBqAWIZV1rJ)대로: 판 이름표 맨 위 → 상대 카드 → 내 패 점수(7점 막대) → [?][나가기] → 내 카드 → 알림. **나가기와 ✕는 같은 기능이라 버튼 하나**(대전 중엔 나가기 예약). 패 내기·뒤집기·가져오기·패 돌리기 연출과 소리는 **한게임/피망 고스톱 기본 연출 흐름**을 따른다(들어 올려 휙 → 내리꽂기 '딱!' + 하얀 터짐, 더미 패 반 바퀴 뒤집기, 먹은 패 차르륵, 더미에서 한 장씩 돌리기) — 그림·소리는 직접 만든 것만. **패 뒷면은 실물 화투처럼 붉은색**(2026-10-04 '남색 뒷면 유지' 지시를 이것으로 바꿈).
- 2026-10-11 디자인팀·UI팀: Figma·디자인 스킬로 **숫자를 더 잘 보이게**, 광·열끗·쌍피·고도리 표시를 **실감나게**, **J·Q·K 인물 그림** 넣기. 설명서는 **외국인이 알기 쉽게**(영어).
- 2026-10-11 게임을 시작할 때 바닥에 같은 월 **3장이 뭉쳐 있으면 그것도 뻑**으로 친다 → 4번째로 먹는 사람이 상대 피 1장을 받는다(자뻑은 그대로 — 내가 싼 뻑만 자뻑).
- 2026-10-11 하루퍼즐 **사이트에도 보이게**(성인(19) 묶음, 고스톱 바로 뒤).
- 2026-10-11 **우리 고스톱(games/gostop)과 똑같이**: 화면 좌표·배치·연출(이펙트)·소리·AI·대전 방식은 그대로 두고 **카드만 화투 → 트럼프**로 바꾼다. 이 게임의 핵심은 고스톱과 같은 이펙트.
- 2026-10-11 트럼프 52장: A~Q = 1~12월, **K 4장 = 조커(보너스패)**. 무늬 = 패 종류(♠ 광·열끗, ♥ 띠, ♦♣ 피).

## 고칠 때 지킬 것
- 화투 고스톱(games/gostop)의 화면·연출을 고치면 **여기에도 같이** 옮긴다(두 게임이 같아야 함). 복사본이라 전역 이름(`TGART`·`TGFX`·`NG.tgostop`)이 겹치면 사이트가 깨진다.
- 규칙 함수에는 무작위·시간을 넣지 않는다 → `node tools/tgostop-sim.js 3000`(52장 보존·다시 두기 같음).
- 사이트 목록: `portal/portal.js` registerGames(고스톱 바로 뒤)와 `ADULT`(성인(19) 묶음)에 들어 있다.

## 확인 방법
- `node tools/gostop-sound-audit.mjs --game tgostop` — 소리 검수(테스트 체크팀): 솔로·AI 대전을 실제로 두며 난 소리를 모두 기록, 패 소리 중복·같은 소리 반복·패+이벤트 겹침·이벤트끼리 겹침·동시 3개 이상·모으기 겹침을 찾음. 소리를 바꾸면 꼭 돌려 0건 확인.
- `node tools/build.js` → `npm test -- tgostop`
