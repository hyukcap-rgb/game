# 두뇌 퀴즈쇼 — 게임 프롬프트 (games/quiz)

> 이 게임을 고칠 때 항상 이 파일을 먼저 읽고 따릅니다. 법무 기준은 `docs/28_퀴즈쇼_법무검토.md`.

## 사용자 지시
- 2026-10-18 캠페인 "여기서 게임하면 머리가 좋아진다"(아이·어른 모두 두뇌를 맑게) — 효과 단정은 광고법 위험이라 문구는 "여기서 노는 시간, 머리가 깨어나는 시간"으로 씀.
- 2026-10-18 이슈를 만들 퀴즈를 **법적으로 가능한 범위에서**: 연예인·노래·춤(10대), CM송·과자·아이스크림 상표 가리고(30대 이상). 무단으로 못 쓰는 것(가요·CM송·포장·연예인 사진)은 이 게임에 넣지 않고, 10초 퀴즈(`shorts/`, 유튜브 공식 플레이어 연결)와 제휴 상품으로 돌림.

## 한 줄 소개
멜로디·상표 가린 추억 간식·그림 속담·옛 인물을 4지선다로 맞히는 온 가족 퀴즈(약 2분, `abil:'추리력'`). 오늘의 시험지(리그) 과목은 아님.

## 규칙
- 한 판 = 문제 N개, 종류는 `cfg.mix`를 돌려 섞음. 문제마다 `sec`초, 시간 끝나면 오답.
- 점수(문제): 정답 60 + 40 × 남은 시간 비율 × 힌트 배율(힌트형: 1개 1.0 · 2개 0.8 · 3개 0.6). 판 점수: base 600×정답률 + time 300×평균 보너스 + 모두 정답 100.
- 절반 이상 정답이면 성공. 별: 오답 0 ★★★ · 2개 이하 ★★ · 그 외 ★.
- 난이도: easy 6문제 20초 · normal 8문제 15초 · hard 10문제 12초. 솔로: 챕터마다 주 종류(멜로디 → 간식 → 속담 → 인물 → 종합), 문제 수 6~12, 시간 18초에서 줄어 최소 9초.
- 대전: 점수전(`duelKind:'score'`, 모두 끝까지), 최대 4명.

## 문제 은행 규칙(`quiz-bank.js`)
- mel: 저작권 끝난 곡만, 음표로(음원 금지). 한국 동요 대부분 금지.
- snack: 포장·로고·CM송·광고 문구·회사 이름 금지. 나온 시기는 10년 단위로만.
- person: 돌아가신 지 오래된 역사 인물만. 현역 연예인·인플루언서 금지.
- 새 문제는 끝에 더함(앞 순서를 바꾸면 같은 씨앗 문제가 바뀜).
