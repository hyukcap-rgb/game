# 고백점프 — 게임 프롬프트 (games/goback)

> 이 파일은 이 게임의 **프롬프트**예요. 개발팀(Claude)은 이 게임을 고칠 때 항상 이 파일을 먼저 읽고 따릅니다.
> 바라는 방향·하지 말 것·고칠 점을 아래 **사용자 지시**에 적어 두면 다음 작업부터 반영돼요.

## 사용자 지시
- 2026-10-08 사용자 요청으로 추가(go back jump). 2~5명이 함께. "go back jump ~ go back jump" 노래가 나오고 시작하는 사람(솔로는 나)부터. **고 = 시계 방향으로 다음 사람 · 백 = 방향을 바꿔 그쪽으로 · 점프 = 지금 방향에서 한 사람 건너뛰기**. 구도는 빨간 카드 테이블(가운데 타원 판 + 둘레 자리 + 아래 큰 버튼 3개)처럼, **상대가 무엇을 골랐는지 잘 보이게**.

## 한 줄 소개
빨간 카드 테이블에 2~5명이 둘러앉아 고·백·점프로 차례를 넘기는 순발력 놀이(약 2분, `abil:'순발력'`). 화면은 누구 차례인지 알려 주지 않는다 — 앞사람이 외친 것(말풍선·화살표·가운데 큰 글자·방향 표시)을 보고 내 차례인지 스스로 알아채는 것이 핵심.

## 규칙 (플레이어가 보는 것)
- 노래(박자 0.36초 × 8: 고·백·점·프·고·백·점·프!) → "시작! ○○부터" → 시작하는 사람 차례.
- 차례인 사람은 박자(창) 안에 고·백·점프 중 하나를 누른다.
  - 고: 지금 방향으로 살아 있는 다음 사람. 처음 방향은 **시계 방향**(화면에서 아래 → 왼쪽 → 위 → 오른쪽).
  - 백: 방향을 바꾸고, 바뀐 방향의 다음 사람.
  - 점프: 지금 방향으로 살아 있는 사람 하나를 건너뛰고 그다음 사람(2명이면 다시 나).
- **늦음**: 내 차례에 창 안에 못 누르면 별 −1, "다시! ○○부터" 1.5초 뒤 그 사람부터 다시(방향 그대로). 별이 0이면 탈락하고 그다음 사람부터.
- **헛누름**: 내 차례가 아닌데 누르면 별 −1(판은 그대로 이어짐). 통신 지연을 봐서 누른 뒤 0.35초(솔로 0.15초) 안에 내 차례가 오면 그 누름을 내 외침으로 쓴다.
- 노래·"다시!" 중에 누른 것은 무시(안내 글만).
- 별(기회)은 `.gb-lv` ★. 하트는 사이트 재화라 쓰지 않는다.
- 박자: `w0`에서 30차례 동안 `w1`까지 줄고, 60차례가 넘으면 0.985배씩 더(최소 0.55초).

## 화면(빨간 카드 테이블)
- 위: 공용 HUD 칩(남은 사람 · 지금 박자 · 내가 외친 수).
- 가운데: 무늬 벽지 방 + 나무·금 테두리 빨간 타원 판(`GO · BACK · JUMP` 바닥 글씨). 자리 = 판 둘레, **나는 늘 맨 아래**, 참가 순서대로 시계 방향.
- 자리마다: 동물 얼굴(자리 색 테두리) · 이름표 · 별. 외치면 얼굴 옆(판 가운데 쪽)에 **색 말풍선**(고 초록 → · 백 주황 U턴 · 점프 보라 호), 바로 앞 사람 것은 흐리게 하나만 남김. 늦음/헛누름은 빨강/보라 도장 + 별 튀김, 탈락은 회색 얼굴 + "탈락" 말풍선.
- 판 위 화살표: 외친 자리에서 방향대로(점프는 점선으로 한 자리를 넘는 호). **다음 사람을 직접 가리키지 않는다**.
- 판 가운데: 지금 방향(시계/반대, 백이면 뒤집히는 움직임) · 큰 외침 글자 · 누가 · 최근 4번 기록 줄.
- 아래: 고·백·점프 큰 버튼(86px, 키보드 1·2·3 / → ← ↑ / 스페이스=고).
- 솔로 1챕터 1~3판만 "차례 도움": 창의 45%가 지나면 차례인 자리가 빛남.
- 목소리(덤): 소리가 켜져 있고 한국어 목소리가 있으면 노래·외침을 읽어 줌.

## 모드
`modes:['solo','duel']`. 오늘의 시험지(SUBJ)에는 넣지 않음(넣을지 사용자에게 물을 것).

| 난이도(levels) | 컴퓨터 | 박자 | 컴퓨터 별 | 컴퓨터 헛누름 |
|---|---|---|---|---|
| easy | 2명 | 2.2 → 1.3초 | 1 | 없음 |
| normal | 3명 | 1.9 → 1.0초 | 2 | 1.5% |
| hard | 4명 | 1.6 → 0.8초 | 2 | 2.5% |

**솔로** `stageCfg(n)`(개념 사이클 없음, `planOf`의 c·k·대장 판만): 컴퓨터 1챕터 1~3판 1명 · 4~10판 2명 · 2챕터 3명 · 3챕터~ 4명(대장 판 +1, 최대 4). 박자 2.2 → 1.15초 × 0.92^(챕터−1)(어려운 판 ×0.94 · 대장 ×0.9 · 쉬어가기 ×1.1, 최소 1.0 / 0.62초). 컴퓨터 별 1챕터 1, 그 뒤 2. 내 별 3. 성공 = 끝까지 남기, 실패 = 내가 탈락.
- 컴퓨터: 차례마다 놓침 확률 5% + 15% × 박자 진행률(+60차례 넘으면 6%p), 반응 = 창의 30~70%, 외침 점프 18~30% · 백 28% · 나머지 고. 헛누름은 차례 아닐 때 차례마다 `aiFalse`. 모두 씨앗 rng(`rngOf(씨앗, 차례 번호, 자리, 종류)`).
- **별**: 한 번도 안 틀림 ★★★ · 별 2개 이상 ★★ · 그 밖 ★.
- 점수: base 500 + time min(300, 외친 수 × 15) + extra 100 × 남은 별.

**대전(2~5명)**: `duelKind:'score'` + `duelEnd:'game'`, `duelMax:5`, `duelReplay:false`. 공용 차례 엔진(`duelTurn`)은 쓰지 않는다(순서가 참가 순서로 고정이고 위 칩 줄에 '차례' 꼬리표가 떠서 누구 차례인지 드러남).
- 판 `duelCfg` = 박자 1.9 → 0.95초, 별 3개(4~5명은 2개). 느긋하게 = 박자 ×1.4. 시작하는 사람 = 참가 순서 첫 사람. 모두 엔진 카운트다운이 끝나는 순간(`G.duel.go`) 노래 시작.
- **차례는 차례인 사람의 기기만 정한다**: 사건 `duelSend('gb', …)` — 외침 `{t:'c', n, c:0|1|2, d:방향, x:다음 자리}` · 늦음 `{t:'m', n, d, x}` · 탈락한 사람 넘김 `{t:'p', n, d, x}` · 헛누름 `{t:'x', h:남은 별}`(순서와 상관없어 바로 적용). 받는 쪽은 차례 번호 `n`과 차례인 사람이 맞는 것만 차례로 적용(늦게 온 것은 줄 세움) → 모든 기기가 같은 순서.
- 탈락한 사람 차례가 오면 그 사람 기기가 `p`로 넘김. 차례인 사람이 나가면(엔진 `left`) 모든 기기가 같이 건너뜀.
- 끝: 남은 사람 1명이거나 노래 뒤 2분 30초(`CAP`) → 각 기기가 `duelEndNow`. 순위 열쇠 `lf` = 남은 사람 1000 + 별×100 + 외친 수(최대 99), 탈락 = 몇 번째 탈락. `duelRank` = lf → 외친 수 → 실수.
- 컴퓨터 상대(사람이 없을 때 1:1): `duelAi:() => null`, 게임이 직접 외침(솔로 컴퓨터와 같은 방식), 수치는 `G.duel.P.ai.st`에 직접.
- 사이트 대전 방(2~5명)에 그대로 나옴(`duelLaunch`가 없어서 `rmOk`).

## 고칠 때 지킬 것
- **누구 차례인지 화면·소리로 알려 주지 않는다**(솔로 첫 판 도움만 예외). 엔진 차례 꼬리표가 뜨는 `duelKind:'turn'`으로 바꾸지 않는다.
- 대전 사건 형식(`gb` · `t/n/c/d/x/h`)을 바꾸면 다른 버전 기기와 차례가 어긋난다 → 바꿀 땐 버전으로 방이 나뉘는지 확인.
- 다음 사람은 **차례인 사람 기기가 정해 보낸 값**(`x`)을 그대로 쓴다. 받는 쪽에서 다시 계산하지 않는다(헛누름 도착 순서가 기기마다 달라도 같게).
- 컴퓨터의 수는 rng로만(`Math.random` 금지). 효과는 `fx()`로 감싸고 판 상태를 바꾸지 않는다.

## 확인 방법
- `node tools/build.js` → `npm test -- goback` · `npm run test:duel -- goback --no-multi`.
- 여러 명: 저장소 밖 임시 스크립트로 `tools/duel-test.mjs` 중계를 본떠 브라우저 3~5대 + 봇(내 차례면 무작위 외침, 가끔 늦음·헛누름, 한 명 나감)으로 끝까지 → 모든 기기의 `_test.state().tr`(차례 기록)·별·순위가 같은지 확인(2026-10-08: 3·4·5명, 최대 109차례 같음).
- 브라우저: `embed/goback.html?mode=solo&stage=n&unlock=1`, `?mode=duel`.
