## 한 줄 소개
화면을 좌우로 끌어 관문(+ − × ÷)을 골라 병력을 키우고, 자동 화살과 돌격으로 적 부대·성문·보스를 뚫는 행군 게임(`NG.march`, 능력 '전략력', 약 1분, game.json order 30). 모드는 솔로·대전만(`modes:['solo','duel']`), 오늘의 시험지에는 없음.

## 규칙 (플레이어가 보는 것)
- **화면 구도(v1.2)**: 부대는 화면 아래 제자리에서 좌우로만 움직이고, 바닥·성벽은 고정. 관문·상자·적·보스가 초당 24로 다가옴(내부 계산은 그대로 부대 위치 z가 늘어나는 방식). 보스는 85 안에 들어오면 초당 5로만 걸어 들어오며(걷는 모션) 그동안 공격·사격이 오감. 화면을 좌우로 끌면(PC는 ← → / A D) 옆으로 움직임. **병사 1명으로 출발**(솔로 `min(8, 1+⌊(n−1)/3⌋)`, 대전 1).
- **시작 갈림길(빠른 판단)**: 출발 약 2초 뒤 가운데 벽으로 길이 나뉨. 한쪽은 숫자 상자(체력 = 2 + 시작 병력 + 스테이지×0.4)가 막은 +판 줄, 다른 쪽은 빨간 대군(22 + 6×단계 + 시작 병력×2, 제자리). 벽 안에 들어가면 반대쪽으로 못 건너감.
- **조준**: 화살은 부대 앞쪽 좌우 `병력 반지름×0.9 + 12` 안에만 나감 → 상자·통·탑·적 부대를 쏘려면 줄을 맞춰야 함. 보스·성문은 어디서나 맞음.
- 화살: 초당 `min(2 + 병력×0.25, 18) × 연사 배율`발, 한 발 피해 `max(1, (2 + 병력×0.25)/18) × 공격 배율`. 사거리 적 부대 58 · 상자·통 70 · 탑·성문 72 · 보스 85.
- **숫자 상자·보상 통**: 정면으로 부딪히면 막힘(병력×0.6/초로 밀어 부숨). 통을 부수면 보상: 병사 +N(45%) · 석궁 공격 ×1.3(30%, 최대 ×3) · 연사 ×1.25(25%, 최대 ×2.5). 위에 보상 그림·글자.
- **갈림길(스테이지 2~)**: 벽 한쪽 = 숫자 상자 + +판 줄, 다른 쪽 = 적 부대(제자리)가 지키는 보상 통.
- 관문: 왼쪽·오른쪽 중 부대 가운데가 있는 쪽이 적용. 파랑 = + ×, 빨강 = − ÷. 첫 관문은 둘 다 +.
- +판 줄: 지날 때마다 +k(k = 1 + ⌊단계/4⌋, 갈림길은 1 + ⌊단계/3⌋).
- 적 부대: 60 안에 들어오면 내 쪽으로 다가옴(대군·갈림길 적은 제자리). 닿으면 초당 `5 + 0.7×min(내 병력, 적)`씩 서로 줄고, 싸우는 동안 속도 30%.
- 톱날·궁수탑·성문·성장 관문·움직이는 관문은 v1.0과 같음. 일반 스테이지 끝엔 대군(남은 기대 병력×0.7 + 6 + 단계)과 싸운 뒤 결승.
- **보스(3의 배수 스테이지 끝)**: 공격 전 땅에 예고(빨간 원이 안쪽부터 차오름·빨간 줄·초록 틈) → 타격. 예고 밖이면 '회피!'. 공격 사이 `max(1.1, 2.2 − 단계×0.03)`초, 체력 50% 아래면 **분노**(빨간 빛, 1.45배 빨라짐, 예고 0.8배, 바위·번개 하나 더).
  - 거인: 내려찍기(원 1개, 32%) ↔ 바위 던지기(원 3~4개, 각 15%, 바위가 날아와 떨어짐)
  - 방패 기사: 창 돌진(빨간 줄, 36%) ↔ 회전 베기(초록 틈 밖 전부, 28%) + 5.5초 중 3초 방패(피해 15%)
  - 주술사: 번개(원 5~6개, 각 12%) · 졸개 둘 소환 · 발밑 독 웅덩이
  - 화염 용: 한쪽 불길(42%) · 불덩이 비(원 3~4개) · 날개 바람(옆으로 24 밀어냄)
  - 피해는 병력 비율 × (1 + 단계×0.015), 한 번에 최대 70%.
- **타격감(보이기만)**: 화면 번쩍·흔들림·0.1초 느려짐(히트스톱)·병사 최대 16명 튕겨 나감·큰 피해 숫자. 보스 머리 위에 체력 숫자, 공격 준비 때 들썩이며 떪.

## 모드별 동작
**솔로** — 씨앗 `'adv:march:'+n`. 스테이지 n: 시작 갈림길 + 구간 `9 + min(n, 12)`개. 새 기믹은 판 안의 시작 카드(2.6초 멈춤, 누르면 바로 시작)로 알림 — 사이트 개념 카드(`concepts`)는 쓰지 않음:
| 스테이지 | 새로 나오는 것 |
|---|---|
| 1 | 빠른 판단(1명 시작·숫자 상자·대군 갈림길) · 관문 · +판 줄 · 적 부대 |
| 2 | 보상 통(병사·석궁·연사) · 갈림길 |
| 3 | 보스 몽둥이 거인(내려찍기·바위) |
| 4 | 곱셈 관문 |
| 5 | 회전 톱날 |
| 6 | 보스 방패 기사(창 돌진·회전 베기) |
| 7 | 성장 관문 |
| 8 | 적 궁수탑 |
| 9 | 보스 주술사(번개·소환·독) |
| 10 | 움직이는 관문 |
| 11 | 성문 |
| 12 | 보스 화염 용(불길·불덩이·바람) |
| 13+ | 모두 섞임, 3판마다 보스 순환 |
- 솔로는 실제 내 병력에 맞춰 적 부대 크기(≤ 병력×0.9+3+n/2)·성문·보스 체력을 줄여 줌.
- 클리어: 결승선 통과 또는 마지막 보스 격파. 실패: 병력 0.
- 별: 클리어 ★, 남은 병력 ÷ 최대 병력 40% ★★ · 70% ★★★ (보스 판 30% · 55%).

**대전** — `duelLaunch()`: 나 + 라이벌 봇 1명(`duel:{ fleet:true }`, 게임이 직접 진행). 같은 씨앗의 똑같은 길(시작 갈림길 포함, 구간은 진행 거리 220마다 어려워짐, 약 760마다 보스 순환), 시작 병력 1, 오른쪽 위 작은 화면에 라이벌 시점.
- 먼저 전멸한 쪽 패배('l'/'w'), 같은 순간 전멸은 무승부('d').
- 2:00까지 둘 다 살면 남은 병력 많은 쪽 승리, 같으면 무승부. `G.duel.a/b.sc` = 남은 병력.
- 라이벌 판단: 관문 80% 옳게 고름, 보스 공격 예고 70% 피함, 갈림길은 +판 쪽, 상자는 쏘고 통은 60% 노림, 톱날·큰 적 부대·독 웅덩이 피함.
- 실시간 사람 대전(서버)은 아직 없음 — 지금은 봇.

## 고칠 때 지킬 것
- 길·적·봇 판단은 모두 씨앗 rng(`S.rng`에서 나눈 줄)로. 흔들림·연기 같은 보이기 전용은 `S.vr`. `Math.random` 금지.
- 게임 상태는 `S`(=`G.mc`). 엔진의 `G.over`·`G.paused`·`G.raf`·`G.cleanup`만 함께 씀.
- 끝낼 땐 `endWith(승패, 사유)` 하나로 → 0.9초 뒤 `finish()`.
- 그림을 바꾸면 `img/`에 webp로(배경 투명), 경로는 `BASE`(모듈에서는 `../games/march/img/`).

## 확인 방법

- 난이도: 브라우저 콘솔에서 `NG.march._sim(n, 씨앗)` → 라이벌 AI로 스테이지 n을 그리지 않고 끝까지(승패·남은 병력·시간). v1.3 기준 AI 승률: 1~4판 11~12/12, 6판 9/12, 9판 3/12(주술사 2.6으로 조정 전), 12·15판 6/12.
