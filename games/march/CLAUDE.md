## 한 줄 소개
화면을 좌우로 끌어 관문(+ − × ÷)을 골라 병력을 키우고, 자동 화살과 돌격으로 적 부대·성문·보스를 뚫는 행군 게임(`NG.march`, 능력 '전략력', 약 1분, game.json order 30). 모드는 솔로·대전만(`modes:['solo','duel']`), 오늘의 시험지에는 없음.

## 규칙 (플레이어가 보는 것)
- 부대는 앞으로 저절로 걷고(초당 24), 화면을 좌우로 끌면(PC는 ← → / A D) 옆으로 움직임.
- 관문: 왼쪽·오른쪽 중 부대 가운데가 있는 쪽이 적용. 파랑 = + ×, 빨강 = − ÷. 첫 관문은 둘 다 +.
- +판 줄: 노란 띠 위 파란 +판을 지날 때마다 +k(k = 1 + ⌊스테이지/4⌋).
- 화살: 초당 `min(2 + 병력×0.25, 18)`발, 한 발 피해 `max(1, (2 + 병력×0.25)/18)`. 사거리 적 부대 58 · 탑·성문 72 · 보스 85. 성장 관문은 내가 줄 선 쪽을 맞히면 +1.
- 적 부대: 60 안에 들어오면 내 쪽으로 다가옴. 닿으면 초당 `5 + 0.7×min(내 병력, 적)`씩 서로 줄고, 싸우는 동안 부대 속도 30%.
- 톱날: 지나가는 순간 겹친 정도만큼 병력의 최대 38.5% 잃음.
- 궁수탑: 75 안에서 0.45~0.9초마다 병사 1~3명 저격. 성문: 부숴야 통과(병력×0.6/초 + 화살).
- 보스(3의 배수 스테이지 끝): 거인(2.4초마다 내려찍기) · 방패 기사(5.5초 중 3초 방패, 피해 15%) · 주술사(4.5초마다 졸개 소환, 5초마다 발밑 독 웅덩이) · 화염 용(3.6초 뒤 1.3초 경고한 쪽에 불, 맞으면 42% 잃음).

## 모드별 동작
**솔로** — 씨앗 `'adv:march:'+n`. 스테이지 n: 시작 병력 `5 + min(25, n)`, 구간 `9 + min(n, 12)`개. 새 기믹은 판 안의 시작 카드(2.6초 멈춤, 누르면 바로 시작)로 알림 — 사이트 개념 카드(`concepts`)는 쓰지 않음:
| 스테이지 | 새로 나오는 것 |
|---|---|
| 1 | 기본 관문 · +판 줄 |
| 2 | 적 부대 |
| 3 | 보스 몽둥이 거인 |
| 4 | 곱셈 관문 |
| 5 | 회전 톱날 |
| 6 | 보스 방패 기사 |
| 7 | 성장 관문 |
| 8 | 적 궁수탑 |
| 9 | 보스 주술사 |
| 10 | 움직이는 관문 |
| 11 | 성문 |
| 12 | 보스 화염 용 |
| 13+ | 모두 섞임, 3판마다 보스 순환 |
- 솔로는 실제 내 병력에 맞춰 적 부대 크기(≤ 병력×0.9+3+n/2)·성문·보스 체력을 줄여 줌.
- 클리어: 결승선 통과 또는 마지막 보스 격파. 실패: 병력 0.
- 별: 클리어 ★, 남은 병력 ÷ 최대 병력 40% ★★ · 70% ★★★ (보스 판 30% · 55%).

**대전** — `duelLaunch()`: 나 + 라이벌 봇 1명(`duel:{ fleet:true }`, 게임이 직접 진행). 같은 씨앗의 똑같은 길(구간은 진행 거리 220마다 어려워짐, 약 760마다 보스 순환), 시작 병력 10, 오른쪽 위 작은 화면에 라이벌 시점.
- 먼저 전멸한 쪽 패배('l'/'w'), 같은 순간 전멸은 무승부('d').
- 2:00까지 둘 다 살면 남은 병력 많은 쪽 승리, 같으면 무승부. `G.duel.a/b.sc` = 남은 병력.
- 라이벌 판단: 관문 80% 옳게 고름, 용의 불 72% 피함, 톱날·큰 적 부대·독 웅덩이 피함.
- 실시간 사람 대전(서버)은 아직 없음 — 지금은 봇.

## 고칠 때 지킬 것
- 길·적·봇 판단은 모두 씨앗 rng(`S.rng`에서 나눈 줄)로. 흔들림·연기 같은 보이기 전용은 `S.vr`. `Math.random` 금지.
- 게임 상태는 `S`(=`G.mc`). 엔진의 `G.over`·`G.paused`·`G.raf`·`G.cleanup`만 함께 씀.
- 끝낼 땐 `endWith(승패, 사유)` 하나로 → 0.9초 뒤 `finish()`.
- 그림을 바꾸면 `img/`에 webp로(배경 투명), 경로는 `BASE`(모듈에서는 `../games/march/img/`).
