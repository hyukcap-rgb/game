## 한 줄 소개
2인 맞고 규칙의 고스톱(약 5분, 19세 이상). 같은 월끼리 먹어 7점을 먼저 내면 고/스톱. 솔로는 AI와 스테이지, 대전은 실시간 1:1 턴제(상대가 없으면 AI). 화투 48장 그림은 Wikimedia Commons의 한국 화투 SVG(Marcus Richert, CC BY-SA 4.0 — 출처 표시 필수, CREDITS.md), 보너스패·뒷면은 직접 그림. 화면은 한게임 맞고식 가로 배치(그쪽 그림·캐릭터·이름은 안 씀). 돈·상품은 걸 수 없고 점수는 게임 안에서만.

## 규칙 (한게임 맞고에서 널리 쓰는 기본 규칙)
- 패: 화투 48장 + 보너스 3장(쌍피 2 · 쓰리피 1) = 51장. 손 10장씩, 바닥 8장, 더미 23장. 판 상태 S의 0번 자리 = **선**(먼저 둠, 처음 바닥의 보너스패도 선이 먹음). 누가 0번 자리인지는 판마다 정함(아래 선 뽑기).
- 바닥에 같은 월 4장이 깔리면 다시 섞음. 처음 손에 같은 월 4장 = **총통**(바로 승리 10점).
- 한 차례: 손패 1장 내기 → 더미 1장 뒤집기. 같은 월이 1장이면 먹고, 2장이면 골라 먹고(종류가 같으면 자동), 3장이면 모두 먹음.
  - **뻑**: 낸 패로 1장을 맞췄는데 뒤집은 패도 같은 월 → 세 장이 바닥에 묶임. 나중에 4번째로 먹으면 상대 피 1장(**자뻑** = 내가 싼 뻑을 내가 먹으면 2장). **3뻑**이면 바로 승리 10점.
  - **쪽**: 낸 패가 바닥에 없었는데 뒤집은 패가 그 패와 같은 월 → 둘 다 먹고 피 1장.
  - **따닥**: 바닥 2장 + 낸 패 + 뒤집은 패가 모두 같은 월 → 4장 다 먹고 피 1장.
  - **쓸**: 내 차례 끝에 바닥이 비면 피 1장(마지막 패로 비운 경우 제외).
  - **흔들기**: 같은 월 3장을 들고 바닥에 그 월이 없을 때 그중 하나를 내며 흔들기(×2, 물어봄).
  - **폭탄**: 같은 월 3장 + 바닥에 1장 → 세 장을 한꺼번에 내 4장 먹고 피 1장, ×2(자동). 손에 빈 패 2장(내면 뒤집기만).
  - **보너스패**: 손에서 내면 바로 먹고 더미에서 1장 받고 한 번 더 둠. 뒤집혀 나오면 먹고 한 장 더 뒤집음.
  - 피 가져오기는 1장짜리 피 → 쌍피 → 보너스 순.
  - **첫뻑**: 자기 첫 차례(보너스패 내기는 세지 않음)에 뻑을 싸면 판돈(점당)의 **5배** 포인트를 상대에게서 바로 받음(점당 100P → 500P, 실시간은 상대 보유까지, 연습 판은 표시만). 규칙 상태 `S.P[i].nt`(낸 횟수)·`fp`(첫뻑) → 화면 쪽 `fpCheck`가 판마다 한 번만 정산(다시 맞추기에도 두 번 안 줌), 결과 창에 '첫뻑' 줄.
- 점수: 광 3장 3점(비광 끼면 2점)·4장 4점·5장 15점 / 열끗 5장부터 1점씩, 고도리(2·4·8월 새) 5점 / 띠 5장부터 1점씩, 홍단·청단·초단 각 3점 / 피 10장부터 1점씩(쌍피 2, 쓰리피 3). 국진(9월 열끗)은 열끗·쌍피 중 점수가 높은 쪽으로 자동.
- **7점** 이상이 되면(고를 했다면 그때보다 점수가 올라야) 고/스톱을 고름. 고: 1고 +1, 2고 +2, 3고부터 +n점에 ×2, ×4…. 손패가 없으면 그대로 스톱.
- 배수(곱함): 흔들기·폭탄 1번마다 ×2, 멍따(열끗 7장+) ×2, **피박**(내가 피로 점수, 상대 피 1~5장 — 0장은 면제) ×2, **광박**(내가 광으로 점수, 상대 광 0장) ×2, **고박**(상대가 고를 했는데 내가 남) ×2.
- 둘 다 7점을 못 내고(또는 고 뒤 점수를 더 못 내고) 패가 다 떨어지면 **나가리**(무승부).

## 모드별 동작
- **오늘의 시험지·연습: 없음**(`modes:['solo','duel']`). 사이트 오늘 탭에는 안 나오고, 모듈 첫 화면도 솔로·대전만. 모듈에 `mode=daily`/`practice`가 들어오면 솔로로 시작.
- **솔로**: AI와 한 판, 이기면 클리어. 매번 다른 패(씨앗 = 스테이지 rng + 이 기기의 판 번호 `hp:gs:n` — 문제를 공유하는 게임이 아니라서).

| 스테이지 자리(챕터 c, 자리 k) | AI | 선 |
|---|---|---|
| 챕터 1 | 쉬움(k=5·10은 보통) | 나(k=5·10은 AI) |
| 챕터 2 | 보통(k=1·9 쉬움, k=5·10 어려움) | 나(k=5·10은 AI) |
| 챕터 3~ | 어려움(k=1·9 보통) | 짝수 자리·5·10은 AI |

  - 챕터 이름: 동네 사랑방 · 시장 골목 · 장터 한마당 · 명절 큰집 · 고수의 방. 개념 사이클(새 규칙)은 없음.
  - **별**: ★ 승리 · ★★ 최종 10점 이상 · ★★★ 최종 20점 이상.
- **대전**(`duelLaunch`, 엔진에 `fleet:true` = 게임이 대전을 직접 진행, `g.sess`): 19세 확인 → 방 고르기 → 실시간 서버에 연결돼 있으면 상대 찾기(20초 안에 없으면 "AI와 바로 대전" 단추), 없으면 AI(보통). 사람·AI 대전 모두 아래 흐름.
  - **선 뽑기**(첫 판 전): 씨앗으로 고른 8장을 엎어 두고 자리 0 → 자리 1 순서로 한 장씩 뒤집음. **높은 월**이 선, 같은 월이면 새 8장으로 다시. 5초 안에 안 고르면 씨앗 난수로 아무거나(대신 골라 줘도 두 기기가 같은 칸). 다음 판부터는 **지난 판 이긴 사람이 선**(나가리면 그대로).
  - **8초 시계**: 패 내기·고/스톱 모두 8초. 내 프로필(또는 상대 프로필)의 캐릭터 둘레에 둥근 시계 + 남은 초. 5초 넘게 남으면 평소 얼굴, 5~2.5초 놀란 얼굴(위아래로 들썩·땀), 2.5초 아래 울상(덜덜 떨림·빨간 테두리), 마지막 3초 째깍 소리. 큰 일이 생기면 잠깐 웃는 얼굴/놀란 얼굴, 판이 끝나면 이긴 쪽 웃음·진 쪽 울상.
  - **시간이 다 되면 자동 수 `autoAct`**(무작위 없음): 보너스패 → 폭탄 빈 패 → **비(12월)·풍(10월)·초(5월)·똥(11월)·팔(8월)·삼(3월)** → 남은 월(9·7·6·4·2·1). 같은 월 안에서는 가치가 낮은 패(피 → 쌍피 → 띠 → 열끗 → 광)부터, 바닥 고르기·뒤집은 패 고르기는 가치가 높은 쪽, 흔들기 안 함, 고/스톱은 스톱.
  - **연속 판**: 한 판이 끝나면 결과 창에서 6초 세고 바로 다음 판. 판 이름표에 "n판째", 결과 창에 전적. 대전이 끝날 때: 누가 나가기를 예약했거나, 포인트가 방 입장보다 모자라거나, 상대가 나갔거나 15초 응답이 없을 때.
  - **나가기 예약**: 대전 중 "나가기" 단추가 "나가기 예약"으로 바뀜 → 누르면 예약(단추가 "예약 취소"), **다시 누르면 취소**. 결과 창에도 같은 단추. 상대에게는 프로필에 "나가기 예약" 표시. 바로 나가고 싶으면 옆 ✕(엔진의 기권 확인 → 판 도중이면 기권 벌점).
  - **강제로 나가거나 끊기면**: 남은 쪽이 그 사람 차례를 같은 자동 수로 대신 두며(연결 끊김이면 2.5초, 연결은 있는데 말이 없으면 8초 + 여유 3초 뒤) **판 끝까지** 진행하고, 그 판이 끝나면 대전 끝. 상대 프로필에 "연결 끊김·자동".
  - 대기실 presence `du:'wait', dg:'gostop', dt, nk, dr:방, dv:2`(dv 2 = 이 기록 방식끼리만 짝), 짝이 되면 `du:'play', dp:상대`. 둘만의 방 `fl-g-<peer>-<peer>`(서버가 `fl-` 방은 바로 전달). 자리 = peer id 작은 쪽이 0번. 씨앗 = `gs:pvp:<peer>:<peer>` + `:판 번호`.
  - **기록 주고받기**: 둘만의 방 presence `{ v:2, nk, pt, bye, ev:[…] }`. ev 한 줄 = `[판, 번호, 종류, …]` — 종류 0 패 `[c,a,b,s]`, 1 고/스톱 `[g]`, 2 선 뽑기 `[칸]`(판 −1, 번호 = 라운드×2+차례), 3 다음 판 `[나가기 예약, 보유 P]`(번호 999). 번호 = 그 판의 결정 순서(패 내기·고스톱 각각 한 번호). 지난 판까지만 남기고 지움.
  - **엇갈림 맞추기**(`rebuild`): 결정마다 '주인이 아닌 쪽이 대신 둔 기록'이 있으면 그것, 없으면 주인 기록을 씀. 잘못된 수(손에 없는 패 등)면 그 자리의 자동 수. 내 결정을 상대가 대신 둔 기록이 내 것과 다르면 판 처음부터 다시 쌓음 → 두 기기가 같은 판으로 모임.
  - 결과(대전 끝): `G.duel.r` = 이긴 판 수 비교('w'/'l'/'d'), `G.duel.a/b.sc` = 내 승수/상대 승수, `G.duel.why` = "n판 a승 b패 · 포인트 ±P · 끝난 까닭". 대전 포인트는 사이트 공통.
- 솔로는 그대로 한 판(선은 스테이지 표, 시계·자동 수·선 뽑기·연속 판 없음).

## AI (남의 손패·더미는 보지 않음)
- `want(S, p, 패)`: 패의 가치(광·고도리·단 진행도, 상대 막기 포함).
- 쉬움: 탐욕 + 큰 흔들림(35%는 아무 패), 고 50%. 보통: 탐욕(낸 패 + 먹을 바닥 패 가치, 못 먹을 땐 상대가 먹을 위험이 적은 패). 어려움: 낸 패의 결과를 실제로 두어 보고 평가(먹은 패 가치 + 뺏은 피 + 흔들기 − 바닥에 남긴 패를 상대가 먹을 확률), 고를 더 과감하게.
- 시뮬레이션(`node tools/gostop-sim.js`): 보통이 쉬움을 약 66% 이김. 어려움≈보통(뒤집힐 패까지 기대값으로 보는 방식은 오히려 약해서 뺐음). 맞고는 운이 커서 AI 세기보다 **선**이 더 큰 차이(선 승률 약 57%) → 솔로 어려운 판은 AI가 선.

## 점수 (엔진)
`score()` = 이긴 판만: base 500 + time = min(350, 최종 점수 × 20) + extra = min(150, 배수 개수 × 50). 솔로 별은 위 표. 진 판 `lossText`는 상대 점수·내 점수.

## 고칠 때 지킬 것
- **규칙 함수(`gsDeal`·`gsApply`·`gsGoStop`)에는 무작위·시간을 넣지 않는다**(두 기기가 같은 판이어야 함). 바꾸면 `node tools/gostop-sim.js`(51장 보존·다시 두기 같음)부터 돌린다.
- 기록 형식(`E/D`·ev)이나 `autoAct` 순서를 바꾸면 옛 버전과 대전이 안 맞는다 → 바꿀 땐 대기실 `dv`·방 presence `v`를 올려 버전이 다르면 매칭하지 않게.
- 대신 두기는 `autoAct`가 무작위 없이 같은 판 → 같은 수여야 성립한다(시뮬레이션이 확인).
- AI는 남의 손패·더미를 보지 않는다(공정).
- 화투 그림은 CC BY-SA 4.0 — 출처 표시(게임 방법 '그림 출처', CREDITS.md)를 지우지 않는다. 한게임 등 특정 서비스의 그림·캐릭터·이름은 가져오지 않는다(배치·비율만 참고).
