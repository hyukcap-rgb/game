# 고스톱 그림 출처

- 화투 48장 그림(`gostop-cards.js`의 그림판): Wikimedia Commons [Category:SVG Hwatu](https://commons.wikimedia.org/wiki/Category:SVG_Hwatu)
  - 만든 사람: Marcus Richert (Louie Mantia, Jr.의 Hanafuda 그래픽을 바탕으로 만든 한국 화투 버전)
  - 라이선스: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
  - 바꾼 점: SVG 48장의 바깥 빨간 테두리를 얇게 잘라 내고(그림 둘레 일부만 남김) 모서리를 둥글게 해, 칸 256×417 크기 WebP 한 장(12열 4줄)으로 구움(`tools/gostop-sprite.mjs`). 이 그림판도 CC BY-SA 4.0.
  - 7장은 원본 대신 하루퍼즐이 새로 그린 그림으로 바꿔 구움: 4월 열끗(두견새), 8월 열끗(기러기), 12월 열끗(제비), 11월 광(봉황)·쌍피·피 2장. 원본 세트의 화풍(빨간 테두리·흰 판·먹선·평면 색)에 맞춘 오리지널(`games/gostop/art/*.svg`, 11월은 `tools/gostop-art-cards.mjs`로 만듦). 같은 그림판에 함께 들어가므로 그림판 전체는 CC BY-SA 4.0으로 둔다.
- 보너스패·뒷면·폭탄 빈 패(`gostop-art.js`): 직접 그림.
- 게임 안 표시: 게임 방법(?) 맨 아래 "그림 출처".
