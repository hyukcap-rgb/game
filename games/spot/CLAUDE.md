## 한 줄 소개
rng로 그린 귀여운 장면(마을·공원·부엌·바닷가·우주) 두 장을 위아래로 놓고, 아래 그림에서 달라진 곳 N곳을 찾아 누르는 집중력 게임(약 2분). 그림 조각 45종은 모두 직접 그린 오리지널 SVG(굵은 외곽선 #1A0F45), 사람은 그리지 않는다(소품·동물·자연).

## 규칙 (플레이어가 보는 것)
- 위 그림(원래)·아래 그림(차이 있음) **어느 쪽을 눌러도** 판정. 찾으면 두 그림 모두에 분홍 동그라미.
- 차이 동그라미 반지름 + 7(그림 단위, `TOL`) 안을 누르면 찾은 것. 이미 찾은 곳을 다시 누르면 아무 일 없음.
- **빗나감** = 차이가 없는 곳을 누름 → 점수 −15(`MISS_PTS`), 두 그림이 잠깐 흐려지며 누를 수 없음(두 그림 사이에 남은 시간 "잠깐! 0.6초"와 막대, `coolShow`)(0.7초, 연달아 빗나갈수록 +0.4초, 최대 2.4초). 기본은 기회 제한 없음. 외줄 타기 변주만 기회 2번(두 번째 빗나감에서 끝). 대전은 늘 기회 제한 없음.
- 💡 힌트: 못 찾은 차이 하나의 **근처**를 큰 점선 동그라미로 2.8초 보여 줌(정확한 자리는 아님). 판마다 3번(보스 2, 맨손 0), 점수 −40(`HINT_PTS`).
- 제한 시간 안에 모두 찾으면 성공. 실패하면 못 찾은 곳을 노란 점선 동그라미로 보여 준다.

## 판 만들기 (모든 판은 N곳을 반드시 찾을 수 있음)
`gen(cfg, rng)`(rng만 씀):
1. 테마 고르기(`cfg.theme` 없으면 rng). 오늘의 문제는 `init`에서 차이 수×7번 rng를 넘겨 같은 날이라도 난이도마다 다른 장면.
2. `placeScene`: 테마의 조각 목록(`SPOT_ART.TH[테마].items` = [종류, 구역, 최대 수])을 섞고 **큰 조각부터** 구역(하늘·땅·벽·식탁·바다·모래…) 안에 놓는다. 조각끼리 **겹치지 않게**(5 여유) → 없어지거나 색이 바뀐 조각이 다른 조각에 가려지지 않는다. 목표 조각 수 = N + 8. 크기 0.9~1.2배, 방향·색·작은 부분은 rng.
3. `pickDiffs`: 조각을 섞어 차례로, 무게 붙은 차이 종류(색 3 · 없애기 2 · 작은 부분 2.8 · 크기 1.4 · 자리 1.2 · 방향 1.1)를 시도.
   - 너무 작은 조각(짧은 변 < 19)은 차이로 안 씀. 크기 바꾸기는 짧은 변 ≥ 24인 조각만(×1.38 또는 ×0.66, 바닥 고정), 자리 옮기기는 옆으로 (폭×0.55+14).
   - 바뀐 뒤 상자도 그림 안·다른 조각과 겹치지 않아야 함. 한 종류는 N의 40%까지(섞이게).
   - 차이 동그라미 = 바뀌기 전후 상자를 덮는 원(대각선×0.4+3, 최소 16). **동그라미끼리 겹치지 않음**(+2 여유).
   - 거울 그림에서는 방향 바꾸기 안 씀. 조각 그림에서는 모든 조각이 조각 경계에 걸치지 않게 놓고, 차이도 한 조각 안에만.
4. N곳을 못 고르면 장면을 새로 만든다(최대 40번). 점검에서 실패 0건.
- 차이 아닌 조각은 위아래가 똑같고, 차이인 조각은 SVG가 반드시 다르다(점검 스크립트로 확인).

## 모드별 동작
**오늘의 문제·연습·대전**(`levels`):

| 난이도 | 차이 | 제한 시간 | 힌트 |
|---|---|---|---|
| easy | 5곳 | 120초 | 3 |
| normal | 7곳 | 150초 | 3 |
| hard | 9곳 | 180초 | 3 |

오늘의 시험지 과목(`SUBJ`)에는 아직 넣지 않음(넣는다면 '집중' 과목 제안). 연습은 배율 0.6/1.0/1.4.

**솔로**(`stageCfg(n)`, 개념 사이클 `planOf('spot', n)`, 개념 표 `CONC`):

| 스테이지 | 종류 | 이름(key) | 내용 |
|---|---|---|---|
| 6 | 변주 | 번개(flash) | 시간 ×0.65 |
| 11 | 새 규칙 | 거울 그림(mirror) | 아래 그림 좌우 반전(`matrix(-1 0 0 1 W 0)`), 누른 자리도 거꾸로 계산 |
| 16 | 변주 | 맨손(bare) | 힌트 0 |
| 21 | 새 규칙 | 깜빡 커튼(blink) | 5초마다 3.2초 보이고 1.8초 한쪽 그림이 커튼에 가려짐(위·아래 번갈아). 가려진 그림은 못 누름(벌칙 없음) |
| 26 | 변주 | 외줄 타기(tight) | 기회 2번(두 번째 빗나감에서 끝) |
| 31 | 새 규칙 | 조각 그림(tiles) | 아래 그림을 4조각으로 잘라 자리를 섞음(제자리 조각 없음, `perm[화면 조각]=원래 조각`). 차이 최대 8곳 |
| 36 | 변주 | 살금살금(subtle) | 없애기·크기·자리 없이 색·방향·작은 부분만, 시간 ×1.25 |
| 41 | 새 규칙 | 몇 곳일까?(secret) | 차이 수를 숨김(`/?곳`), 다 찾으면 저절로 끝 |
| 46 | 변주 | 차이 잔치(more) | 차이 +2곳 |

- 사이클 자리 k: 1 소개(쉬움) · 5 어려움 · 6 변주 소개 · 9 쉬어가기 · 10 보스. 51부터 리믹스.
- 차이 수: 챕터 1 = `LT.ch1[k−1]`(4·5·5·5·6·4·5·6·4·7), 챕터 2~ = `LT.base[c] + LT.kOff[k]`(기본 6·6·7·7·8), 3~12곳(조각 그림은 8곳까지).
- 제한 시간 = 차이 × `LT.spp[c]`(22·20·19·18·17·16초) × `kTime[k]` × 규칙 배수(`mjTime`: 거울 1.15·커튼 1.25·조각 1.25·비밀 1.1) × 변주 배수(`twTime`), 5초 단위, 최소 40초. **아직 플레이 데이터로 맞추지 않은 첫 값.**
- 테마 = `THEMES[(n − 1 + c) % 5]`(마을·공원·부엌·바닷가·우주가 돌아가며).
- 챕터 이름: 눈 크게 뜨기 · 반짝 관찰단 · 숨바꼭질 골목 · 매의 눈 · 명탐정의 방.

**별**: 힌트+빗나감 0 → ★★★, 2 이하 → ★★, 그 외 ★.

**대전**: normal(7곳, 150초) 같은 씨앗 = 같은 그림, 먼저 다 찾는 사람이 이김(엔진 기본 대전). `duelStat = { unit:'곳', v:찾은 곳, t:전체 }`, 기회 제한 없음, 몇 곳일까 규칙 꺼짐. `duelPace:[85,.8]`, `duelHow:'같은 그림 · 누가 먼저 차이를 다 찾나'`.

## 점수
엔진 `calcScore()` = round((base + time + extra) × 배율). `score()`:
- base 500
- time = max(0, 350 − floor(sec × 350 / 제한 시간))
- extra = max(0, 150 − 40×힌트 − 15×빗나감)

## 고칠 때 지킬 것
- 장면·차이는 **주어진 rng에서만**(Math.random 금지, 효과 연출 제외). 힌트 자리는 `m.rng`(판을 만든 뒤 이어 쓰는 rng).
- `SPOT_ART.P`·`TH`의 순서, 조각 목록, `placeScene`/`pickDiffs`의 rng 쓰는 순서를 바꾸면 같은 씨앗의 그림이 달라진다(조각 추가는 끝에, 테마 목록에 넣으면 그 테마 그림이 바뀜).
- 새 조각은 `draw`가 0..w × 0..h 안에 그리게, 색 후보는 빛깔이 확실히 다르게, 작은 부분(det)은 휴대폰에서 보일 만큼 크게(대략 지름 8 이상).
- 조각·크기·차이 규칙을 바꾸면 아래 생성 점검으로 실패 0·판 만들기 시간을 다시 본다.
- 아래 그림의 동그라미는 `<use>` 복사본으로 보이므로 CSS 애니메이션이 안 걸린다(속성으로만 그림). 효과는 `try{}catch(_){}`로 감싼다.
- CSS는 `css` 문자열 안에만, `.ng-spot` / `body[data-mode="spot"]`로 범위를 묶는다(키프레임 `spot-…`).
- 그림·이름은 오리지널만(상용 게임 이름·캐릭터 그림 금지, docs/13_법무검토_IP.md).
