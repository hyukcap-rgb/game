## 한 줄 소개
밤하늘 판에서 구슬을 쏘아 숫자 블록을 깨는 각도 퍼즐. 턴마다 블록이 한 줄씩 내려오고, 바닥선을 지키며 모든 줄을 깨면 클리어(`NG.ball`, 능력 '공간지각', 약 3분, game.json order 3).

## 규칙 (플레이어가 보는 것)
- 판 8열 × 11줄(`BC=8, BR=11`, 칸 100 논리 좌표). 줄 0은 여유 줄, 새 줄은 줄 1로 들어옴, 맨 아래 줄(10)은 발사 자리. **시작할 때 위 4줄을 미리 채움**(`BPRE 4`, 총 줄 수 안에서, 먼저 만든 줄이 아래).
- 판을 누른 채 끌어 조준(점선 = 첫 튕김까지), 떼면 발사. ◀ ▶(64×56) 한 번 1.5°, 0.3초 넘게 누르면 0.1초마다 1.5°→4°로 빨라짐 + [발사]. 발사 자리 옆에 각도 "63°"(14px). 각도 `BAIM_MIN 0.14 ~ BAIM_MAX π−0.14`.
- 가진 구슬 수만큼 연달아 날아감(속도 `BSPD 2800`, 간격 `BGAP 0.03`초). 2초 넘게 날면 자동 ×2, 4초 넘으면 ×4, [빠르게 보기] 토글 ×2. 다 쏜 뒤 1.5초가 지나면 [발사] 자리가 **[모두 거두기]**(남은 구슬·불꽃을 바로 바닥으로, 다음 자리는 먼저 떨어진 구슬 → 없으면 맨 먼저 쏜 날고 있는 구슬). 처음 떨어진 자리가 다음 발사 자리.
- **물리는 고정 단계**: `BSTEP 1/240`초를 `BSUB 2`번 나눠(한 번 5.8 논리 = 칸의 1/17) 계산. 프레임 길이·빠르게 배수는 "한 프레임에 몇 단계"만 바꾸므로 30·60·120fps 결과가 같음(봇 `fps` 모드로 확인). 판 결과에 영향을 주는 계산은 `ballStep`에만.
- 블록(둥근 사각)·범퍼(원, 굵은 점선 테두리)는 숫자만큼 맞히면 깨짐. 별 조각을 먹으면 다음 턴 구슬 +1(바닥 줄에 닿은 별 조각은 자동 획득).
- 특수 블록: 시계(깨면 다음 턴 안 내려옴) · 방패(아래 면은 막힘) · 물감(깨면 같은 색 블록 체력 25%↓) · 폭죽(깨면 불꽃 구슬 4개가 대각선으로 튐).
- **이벤트 블록 4종**(금 테두리 + "!" 배지 + 남은 턴): 판에 나온 뒤 **3턴 안에** 깨면 효과, 못 깨면 보통 블록으로 바뀜(`BEV_TURNS`). 별똥별(구슬 +2, 판 동안 유지) · 번개(같은 가로줄 블록 체력 −2) · 보물 상자(셋 중 가장 적은 아이템 +1) · 자석(판의 별 조각을 모두 모아 구슬 +).
- 블록이 바닥 줄에 닿으면 별빛 방어막이 1번 전체를 한 줄 올려 줌(`ballGuard`), 두 번째엔 실패.
- 아이템 판마다 1번씩: 뚫는 구슬(빨강, 이번 턴 뚫고 지나가며 1씩) · 긴 조준선(하늘, 조준선 두 번 튕긴 곳까지) · 한 줄 올리기(초록, 전체 한 줄 위, 맨 윗줄이 비어 있을 때) · 빠르게 보기(흰 토글). 개수 배지 13px.
- 시간 제한 없음(`limit:0`). 승패는 줄·턴으로. 판 안 안내 문장은 처음 1번만(`store 'hp:ballTip'`), 쏘면 사라짐.

## 모드별 동작
**오늘의 문제·연습** — `genBall(rng, cfg)`에서 `cfg.like`(비슷한 솔로 스테이지)의 설정을 가져와 `rows`만 바꾸고 새 블록 소개(intro)는 끔. 오늘의 문제는 씨앗 `'exam:'+날짜+':ball'`(모두 같은 판), 요일 난이도(월·화 쉬움 · 수·목·금 보통 · 토·일 어려움), 배율 없음. 연습(embed)은 새 씨앗 + LEVELS 배율.

| 난이도 | levels | 판 | 따라 하는 스테이지 설정 | 연습 배율 |
|---|---|---|---|---|
| easy 쉬움 | `{ rows:10, like:5, limit:0, evN:[1,2] }` | 블록 10줄 | 5: 구슬 3, 시계만 | 0.6 |
| normal 보통 | `{ rows:14, like:12, limit:0, evN:[1,2], hpAdd:1 }` | 블록 14줄 | 12: 구슬 3, 시계·방패·물감(체력 줄 번호+1) | 1.0 |
| hard 어려움 | `{ rows:18, like:22, limit:0, evN:[1,2] }` | 블록 18줄 | 22: 구슬 4, 특수 4종 | 1.4 |

- 표는 `BLEVELS`(봇도 그대로 읽음). 모든 난이도에 이벤트 블록 1~2개(씨앗으로 같은 자리, `evN`). 보통의 `hpAdd:1`은 "아무 각도로만 쏴도 깸"을 막으려고(무작위 봇 50% → 5%, 서툰 봇 9/10, 강한 봇 전부).

**솔로** — 씨앗 `'adv:ball:'+n`, 배율 1, 기록 저장 이름 `saveKey:'hp:ballStages'`. 개념 사이클(새 규칙·변주) **없음**: 난이도는 `ballStageCfg(n)`이 n에 따라 고르게 올림.
- `rows = min(36, 7 + floor(0.45n))` (1→7줄, 10→11, 20→16, 30→20, 50→29)
- 줄당 블록 수 `minN = min(5, 3 + floor(n/24))` ~ `maxN = min(6, 4 + floor(n/9))`
- 체력 배수 `hpMul = min(1.5, 0.82 + 0.015n)`, 블록 체력 = `max(1, round((줄번호+1) × hpMul × (0.7~1.3)))`
- 2배 체력 확률 `dbl` = n≥24일 때 `min(0.12, (n−20)×0.005)`, 범퍼 확률 `bump = min(0.2, 0.05 + (n−1)×0.0052)`
- 별 조각: 줄마다 1개 + 두 번째 확률 `star2 = max(0, 0.34 − 0.02n)`. 시작 구슬 `start` = 3(n<22) / 4(22~44) / 5(45+)
- 특수 블록은 `BSP_AT = { clock:3, shield:7, paint:12, fire:18 }`부터 9% 확률로 섞임(첫 등장 판은 앞쪽 줄에 1개 보장 + 안내 띠).
- 이벤트 블록은 `BEV_AT = { meteor:15, bolt:25, chest:35, magnet:45 }`부터 줄마다 9%(`BEV_P`)로 하나(첫 등장 판은 1개 보장 + 안내 띠). **줄을 다 만든 뒤에 같은 rng로 고르므로 이벤트가 없는 판(1~14)은 예전과 같은 판**.
- 블록 색은 처음 체력 단계로 고정(`ballBand`: 1~3·4~7·8~15·16~30·31+). 물감 블록의 "같은 색"도 이 단계.
- 등장 판은 `CONCEPTS.ball = { fixed:[...] }`로 엔진에 알려 규칙 카드만 보여 줌:

| 스테이지 | 키 | 이름 | 하는 일 |
|---|---|---|---|
| 3 | clock | 시계 블록 | 깨면 다음 한 턴 안 내려옴(`G.freeze`), 기준 턴 R +1 |
| 7 | shield | 방패 블록 | 아래 면(법선 ny>0.75)으로 맞으면 피해 없음 |
| 12 | paint | 물감 블록 | 같은 색 구간(`band`) 블록 체력 `max(1, round(hp×0.25))` 감소 |
| 18 | fire | 폭죽 블록 | 불꽃 구슬 4개(`BSPARK_V 2200`) 대각선 발사 |
| 15 | meteor | 별똥별 블록(이벤트) | 3턴 안에 깨면 구슬 +2 |
| 25 | bolt | 번개 블록(이벤트) | 같은 가로줄 블록 체력 −2 |
| 35 | chest | 보물 상자 블록(이벤트) | 셋 중 가장 적은 아이템 +1 |
| 45 | magnet | 자석 블록(이벤트) | 판의 별 조각을 모두 모음 |

- 기준 턴 `R` = 줄 수 − 3(위 4줄을 미리 채워 새 줄이 3턴 일찍 끝남)에서 시작, 시계로 멈춘 턴·줄 1이 막혀 새 줄이 늦어진 턴마다 +1.
- 별(`ballStars`): 턴 ≤ R+3 그리고 방어막 지킴 → ★★★, 턴 ≤ R+6 → ★★, 그 외 ★.
- **대전 = 모든 블록 먼저 없애기**(대표 의견 3): `ballDuelCfg()` = 고정 7줄 판(`fixed`: 줄이 내려오지 않음·새 줄 없음·방어막 없음·한 줄 올리기 없음), 시작 구슬 5, 별 조각으로 늘어남, 이벤트 블록 3개, 체력 `hpAdd 6`(줄 번호+6 기준), 제한 3분(`limit 180`, 공용 v3 느긋하게면 그 값). 지금 엔진은 대전에도 `levels.normal`을 넘기므로 `init`에서 `G.duel`이면 대전 설정으로 바꿈(v3가 `duelCfg`를 넘기면 `fixed`가 있어 그대로 씀). 다 깨면 성공(먼저 끝낸 쪽 승), 3분이 지나면 `finish(false)` → 진행도(깬 블록/전체)로 판정. HUD는 깬 블록·**남은 시간**·구슬(방어막 칩 없음).
- 대전 정의: `duelKind:'race'`, `duelMax:2`(1단계 1:1, 다인원은 공용 v3 뒤), `duelCfg`, `duelHow`, `duelPace:[110,.65]`, `duelStat.get = { v:깬 블록, t:전체, mis:0 }`, `duelMini`(남은 블록 지도 8×7, 56글자 '0/1' + 72×56 SVG).

## 점수 (그대로)
`score()` → `calcScore()` = `round((base + time + extra) × G.L.mult)` (클리어했을 때)
- base = 500(클리어)
- time = 턴 보너스 `max(0, 350 − max(0, G.turn − G.R) × 30)`
- extra = 방어막 지킴 100 + 아이템 안 씀 50
- mult: 오늘의 문제·솔로·대전 1, 연습 0.6/1.0/1.4. 최대 1000점(배율 1).

## 고칠 때 지킬 것
- **판 내용은 씨앗 rng로만**(`genBall`에서 `Math.random` 금지). 물리(`ballUpdate`·충돌)는 무작위 없이 결정적으로 — 같은 날짜 = 같은 판, 대전 공정성, 봇 재현성. `Math.random`은 효과(조각·흔들림·별 반짝임)에만.
- 깰 수 없는 판이 나오면 안 됨: 수치를 바꾸면 반드시 봇으로 클리어율·기준 턴 확인(결정 135 개편 때 기준: 1~30 강한 봇 전부, 서툰 봇 24/30 클리어).
- 물리를 바꾸면 `node tools/star-ball-bot.js index.html fps`로 30/60/120/144fps 결과가 같은지 확인.
- `star-ball-bot.js`는 소스에서 `/* ---------- 별빛 구슬: 밤하늘` ~ `\nObject.assign(SFX_GATE, { bTink` 구간을 잘라 씀 → 이 두 표시와 `function ballStageCfg`, `genBall/ballInit/ballFire/ballUpdate/ballStars/BAIM_MIN/BAIM_MAX/ballBlocksLeft` 이름을 유지. 화면 의존 코드는 `G.sim`일 때 건너뛰게(`ballAfter`). 봇은 오늘의 문제 표를 `BLEVELS`에서 그대로 읽음(`BR`, `ballDuelCfg`도 씀).
- `NG.ball` 계약 필드 이름·모양 유지. `saveKey`를 바꾸면 기존 솔로 기록이 사라짐.
- 그림·색·이름은 우리 것만(블록 5색 `BPAL`, 별빛 방어막, 별 조각, 이벤트 블록 4종 도형).
- 눈 편한 화면(2026-10-06 디자인팀): 광택·그라데이션·그림자 없음, 판 안 단색 `#211A4A`, 블록 테두리 `#1A0F45`, 숫자 흰 글자 20px + 외곽 2px, 계속 움직이는 효과 없음(별 조각·방어막 띠·위험 줄 모두 멈춤). 이벤트 블록 금 테두리만 1초 주기 밝기 20% 이내. 효과는 맞을 때 0.12초 눌림·−1, 깰 때 파편 6~10개, 한 턴 6개 이상 "와르르 N개!", 10개 이상 `fxShake` 2px. 원본 블록깨기 게임의 규칙 조합·화면·수치·용어를 가져오지 않음(결정 135).
- 모바일: 캔버스 포인터 조준 + `touchstart preventDefault`, ◀ ▶ 길게 누르기, 화면 높이에 맞춘 캔버스 크기(`size()`), 정리(`G.cleanup`)에서 resize·반복 타이머 해제.
- `core/`를 고치면 모든 게임과 모든 embed에 영향 → 꼭 필요할 때만.

## 확인 방법
- `node tools/build.js` (고친 뒤 매번: index.html 파일 목록, `embed/ball.html` 다시 만듦) → `index.html` 열어 별빛 구슬 플레이.
- 모듈: `embed/ball.html?mode=daily` · `?mode=practice&level=hard` · `?mode=solo&stage=18&unlock=1` · `?mode=duel`.
- `npm test -- ball` (사이트·모듈에서 모든 모드를 한 판씩 자동 점검, `tools/test.mjs`).
- 자동 플레이 난이도 점검: `node tools/star-ball-bot.js [index.html] [모드] [각도 수] [조준 흔들림(rad)]`
  - 예) `node tools/star-ball-bot.js index.html stages:1:30 40` (잘하는 사람) · `node tools/star-ball-bot.js index.html stages:1:30 16 0.03` (서툰 사람)
